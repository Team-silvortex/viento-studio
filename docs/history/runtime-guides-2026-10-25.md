# 声音与项目事件指南的历史前言

2026-10-25 从下列现行指南迁存的版本前言。文字中的“当前”“未发布”指原记录的开发时点；相对链接改指原文目标，测试报告及指纹保持原文件。现行入口见[声音](../SCENE_AUDIO.md)、[项目事件](../PROJECT_EVENTS.md)和[行为声音控制](../PROJECT_AUDIO_CONTROLS.md)。


## 场景声音

来源：[SCENE_AUDIO.md](../SCENE_AUDIO.md)。

**0.1.6 收录说明**：[本版源码](../RELEASE_0.1.6.md)收录音轨使用位置、提示就地定位及行为参数原文只读查看。表单提示与保存态文字匹配分别标记，保留原编辑输入及试听；查询不提供删除保护。下文开发专题保留原版本与验收条件。

**0.1.5 收录说明**：[本版源码](../RELEASE_0.1.5.md)收录已有声音的时间提示编排、轨道管理、已绑定素材选择、就地试听及暂停／定位，以及行为文本参数中的音轨选择。读取、试听、表单修改与普通保存保持独立。下文开发阶段及专题证据保留原时点；源码发布不代表已更新安装或设备验收。

[0.1.4 源码](../RELEASE_0.1.4.md)已收录首次声音创建、逐轨触发方式与[行为驱动声音](../PROJECT_AUDIO_CONTROLS.md)：Godot 项目行为可按当前场景音轨 UUID 请求播放／停止，独立记录显示控制与音轨来源。首次创建可逐轨选择定时播放或由行为触发；默认保持定时播放，纯行为声明允许 `cues: []`。当前平台与验收以[当前状态](../STATUS.md)为准。0.1.4 后工作树另接[已有声音的时间提示增删](../SCENE_AUDIO.md#增删已有声音的时间提示)，接通[调整目标轨道与顺序](../SCENE_AUDIO.md#调整提示目标轨道与顺序)并支持[复制与移除轨道](../SCENE_AUDIO.md#复制与移除已有声音轨道)，随后接通[选择已绑定素材](../SCENE_AUDIO.md#替换音轨使用的素材)，独立的[就地试听](../SCENE_AUDIO.md#就地试听音轨素材)进一步支持进度、暂停／继续与定位；源码版本与后端协议保持。

**0.1.3 收录说明**：本页标为 0.1.2 后工作树的多行为、脚本引用、Bevy Rust 与声音增量现已纳入[本版源码](../RELEASE_0.1.3.md)。历史版本、模块数和验收条件保留原时点；0.1.3 收录时为 21 模块／38 项声明能力，该次未制作或更新安装包。

0.1.2 之后的未发布工作树增加独立声音声明、Rust 规则和内置字段编辑。第一条实际播放通道是 Linux Godot 4；Bevy 两条通道明确报告缺少音频能力。该阶段为 21 模块／38 项声明能力，声音编辑属于 `org.viento.scene-audio`，只依赖文档模块。

正文中的音频播放器与素材导入仍见[音频资源](../AUDIO_RESOURCES.md)。场景声音使用这些资源的稳定编号，决定运行时何时播放，不改变 OC 正文，也不改变 Scene2D v1／v2／v3 的字段。


## 项目事件

来源：[PROJECT_EVENTS.md](../PROJECT_EVENTS.md)。

**0.2.0 后当前工作树**在显式逐实例动画项目中使用协议11；事件接口和队列保持，事件回看同时读取协议10／11的进入来源，动画命令与完成另外带有目标身份。范围需在动画字段中[审阅并保存](../SCENE_ANIMATION.md#为正式运行选择播放范围)，不从消息或参数名推断；当前源码验证见[本轮记录](../test-results/animation-instance-runtime/README.md)，不代表更新安装。

**0.1.9 后工作树**新增[事件投递回看](../PROJECT_EVENTS.md#按事件回看投递与动画进入)，沿用既有p10来源证据；该回看切片接入时，严格控制器工程使用Godot0.19.0／protocol10／清单11，普通动画p7、无动画p4。此增量只读，不改变事件接口、作者格式或安装版。

**0.1.8 源码收录**：自然完成通知、状态表与条件、版本化源码重编辑、参数接口及脚本使用位置已纳入[本版](../RELEASE_0.1.8.md)。0.1.8发布时Godot适配器0.16.0，新含动画项目使用protocol 7／清单8，22模块／43项声明能力保持；下述较早阶段的版本与验证条件按当时范围保留，本次未更新安装。

**0.1.7 源码**新增[事件触发动画片段](../SCENE_ANIMATION.md#用项目事件触发动画片段)起始脚本，组合已有订阅与选择／播放端口，事件处理和动画执行回执各自核对；事件总线格式与生命周期保持。见[版本记录](../RELEASE_0.1.7.md)。下列项目事件历史证据保留原执行版本，本次未更新安装。

本页能力已纳入源码交付；开发证据保留执行时的 0.1.3 工作树身份，安装及目标设备范围以[当前状态](../STATUS.md)为准。

已收录 [0.1.4 源码](../RELEASE_0.1.4.md)。项目行为可以发布带有一个标量值的事件，由当前场景内明确订阅的其他行为处理。例如，拾取行为发布 `item.collected`，任务行为处理后更新[共享状态](../PROJECT_SHARED_STATE.md)，再请求进入下一个[组装成员场景](../PROJECT_ASSEMBLY.md#运行中切换场景)。

事件接口属于项目会话，订阅属于当前场景访问。切场景后历史记录仍可查看，旧订阅自动撤销；新场景不会补收先前事件。需要跨场景保留的结果应明确写入共享状态。事件不是存档、网络消息或持久任务队列。
