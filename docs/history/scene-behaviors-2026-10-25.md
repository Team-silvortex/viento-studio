## 历次增量前言

**0.2.0 后当前工作树**支持在动画文档中显式选择[逐实例正式运行范围](../SCENE_ANIMATION.md#为正式运行选择播放范围)。同一脚本可由不同实例分别控制其动画，状态片段参数助手和普通保存保持；项目端口的身份约束见[下节](../SCENE_BEHAVIORS.md#逐实例动画端口的身份边界)。应用版本不变，本轮未更新安装。

**0.1.8 源码收录**：自然完成通知、状态表与条件、版本化源码重编辑、参数接口及脚本使用位置已纳入[本版](../RELEASE_0.1.8.md)。0.1.8发布时Godot适配器0.16.0，新含动画项目使用protocol 7／清单8，22模块／43项声明能力保持；下述较早阶段的版本与验证条件按当时范围保留，本次未更新安装。

**此前0.1.7开发阶段**可在新建脚本中选择 **Godot / 动画状态表**。每个状态生成 `clip_<状态标识>` 文本参数，继续在行为编辑器按名称选入片段；初始状态会在项目运行就绪时播放。表格生成、源码保存、绑定和参数保存分别负责，见[状态表用法](../SCENE_ANIMATION.md#从状态表生成动画脚本)。

**此前0.1.7开发阶段**增加普通“Godot / 动画完成后衔接片段”脚本，复用片段参数选入与普通保存；新含动画项目通过 protocol 7 提供完成订阅。详见[自然完成用法](../SCENE_ANIMATION.md#动画自然完成与片段衔接)，该增量尚未发布。

**0.1.7 源码收录**：[项目动画控制](../SCENE_ANIMATION.md#行为控制项目动画)、[命名片段](../SCENE_ANIMATION.md#命名动画片段)、[按名称选入片段编号](../SCENE_BEHAVIORS.md#将动画片段编号填入行为参数)及[事件动画起始脚本](../SCENE_ANIMATION.md#用项目事件触发动画片段)现已进入[本版](../RELEASE_0.1.7.md)。脚本、参数和保存仍沿普通作者流程；目录不建立持续引用保护。当前 22 模块／43 项声明能力，以下较早版本与测试数字保留各自时点，本次未更新安装。

**0.1.5 收录说明**：[本版源码](../RELEASE_0.1.5.md)收录已有声音的时间提示编排、轨道管理、已绑定素材选择、就地试听及暂停／定位，以及行为文本参数中的音轨选择。读取、试听、表单修改与普通保存保持独立。下文开发阶段及专题证据保留原时点；源码发布不代表已更新安装或设备验收。

**0.1.3 之后的当前工作树**为 Godot 项目组装行为提供[场景切换](../PROJECT_ASSEMBLY.md#运行中切换场景)、[共享状态](../PROJECT_SHARED_STATE.md)、[项目事件](../PROJECT_EVENTS.md)和[声音播放／停止](../PROJECT_AUDIO_CONTROLS.md)。这些接口绑定当前场景访问，单场景运行不会注入项目端口；旧行为计划与单场景协议保持。当前为 21 模块／40 项声明能力，应用版本和安装保持。

**0.1.3 收录说明**：本页标为 0.1.2 后工作树的多行为、脚本引用、Bevy Rust 与声音增量现已纳入[本版源码](../RELEASE_0.1.3.md)。历史版本、模块数和验收条件保留原时点；当前为 21 模块／38 项声明能力，本次未制作或更新安装包。

**0.1.2 之后的未发布工作树**增加首次创建时的多绑定／多脚本清单，以及独立的[已有行为管理](../SCENE_BEHAVIORS.md#管理已有行为)。一份行为文档可配置 1–32 个绑定，实际使用最多 8 份已登记 TXT；同一实例可有多份行为，同一脚本可由多份绑定复用。系统仍为 20 模块／37 项声明能力；[多绑定创建](../test-results/scene-behavior-multi-create/README.md)与[已有行为关联](../test-results/scene-behavior-links/README.md)分别记录范围，本轮未更新或安装程序包。

**0.1.2 源码交付**：本页的原文查找替换及原生撤销／重做修复已纳入本版。当前系统另含配方创建助手，共 20 模块／37 项声明能力；下列脚本和行为专题数字保留当时范围，见[版本记录](../RELEASE_0.1.2.md)。

**0.1.1 源码交付**：本页标为“0.1.0 之后工作树”的能力现已纳入 0.1.1；既有标题与链接保留，专题测试仍按当时版本解读。当前范围见[版本记录](../RELEASE_0.1.1.md)，安装及设备验收另列。

0.0.8 源码已接通“已登记场景实例 → 独立绑定文档 → 已登记行为源码 → 参数 → 运行事件”。第一种实际实现是 Linux Godot 4 的 GDScript Node 行为。纯绑定规则、冻结执行中间层和 Godot 实现分别维护，界面不解析或执行 GDScript。

行为不写入 OC 定义或旧 Scene2D 的演员字段。Scene2D v2／v3 实例可引用独立 JSON 绑定文档；行为源码使用普通已登记 TXT 文档，在编辑器源码模式编辑。没有行为的场景仍产生原 plan/runtime v1／v2；明确启用行为时才产生新的 plan/runtime v3。World v1 的 `behaviorBindings` 仍为空，不因此升级 World、workspace 或 Scene2D 作者格式。

**Bevy Rust 增量**：当前工作树另有独立 `org.viento.bevy-rust` 执行通道，脚本创建与首次行为表单可明确选择 Rust；已有引用和绑定编辑继续共用中立格式。使用前需配置固定本机工具链，运行限无图、有界 `ready` 与显式固定步位置／事件逻辑；[Bevy 指南](../BEVY_BACKEND.md#rust-作者行为通道012-后工作树)、[首次通道记录](../test-results/bevy-rust-behaviors/README.md)和[固定步记录](../test-results/bevy-rust-fixed-step/README.md)单独说明，旧 Godot 证据范围保持。

## 模块数与固定步发布时点

当前有未保存草稿、正在创建其他文档或宿主忙碌时，先完成当前操作；取消脚本窗口不会写文件。预览与创建草稿之间若文档会话、正文目录或类型目录变化，需重新打开核对。此入口属于独立 `org.viento.scripts` 模块，提供 `authoring.script`；该入口初次接入时为 19 个固定模块、36 项声明能力；当前系统为 20／37。创建和编辑只生成普通草稿，不解析或执行 GDScript／Rust，也不提供 LSP 或自动发现导出属性。Rust 编译由独立 Bevy Rust 执行适配器在显式构建／运行时负责。

已登记且格式有效的绑定文档现在可以通过独立的 **编辑场景行为** 面板修改。它属于 `org.viento.scene-behaviors`，声明能力为 `scene.authoring.behaviors`；该编辑专题接入时为 18 个固定模块、34 项声明能力，随后首次创建行为增至 18／35、脚本创建增至 19／36；当前系统为 20／37。界面、可移植原文补丁、只读依赖核对和文档草稿宿主分别接入，不需要启动 Godot 或外部 IDE。

本增量不增加作者格式、系统模块或声明能力，产品版本仍为 0.1.2 工作树；实际验收范围见[固定步专题](../test-results/bevy-rust-fixed-step/README.md)，安装、图形窗口和移动设备验证分别进行。
