# SCENE_ANIMATION.md 历史说明归档

归档日期：2026-10-25。以下内容从[当前指南](../SCENE_ANIMATION.md)移出，保留原记录的开发时点、版本和验收边界；其中“当前”“工作树”“未发布”和安装状态均指原记录时点，不代表现在的产品状态。当前版本与交付范围见[状态页](../STATUS.md)。原专题、发布记录及其证据文件保持不变。

## 历次增量前言

**0.2.0 后工作树新增[按动画目标回看](../SCENE_ANIMATION.md#按动画目标回看运行记录)**：从一条命令或完成记录打开本目标的访问历史，同一实例的多个行为共同展示；完成记录可定位到本目标最后执行的命令。只读视图复用协议11，操作不改变播放或作者文档。

**0.2.0 后当前工作树**支持[显式逐实例运行范围](../SCENE_ANIMATION.md#为正式运行选择播放范围)：动画 schema 4 经检查、审阅和普通保存后，在 Godot 项目组装中按实例控制播放与自然完成。整场景旧语义、状态表作者脚本和独立[保存态预览](../SCENE_ANIMATION.md#按实例预览已保存动画)保持。应用版本仍为0.2.0，本轮未更新安装；旧发布及专题证据保留原条件，当前验证见[逐实例运行记录](../test-results/animation-instance-runtime/README.md)。

**0.1.8 源码**收录自然完成衔接、状态表生成与重编辑、静态状态图和事件载荷条件；配套参数修复与脚本使用位置见[版本记录](../RELEASE_0.1.8.md)。下文开发专题保留当时的版本与证据，本次未更新安装。

**此前0.1.7开发阶段**可从[动画状态表生成普通脚本](../SCENE_ANIMATION.md#从状态表生成动画脚本)，集中配置初始状态、事件与自然完成转换；生成、普通保存及运行分别负责。

**此前0.1.7开发阶段**增加[动画自然完成与片段衔接](../SCENE_ANIMATION.md#动画自然完成与片段衔接)：普通行为脚本订阅自然完成，选择后续片段；完成记录和命令记录分开。该增量现已收录0.1.8源码；开发验证范围见[专题记录](../test-results/project-animation-completion/README.md)。

**0.1.7 源码**已收录等分网格序列帧、项目动画控制、命名片段、行为参数片段选入、片段使用位置、事件触发、整段时长调整和轨道复制，详见[本版记录](../RELEASE_0.1.7.md)。下文“0.1.6 后工作树”与适配器版本按专题开发时点保留；本次未更新安装，旧报告不改标为发布重跑。

此前 0.1.6 源码支持独立视觉关键帧动画：内置字段编辑、Rust 采样示意、已保存场景画面预览、Godot 场景与多场景工程执行。当前安装版尚未更新；发布范围见[版本记录](../RELEASE_0.1.6.md)，开发验证保留于[验收记录](../test-results/scene-animation/README.md)。

## 命名片段首次发布基线

**0.1.7 发布基线**：schema 3 要求 `animation.clips2d`，动画计划为第 2 版；Godot 适配器 0.15.0 对含 schema 3 的项目生成 protocol 6／清单 7。只含 schema 1／2 动画的项目继续生成 protocol 5／清单 6，无动画项目仍为 protocol 4／清单 5。Bevy 未声明动画片段支持。片段混合、状态机、关键帧事件、播放速率、骨骼与 3D 动画不在本轮范围。实际源码、Chrome、Godot 与工程交付验证见[命名片段验收](../test-results/scene-animation-clips/README.md)，尚未更新安装包。
