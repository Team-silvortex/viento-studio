# 原地重启当前关卡

0.3.0 源码新增 **Godot / 按动作原地重启关卡**。它销毁当前组装成员的运行对象，再重新创建同一场景，并在新行为就绪前完整覆盖明确列出的共享状态。未列出的进度保留；作者文件和素材不改。本机已安装版本仍为0.2.0，0.3.0 发布验证见[发布检查](test-results/release-0.3.0/README.md)。

## 在内置编辑器中配置

1. 将游玩场景加入已保存的[项目组装](PROJECT_ASSEMBLY.md)。一个成员也可以重启；此能力要求组装，单独场景构建会提示改用组装。
2. 选择已存在的输入动作。需要自定义重启键时，创建并保存输入映射，例如 `restart → R`，在组装中引用并保存；模板不会替你创建动作，使用已有 `ui_accept` 无需另建映射。当前预览的 `ui_cancel`（通常是Escape）仍用于结束运行，重启请选择其他动作。
3. **新建脚本 → Godot / 按动作原地重启关卡**，核对预览，创建普通TXT并保存。
4. 在 **构建 → 管理已有行为** 中审阅并保存该脚本的引用。在游玩场景的行为编辑器添加一个绑定，选择稳定实例，再通过 **脚本参数接口 → 补齐缺失参数** 加入两项String参数。
5. 将 `action_name` 改为已保存的动作；可用[按名称连接](SCENE_BEHAVIORS.md#按名称填写成员实例与输入动作)。填写状态初始值，检查完整修改，应用原文草稿并普通保存。
6. 检查组装，重新构建并窗口运行。移动、拾取或受伤后按重启键，核对位置、道具、门、生命、HUD和声音的重建结果；长按只触发一次，释放再按才允许下一次。

| 参数 | 原始默认值 | 含义 |
| --- | --- | --- |
| `action_name` | `ui_accept` | 已注册的输入动作；按需改为 `restart` |
| `state_values_json` | `{"score":0,"health":100}` | 只复位明确列出的共享状态；例如 `{"score":0,"health":3,"door_open":false}` |

不需要目标场景参数。`{}` 只重新创建对象，不覆盖共享键；未列键继续保持，新的关卡行为也可能在进入后正常写入状态。参数助手只接受当前官方完整正文的LF／统一CRLF表示，各允许一个开头BOM；修改正文后继续普通手填。专用构建预检和能力推导只匹配原始官方正文，不扩展为任意源码解析。

## 状态、时间与输入

初始值沿用[关卡重试的严格JSON规则](SCENE_RETRY.md#初始值的规则)：最多4096 UTF-8字节、0–16个标量键，拒绝重复解码键、嵌套、null、无效Unicode或越界数字。官方源码的错误定位到绑定及参数；自定义脚本不推断语义。

请求先验证当前访问、绑定、待处理切换、完整状态候选及剩余预算。拒绝返回false，不改状态和预留额度；受理后复制初始值，预留每键一次变更额度，并占用原有切换槽位。旧队列按原规则处理，到离场边界时一次合并初始值，再关闭旧场景和创建同一成员。期间旧行为对未指定键的正常写入仍保持，但不得破坏已预约覆盖后的总容量。

旧行为、物理体、相机、HUD、声音和动画随旧节点关闭，新访问重新实例化。旧项目、事件、状态、媒体与重启访问接口失效；不会把旧行为对象搬进新场景。模板忽略进入时已按住、重复、失焦和界面已处理的输入，须释放后重新按下。

这是**同一次有限会话中的新场景访问**：访问号、共享状态修订、事件／媒体序号、总运行时间和累计预算继续，场景局部计时重新从0开始。最多64次访问，其他事件／状态／媒体预算也不因重启而重置。结束优先于已预约重启，取消或中止不应用初始值，也不返还已占用额度。它不等于暂停、持久存档或全新会话。

## 后端与观察接口

自定义Godot项目行为可以使用独立的访问接口：

```gdscript
var restart = get_meta("viento_project_restart")
var accepted = restart.request_restart({"score": 0, "health": 3})
```

接口只接受当前访问绑定的合法Dictionary。普通 `viento_project.request_scene()` 和 `viento_project_retry.request_retry()` 继续拒绝跳向自身；失败页回关卡仍用[不同成员重试](SCENE_RETRY.md)。

原地重启生成层为 **0.47.0**，声明 `project.scene-restart`。当前Godot执行描述符为0.49.0；未要求暂停的工程继续此0.47.0生成层，要求暂停时再包上[0.48.0可选暂停外层](PROJECT_PAUSE.md)。新增入口包在完整0.46.0重试层外，逐字校验新脚本、清单、原设置及成对时钟设置；缺失或修改不降级执行。旧86份后端GD／文本保持。精确绑定官方脚本时，成员和组装都明确要求此能力；删掉声明不能绕过支持检查。Bevy尚未接入。

项目业务线协议仍按内容选择4／7／10／11，作者格式和事务日志不升级。适配器根据可信生成能力显式启用读取同场景新访问，通用读取器默认继续拒绝。启用的观察快照携带可选 `project.sceneRestart: true`，查询会重新验证相邻访问和离场边界；旧快照不加该字段，旧样本不会在重启间隙冒充新位置。该标记描述观察能力，不赋予执行权限。

作者包仍携带普通脚本和显式依赖；标准 `.viento-build.zip` 包含完整新外层，可在换根后检查运行。生成工程仍依赖Godot工具，不是独立游戏发行物。作者操作、原生窗口和离线重跑分别记录在[本轮验证](test-results/scene-restart/README.md)。本轮[运行菜单](PROJECT_MENU.md)已补场景重开与暂停恢复／结束；完整从空白关卡创作、持续运行、跨启动进度及新安装验收继续按[路线](ROADMAP.md)推进。

运行菜单复用此重启端口，但只在正常scene菜单模式可调用；暂停中重开仍拒绝。具体边界见[运行菜单](PROJECT_MENU.md)。
