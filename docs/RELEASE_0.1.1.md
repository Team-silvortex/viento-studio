# 0.1.1 版本记录

2026-10-13。本版收录 0.1.0 之后的 3D 导航与天气表现、内置脚本／行为创作、源码编辑辅助及生成工程交付。应用与工程数据分别管理，原工程、素材、应用标识及用户数据路径保持。

## 变更

- **3D 观察与导航**：六向标准观察、临时镜头平移、正交观察、坐标方向提示与双指平移／捏合。数学、绘图适配与界面分开；只读视图不写作者相机或场景原文。
- **距离雾与通用粒子场**：Rust 校验、保真编辑及确定性采样接入环境编辑、独立播放时钟、WebGL2 实例绘制与 Godot 工程。雨雪通过参数组合表示；作者先审阅草稿，再普通保存。
- **内置脚本和行为创作**：提供两份 GDScript 起始内容；已有行为的类型化参数、信号及绑定可审阅后应用草稿。首次添加行为一次保存声明、登记与 Scene2D 关联，随后打开原文继续编辑；创建本身不执行脚本。
- **源码编辑辅助**：单行／多行缩进、原生撤销与重做、行列位置和按行跳转；构建诊断打开原文后保留单条问题上下文，修改或撤销后提示重新检查。修复折行显露、跨窗口焦点交接、过期选区及窄屏布局，中英日同步。
- **生成工程交付**：核对成功 Scene2D 构建的身份、来源和库存后，审阅并导出 `.viento-build.zip`，包含登记文件、必要资源、说明与校验清单。作者完整工程迁移仍使用 `.viento.zip`；Godot 与 Bevy 保留各自工具依赖。
- **故障恢复测试稳定性**：模拟崩溃进程保持在事务检查点，确认观察期间仍持锁并由父进程终止；父连接断开时退出。修复的是测试进程提前退出的竞争问题，生产事务规则保持。

当前为 **19 模块、36 项声明能力**。功能图谱共 **110 功能、288 实现、433 绑定、1732 评分单元**；本版将 14 个新增功能的交付状态及相应交付评分更新为源码交付，其他评分和历史验证不提升。操作入口见 [3D 场景](SCENE3D.md)、[脚本与行为](SCENE_BEHAVIORS.md)、[工程交付](BACKEND_PROJECTS.md)和[完整工作流](PROJECT_WORKFLOW.md)。

## 交付边界

本次提交推送源码，不制作安装包、更新现有安装或创建 GitHub Release／版本标签。用户可从源码启动或自行构建；最近保留的 Linux 安装包验收仍为 [0.0.4](test-results/release-0.0.4/results.json)。

3D 仍为有限方块与环境表示；模型、纹理、物理、空间层级及 3D 行为另行推进。无头 Godot dummy 渲染不能回读非空粒子实例时明确报告限制，真实图形验收另列。生成工程交付当前接 Scene2D，未纳入 Scene3D 或 Composition，也未生成独立游戏发行程序。

内置作者脚本当前为 GDScript；Bevy 仍使用可信 Rust 运行程序，不编译工程内 Rust 文本。完整问题总表、持续诊断、外部 IDE／LSP、Nuislang／ns-nova 原生执行和嵌入式引擎视口继续独立开发。
