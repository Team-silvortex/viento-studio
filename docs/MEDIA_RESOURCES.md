# 图片、视频与音频资源

本页是文档媒体的统一使用入口，适用于桌面版和本地浏览器编辑服务。媒体可用于任意文档类型，文件保存在作品自己的素材存储中。平台与发行状态见 [当前状态](STATUS.md)。

## 导入或复用素材

1. 打开文档并进入编辑状态，在正文或文字字段中定位插入位置。
2. 点击 **插入素材 → 从电脑导入**，可选择多个文件；也可直接粘贴图片，或把受支持的文件拖入编辑区。
3. 复用已有素材时，在素材窗口按名称搜索，或按图片、视频、音频筛选，点击可用素材卡片插入。
4. 检查草稿中的素材预览，然后 **保存修改**。保存后，媒体在正文对应位置显示。

| 种类 | 可导入格式 |
| --- | --- |
| 图片 | PNG、JPG / JPEG、WebP、GIF、SVG |
| 视频 | MP4、WebM、MOV |
| 音频 | MP3、WAV、OGG / OGA、Opus、FLAC、M4A、AAC |

单个文件最多 256 MB，实际限制为 `256 × 1024 × 1024` 字节。导入会检查扩展名和文件内容的格式特征；能够导入不等于本机一定能解码播放。文件保留原始编码，应用不在导入时转码。

导入期间会保护插入位置并暂时阻止保存、切换文档等操作。可以点击 **取消导入**；失败或中断会清理尚未完成的临时文件。多文件导入中已完成登记的素材仍保留在列表中，可重新选择。

素材入库与文档保存是两件事：导入成功后取消正文草稿，不会自动删除已登记素材。内容相同且已登记原文件完整时会复用已有文件，避免重复占用空间。

## 编辑与预览

| 编辑位置 | 插入行为 |
| --- | --- |
| Markdown / 文本的源码或分段 | 在当前文字位置插入媒体标记 |
| JSON / YAML 的源码或分段 | 向媒体列表追加 `{type, src, caption}` 对象；根文档是列表时直接追加 |
| 文字字段 | 在字段值中插入媒体标记，序列化时按该格式转义 |
| 已有媒体对象的 `src` 字段 | 选择一份同类型素材，替换该字段的稳定引用 |

JSON / YAML 已有同名非列表字段会保留，插入时使用空闲的媒体字段名。操作按源文范围追加，保留其他值、注释、BOM 和换行；语法不完整或根内容无法容纳媒体对象时，会提示修正并保留草稿。字段模式的其他约束见 [字段编辑](FIELD_EDITING.md)。

草稿预览随当前内容更新；音视频提供播放、暂停和进度控制，不自动播放。退出编辑、切换到另一份文档或更换预览内容时，会暂停旧播放器。保存才会更新正式正文与引用索引，预览出现不代表已经保存。

播放取决于浏览器、WebView 和系统解码器。素材离线、缺失或无法解码时会提示问题；音视频提供原文件入口。先确认素材存储在线和原文件完整，再判断是否需要在其他工具中转换编码。音频缓冲和格式细节见 [音频资源引用](AUDIO_RESOURCES.md)。

## 引用与文件位置

编辑器新插入的引用使用素材 UUID，例如以下三个独立媒体标记：

```md
![角色立绘](asset:00000000-0000-0000-0000-000000000001)
!video[动作参考](asset:00000000-0000-0000-0000-000000000002)
!audio[角色配音](asset:00000000-0000-0000-0000-000000000003)
```

示例 UUID 需对应本工程中实际登记的素材。图片沿用 Markdown 图片语法，`!video` 和 `!audio` 是 Viento 扩展；在其他阅读工具中应使用分享导出后的相对文件链接。JSON / YAML 媒体对象使用 `type`（`image`、`video` 或 `audio`）、`src`（稳定引用）和可选说明 `caption`，可放入字段或列表。代码围栏中的示例不当成实际媒体引用。

新导入文件分别位于素材存储的 `media/images/`、`media/videos/`、`media/audio/`，使用 UUID 文件名；登记中的名称保留导入文件名。元数据位于工程的 `metadata/assets/<UUID>.json`。已有素材保留原目录和 ID，原有 `assets/...` 路径引用继续兼容。

若工程绑定外置素材目录，文件写入该素材存储；日常工程应保持与源码和应用安装目录分离。移动作品或更换磁盘时通过完整包迁移，或按 [外置素材绑定流程](WORKSPACE_LAYOUT.md#引用与素材目录) 处理实际文件和本机绑定，不要把本机绝对路径写进正文。

## 正文嵌入与对象资源绑定

**插入素材** 修改当前正文草稿，媒体按正文位置显示。封面、立绘、配音等需要作为对象附件维护时，可先保存或结束文档草稿，再进入 **世界与对象 → 选择对象 → 绑定资源**，选择已登记素材、填写用途，预览后保存。

World 资源绑定记录对象与素材的关系，不自动在正文中插入标记。同一素材可以被多个文档引用或绑定，文件仍由素材登记管理。资源包和文档分享会收集正文引用及明确绑定的资源；World 面板中的文件存在状态不能代替内容指纹校验。操作和归属关系见 [项目工作流](PROJECT_WORKFLOW.md#日常工作流)。

## 导出与迁移

| 目的 | 使用方式 |
| --- | --- |
| 单独取出图片、视频或音频原文件 | 素材卡片或资源包清单中的 **导出原文件**；保留原字节和格式，不附带 UUID 或依赖 |
| 将选定素材、对象与关系搬到另一工程 | **导出 → 资源包**，选择内容及依赖，在目标工程预览后导入 |
| 给他人阅读含媒体的文档 | **导出 → 离线网页或 Markdown**；网页可显示播放器，Markdown 为音视频生成文件链接 |
| 完整备份或换电脑继续编辑 | 完整 `.viento.zip` 项目包，包含全部素材、登记、正文和模板 |

单素材导出可在保留正文草稿时进行；文档分享、资源包和完整项目包读取已保存内容，先保存草稿再导出。外置素材会随相应包携带，缓存与本机路径绑定不进入完整项目包。操作细节见 [导出](EXPORT.md)，跨工程依赖与冲突规则见 [资源包](RESOURCE_PACKAGES.md)。

## 平台和运行边界

桌面版与浏览器编辑服务提供导入、插入和预览；只读浏览服务可阅读已保存媒体并使用相应导出入口，不提供文档写入。

Android 当前保留项目包中的媒体字节和引用，素材选择、访问和播放尚未接入；迁移能力不代表已经支持移动端媒体预览。见 [移动端说明](../mobile/README.md)。

本文描述文档内媒体。实验 Scene2D 构建当前只消费声明的图片资源，视频播放、音频行为和任意游戏媒体逻辑尚未接入，详见 [场景构建](PROJECT_BUILD.md)。
