# 0.2.9 版本记录

2026-11-11。本版完善 Godot 二维项目的行为控制和物理调试：多对象机关、自由平面角色输入、验收问题定位与碰撞示意沿现有作者保存、运行观察和工程交付流程接通，同时收录上一版之后的 ZIP 导入安全修复。

## 主要变化

- **多对象压力板**：新增普通 **Godot / 触发区占用** TXT 起始脚本，把真实 Area2D 内的物理体汇总为空／非空状态。A 离开而 B 仍在时保持占用，最后一个对象离开才发布空板事件；载荷使用触发区自身 UUID，可与事件控制平台组合。逐对象进入／离开模板保持独立，脚本和绑定仍需显式保存。[配置指南](SCENE_PHYSICS2D.md#多对象压力板与触发区占用)、[开发实测](test-results/scene-physics2d-sensor-occupancy/README.md)
- **自由平面行为意图**：新增 **Godot / 平面运动意图** 起始脚本和行为局部 `viento_planar_intent` v1 端口，供无重力、`controls: none` 的物理角色提交二维方向。每实例在下一接受步消费首个有效请求一次，长向量归一化、短向量保留强度，无新请求时归零；实际位移继续经过原生停止／滑动求解。四个动作参数可引用已保存的项目输入映射，也可普通编辑源码实现巡逻或 AI；原重力角色意图接口保持。[配置指南](SCENE_PHYSICS2D.md#用行为脚本驱动自由平面角色)、[开发实测](test-results/scene-physics2d-planar-intent/README.md)
- **验收结果定位**：物理输入验收的通过／失败条目可直接选中同一次运行的精确实例、访问、步骤和样本。实际值来自真实观察，选择只改变查看位置；需要编辑时再明确打开物理声明来源。任务、冻结快照或输入草稿变化会撤销旧入口。[操作指南](SCENE_PHYSICS2D.md#从验收条目定位物理样本)、[开发实测](test-results/physics-case-inspection/README.md)
- **位移与碰撞示意**：选中物理样本后，以等比图比较请求／实际端点、接触点和法线，保留原始精度数值。纯模型和 SVG 绘制分别维护，图只消费已准入样本；端点连线不表示完整运动轨迹，固定长度法线只表示方向。选择、刷新和切语言不发起新运行或保存。[操作指南](SCENE_PHYSICS2D.md#查看位移与碰撞示意)、[开发实测](test-results/physics-sample-diagram/README.md)
- **ZIP 导入安全修复**：收录提交 `00c06ffe` 的修复，升级 zip 依赖至 9.0.5，并在桌面／移动原生导入读取清单和创建恢复目录之前，严格核对中央目录与本地文件头一致性。合法旧归档及作者格式保持；宿主 Rust 最低版本为 1.88。[修复说明](SECURITY_ZIP_2026-11-04.md)、[原始验收](test-results/zip-security-2026-11-04/README.md)

## 数据与交付边界

Godot 执行适配器为 **0.41.0**。符合条件的自由平面角色叠加独立 `physics.planar-intent2d` 生成层；局部端口、派生继承脚本和严格库存随生成工程交付。执行指纹改变后，旧冻结构建需显式重建，作者文件不自动改写。应用版本、生成层和项目／物理观察协议分别维护；本版不升级作者场景／物理格式、Rust／WASM 语义接口或运行线协议。

脚本、参数和绑定通过普通保存持久化，资源包按明确选择及已登记依赖迁移；生成 `.viento-build.zip` 需要对应引擎工具，不是独立游戏发行包。物理输入回放与验收仍限单入口、无作者行为／声音／动画的受限 Godot 项目，因此行为意图接通不等于已完成行为项目的逐角色回放。持续接触、刚体、材质及 Bevy 物理尚未接入。

各开发专题保留原时点的日志、首次失败、条件跳过及来源摘要；它们不改标为升版后的重新执行。升版检查的实际命令、结果和覆盖范围统一见[0.2.9 发布检查](test-results/release-0.2.9/README.md)。本机已安装 Studio 仍为 **0.2.0**；源码发布不会自动更新安装，也不外推其他平台或实体设备验收。
