# 0.0.5 版本记录

2026-10-02。新增资源绑定、可跨项目导入的选择式资源包和单个素材原文件导出。继续使用 workspace v2 / v3，保留作品、对象和素材 UUID，沿用正文、登记及外置素材结构。

## 变更

- **绑定资源**：在“世界与对象”中选择已登记素材与自定义用途，预览后保存。GUI、CLI 和 HTTP 共用 `resource.bind`；支持离线素材、版本冲突检查、保真登记修改与中断恢复。
- **资源包复用**：从“导出 → 资源包”选择对象和素材，自动收集引用、附属故事与模板依赖。`.viento-package.zip` 保留原始文件、UUID、关系、用途和解析规则。跨项目导入先预览；相同内容复用，冲突阻止写入，未完成的导入支持恢复。
- **单素材导出**：插入素材窗口和资源包清单提供“导出原文件”。图片、视频、音频及其他已登记素材按原格式保存，不转码、不打 ZIP；保留编辑草稿、光标和资源勾选。下载与系统保存使用实际文件名和扩展名，支持取消、过期与重试。
- **数据保护**：新增资源绑定 version 4 意图与资源包导入日志；Node 读取／写入／导出及 Rust 备份检查未完成事务。流式文件校验、可移植路径和内容指纹检查覆盖原文件与资源包，失败保留原项目。
- **界面与文档**：上述流程提供中英日提示、搜索筛选、清单返回入口和窄屏布局，补齐使用说明、协议与回归证据。
- 产品、锁文件和界面统一为 `0.0.5`；Android `versionCode` 为 `1000005`，macOS 构建编号为 `1.0.5`。应用标识仍为 `io.viento.studio`。

使用与边界见 [资源绑定](WORLD_RESOURCES.md)、[资源包](RESOURCE_PACKAGES.md)、[单素材导出](EXPORT.md#单个素材导出原文件) 和 [事务恢复](WORLD_TRANSACTIONS.md)。

开发阶段的 [资源绑定](test-results/world-resources/results.json)、[资源包](test-results/resource-packages/results.json) 和 [单素材导出](test-results/asset-export/results.json) 保留当时的 0.0.4 源码标识和结果。其中真实浏览器验证了跨项目导入、原文件下载、中英日、窄屏、草稿及原始字节保留；进程中断与恢复由专项回归覆盖。这些记录不改写为新安装包验收。

本次交付为源码版本提交与推送，没有重新制作、发布或安装 AppImage、deb、APK，也没有创建 GitHub Release。已有 0.0.4 安装和 `dist/current/` 保留；需要使用新桌面功能时应从 0.0.5 源码启动或另行构建安装包。Windows／macOS 原生交互、Android 新界面与新的系统保存窗口操作仍需目标平台验收。

Android 继续支持现有编辑器与完整项目迁移，尚未接入资源绑定、选择式资源包和单素材导出界面。资源解绑／替换、通用混合 ChangeSet、workspace v4 和 Build 仍未实现。旧程序不能恢复新的资源绑定或资源包导入日志；回退前应先用支持相应协议的版本完成恢复。
