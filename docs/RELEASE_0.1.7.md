# 0.1.7 版本记录

2026-10-20。本版收录 0.1.6 之后的八项动画增量：从图集序列帧、片段编辑与复用，到行为控制、事件触发和执行记录，继续贯通普通保存、Godot 构建与工程交付。

## 变更

- **等分图集序列帧**：使用实例现有图片，配置列／行和帧索引；字段编辑、编辑示意、保存态场景画面和 Godot 使用同一离散采样规则。共享图片的实例各自保持帧状态，大图集的解码预算与着色缓存独立受限。
- **行为控制项目动画**：脚本可播放、暂停、停止或定位当前场景的动画。Rust 维护显式时钟下的播放头规则，Godot 在当前访问内排队；独立控制记录展示实际执行回执与行为／动画来源。
- **命名动画片段**：同一动画定义可重叠的时间窗口，各自设置循环并保留稳定 UUID。编辑示意、场景画面、脚本选择和工程交付使用局部时间；观察记录可定位到具体片段声明。
- **行为参数按名称选片段**：读取当前场景已保存的片段，按名称、范围和完整编号选择，再显式填入普通文本参数。目录读取、暂选、审阅和保存分开；旧动画与空片段不自动升级。
- **片段使用位置**：查看同场景已保存行为参数中完整 UUID 的文字匹配，并就地定位只读原文。查询不改变动画表单、已有审阅或播放，也不自动保护删除或迁移引用。
- **事件触发片段**：新增可编辑的 Godot 事件动画起始脚本，收到指定事件后从头播放所选片段或完整动画。启动时只订阅，退出时清理；重复事件按队列处理，事件处理记录与动画执行回执分别核对。实际 Godot 验证修复了已释放对象的类型守卫。
- **整段按比例调整时长**：以当前未保存表单为输入，同步缩放全部关键帧和片段边界，保留数值、身份、顺序及网格。相同时长不重算，浮点精度使不同时间合并时整次拒绝；结果仍需检查、审阅和普通保存。
- **复制轨道到其他实例**：从当前表单选择源轨道及同场景的已保存目标实例，分配新编号并追加副本。目标同属性冲突或超预算整次拒绝；序列帧仍使用目标自己的图片，不复制资源或建立持续同步。

上述作者与观察界面提供中、英、日说明，并分别保护来源、目录、当前表单和在途请求。操作见[场景动画](SCENE_ANIMATION.md)、[行为参数选入](SCENE_BEHAVIORS.md#将动画片段编号填入行为参数)和[项目事件](PROJECT_EVENTS.md)。

## 格式与兼容

当前 **22 模块／43 项声明能力**；图谱为 **133 功能／399 实现／583 绑定／2332 评分单元／96 工作流**。Godot 适配器为 **0.15.0**，Bevy 数据适配器 **0.3.0**、Rust 适配器与模板 **0.2.0** 保持。产品升版不提高已有成熟度评分。

动画 schema 1 保留原四属性，序列帧使用 schema 2，命名片段使用 schema 3；采用新字段时经普通审阅显式升级，旧作品不批量迁移。schema 3 使用 animation-plan 2，旧动画仍为 plan 1。Godot 项目按冻结内容选择协议与清单：无动画为 protocol 4／清单 5，仅旧动画为 protocol 5／清单 6，含 schema 3 为 protocol 6／清单 7。旧接口和无动画／原动画生成路径保持各自兼容边界。

共享 Rust 主协议保持第 1 版，序列帧、transport、片段、时长调整和轨道复制分别使用可选能力标记。缺少作者辅助能力不会授权 JavaScript 回退变换；普通编辑按已有能力继续。时长调整通过时间叶补丁保留无关原文；新增轨道会重写 `tracks` 数组，保留数组外未修改字节、BOM 和换行风格。应用标识、用户数据路径、已有元数据与素材不因升版搬迁。

## 交付边界

本次提交推送 **0.1.7 源码**，不制作安装包或更新本机安装，不创建版本标签或 GitHub Release。最近保留的 [Linux 安装验收](test-results/native-installed-0.1.1/README.md)仍为 0.1.1 工作树 AppImage；本轮没有新增安装、Android 或其他桌面设备验收。

动画仍是 Scene2D 的视觉层，不改变碰撞体或逻辑位置；保存态画面预览不执行脚本、物理或声音。Godot 工程 ZIP 仍需对应工具，尚非独立游戏发行程序。任意矩形／裁边／旋转图集、换图轨道、骨骼、混合状态机、缓动、关键帧事件、播放完成事件、运行时播放速率、3D 与 Bevy 动画继续独立推进；动画场景暂不接有限控制重放／用例运行。

片段编号参数仍是普通字符串。使用位置只覆盖当前场景已保存行为的完整编号文字匹配，不覆盖其他场景、脚本计算或未保存行为；未匹配不证明无人使用，也不建立自动引用保护。
