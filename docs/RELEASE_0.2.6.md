# 0.2.6 版本记录

2026-10-28。本版把运行过程中的时钟、因果引用、媒体请求和事件回执分别保存，补齐事件位置只读面板。作者数据、有限执行预算和后端能力各自守护；未确认结果不会被解释为未执行。Godot 音频退出修订及其重建、验证和回退记录一并纳入源码。

## 变更

- **调度时钟与预算窗口**：记录真实 Godot idle／physics 帧对、七维预算差值与累计用量，保留最近 32 个观察窗口。成功、失败和取消均保存最后有效摘要；窗口轮转、flush 和切场景不补充预算，观察时钟不替代执行调度器。
- **因果锚点**：在最近尾部之外保留未决事件／动画完成投递、目标播放基线及仍被状态进入引用的来源。全局命令截止与具体实例的播放命令分别记录；稀疏投影不裁剪原完整语义账本。
- **精确业务帧**：在业务回执输出时捕获引擎帧，通过独立封套核对原业务，再保存最近 128 条位置。零成本回执仍有位置；取消和通知异常保留已经准入的事实，不按日志邻近关系推算时钟，也不重复消费业务帧。
- **动画与音频请求观察**：分别保存请求身份、接受时钟，以及有匹配回执的应用或中止清理结果。两域复用有界观察机制，各自保留最近 128 条终态和全部未决请求，独立编号、FIFO 与预算。缺少完整结果保持 pending，即使命令可能已执行；音频 applied 只证明后端播放／停止调用有回执，不代表物理设备出声。
- **事件发布与逐接收者位置**：复用已有发布序号和 handled／skipped 回执，保存发布与各接收者的真实业务帧。默认保留最近 32 条已结清发布及全部未决；零接收者立即结清，部分完成保留已有结果。取消或缺回执不推断回调未执行、不补造丢弃结果。
- **中英日只读面板**：构建对话框可查看事件位置和保留范围。严格核对当前后端、任务、冻结构建及成员来源；失效、切换或缺能力时清空旧数据。面板独立于旧事件账本和运行对象视图，不授予作者保存权限；没有项目事件能力的 Bevy 不显示此面板。
- **宿主与库存修复**：收尾观察者抛错仍保留有效事实及失败会话；完整核对重生成的后端描述，防止降低能力绕过读取器。音频请求生成器允许真实导入产生的固定受限 UID 文件，同时继续拒绝未知、链接及损坏库存；旧 GDScript 与冻结生成层保持各自来源。
- **Godot 音频退出修订**：保存官方 4.7.2 WAV／播放对象退出残留的调查、固定来源补丁、重建与回退流程。本机独立工具已在此前切换至音频修订版，原官方引擎保留；本版源码推送不自动安装或切换其他机器的工具。

操作与合同见[构建工作台](PROJECT_BUILD.md)、[执行中间层](BACKEND_MIDDLEWARE.md)及[Godot 工具链](GODOT_TOOLCHAIN.md)。

## 格式、分层与兼容

Studio 保持 **23 模块／45 项声明能力**；功能图谱为 **181 功能／546 实现／756 绑定／3024 评分单元／145 工作流**。六项功能从工作树归入源码交付，原评分及历史证据保持，发布本身不提高成熟度。

Godot 执行适配器为 **0.36.0**。含音轨项目外层生成 0.36.0，无音轨但含动画为 0.35.0，其余项目为 0.34.0；内部调度观察层为 0.33.0。新观察沿独立协议 1 组合，原项目协议按内容选择 **4／7／10／11**。事件位置复用现有封套与回执，不增加后端能力、请求 ID、生成脚本或业务协议。

作者格式、UUID、原文、素材和应用标识 `io.viento.studio` 保持。新读取器、库存和工具身份会改变冻结构建的校验基线；旧构建仍可读取，运行或交付时若当前指纹不符，应显式重建，不能改旧摘要绕过检查。Bevy 数据 **0.3.0** 和 Bevy Rust **0.2.0** 适配器能力未扩大。

## 交付边界

本版为 **0.2.6 源码交付**，提交并推送主分支；本次不制作或安装新程序，不创建版本标签或 GitHub Release。本机 Linux x86_64 AppImage 仍为 **0.2.0**，[安装验收](test-results/native-installed-0.2.0/README.md)保持其原范围。

运行仍是**有限会话**：事件累计 128 次发布，状态修改 1024 次，音频／动画请求各 256 次，另有注册、投递、字节、场景访问、协议帧、进程输出和时限。原始尾部、调度窗口、业务位置、请求终态与因果锚点各自留存，均不返还预算。完整语义账本、退休身份、去重与 FIFO 尚未裁剪，实时准入和持续运行仍待独立设计。

Bevy 尚未接入项目组装、项目事件、声音、动画与本版运行观察，也没有新增图形、物理或设备支持。`.viento-build.zip` 仍交付需要相应工具的后端源工程；独立游戏发行、其他桌面系统、Android 设备及新版 Tauri 安装验收不在本版范围内。
