# 0.1.6 版本记录

2026-10-18。本版把独立关键帧动画接入场景创作、预览、Godot 运行与工程交付，同时补齐音轨使用位置和只读原文定位。

## 变更

- **关键帧动画编辑**：视觉位移、旋转、缩放与不透明度，支持轨道、关键帧、线性／阶梯插值与循环。Rust 统一检查和采样；字段表只更新普通草稿，持久化继续使用编辑器保存。
- **按实例选择目标**：从已保存场景按名称和完整编号选择，同定义的多个实例分别列出；缺失目标可修复，应用前重读来源，过期目录不会覆盖当前编辑。
- **首次创建动画**：在构建页选择场景，配置起止帧并审阅，一次可恢复事务保存新动画正文、新登记与场景关系。已有动画直接打开；回复不确定时先核对保存结果，避免重复创建。兼容登记文件的 UTF-8 BOM 并保留未改字节。
- **场景画面预览**：在保存态场景中用实际坐标、颜色和图片播放、暂停或定位动画。停止恢复静态并保留视图；动画出错不影响静态场景。播放、图片读取、布局编辑与后端执行保持独立。
- **Godot 动画执行与交付**：独立视觉容器支持与输入、行为、声音共同运行；每次进入场景单独计时，多场景工程和导出 ZIP 保留动画清单与脚本。旧无动画场景保持原通路。
- **音轨使用位置**：区分当前表单提示与同场景已保存行为中的完整编号文字匹配；可定位提示，或就地只读查看匹配参数原文，保留未完成输入与试听状态。
- **分发与回归修复**：修正 3D 导出替换测试对 inode 分配的假定；源码打包清单补入动画示例，并验证示例完整性及私有状态／缓存排除。中英日交互与错误提示同步。

当前 **22 模块／43 项声明能力**；图谱 **130 功能／375 实现／559 绑定／2236 评分单元／93 工作流**。Godot 适配器 **0.12.0**、项目协议 **4**；Bevy 数据适配器 **0.3.0**、Rust 适配器与模板 **0.2.0**。动画文档使用独立 schema 1；主 Rust ABI、既有 Scene2D 作者格式及应用数据身份保持。产品升版不提高已有成熟度评分。

操作见[场景动画](SCENE_ANIMATION.md)和[音轨使用位置](SCENE_AUDIO.md#查看音轨使用位置)。

## 交付边界

本次提交推送 **0.1.6 源码**，不制作安装包或更新本机安装，不创建版本标签或 GitHub Release。最近 [Linux 安装验收](test-results/native-installed-0.1.1/README.md)仍为 0.1.1 工作树 AppImage；源码或分发验证不代表 Android 或其他桌面设备验收。

动画目前只支持四类视觉通道，目标为保存态 Scene2D 稳定实例。场景画面预览不执行行为、物理或声音，不叠加未保存动画草稿或配方；序列帧／图集、骨骼、混合状态机、行为播放控制、3D 与 Bevy 动画继续独立推进。Godot 动画暂不接有限控制重放／用例，工程 ZIP 仍需对应引擎工具，并非独立游戏发行程序。

音轨使用位置是有限范围的文字匹配，不是引用保护或删除证明；未覆盖脚本计算、其他场景和未保存行为草稿。应用数据路径、旧作品与素材保持，新示例不包含私人作品。
