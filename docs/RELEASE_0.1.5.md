# 0.1.5 版本记录

2026-10-16。本版完善声音创作工作流：在已有声明中编排提示、管理轨道、选择素材并试听，再将音轨编号选入行为参数。作者修改仍经完整原文审阅、应用草稿和普通保存；目录读取、试听和后端执行分别维护。

## 变更

- **时间提示编排**：添加或移除 0–64 条播放／停止提示，改接已有音轨并上移／下移。执行先按时间排序，同刻按作者列表顺序；保留已有提示身份和未修改原文。
- **轨道复制与移除**：复制当前设置并生成独立轨道身份，不复制提示；维持 1–16 轨。移除前需处理提示引用，行为中的字符串 ID 仍由作者检查。操作不删除素材或登记。
- **选择已绑定 WAV**：先通过现有资源绑定入口登记关联，再在声音编辑器显式读取候选并换用素材。应用前复核来源和完整目录，保留轨道身份与提示；绑定与正文保存仍是两次独立操作。
- **单轨就地试听**：按当前音量／循环试听选中的 WAV，显示进度和时长，支持暂停、继续和定位。每次开始重新验证来源与文件字节；暂停／继续沿用该次内存快照，不重复读取。编辑、取消、关闭或隐藏页面停止试听并释放资源。
- **行为参数选择音轨**：在行为编辑器读取当前场景已保存的音轨，明确点击“填入音轨编号”后再审阅、应用草稿和保存。任意文本参数均可使用，数字／布尔不提供此助手；不会根据 `track_id` 等参数名推断用途，也不自动修改脚本或关系。
- **三语与输入保护**：中英日界面保留未完成输入及各绑定的独立选择；只读目录失败、能力撤回、关闭和迟到回复不覆盖普通编辑。

当前为 **21 模块、40 项声明能力**；图谱为 **128 功能、357 实现、541 绑定、2164 评分单元、90 条工作流**。作者格式与 Rust ABI 保持，Godot 适配器 **0.11.0**、项目协议 **4**，Bevy 数据适配器 **0.3.0**、Bevy Rust 适配器与模板 **0.2.0**。新增可选目录接口不增加 Studio 声明能力数；产品升版不改变后端身份或提高成熟度评分。

操作见[场景声音](SCENE_AUDIO.md)、[行为参数音轨选择](SCENE_BEHAVIORS.md#将音轨编号填入行为参数)及[行为声音控制](PROJECT_AUDIO_CONTROLS.md)。

## 交付边界

本次提交推送 **0.1.5 源码**，未制作安装包、更新本机安装、创建版本标签或 GitHub Release。新增功能需从源码启动或自行构建。最近的 [Linux 安装验收](test-results/native-installed-0.1.1/README.md)仍为 **0.1.1 工作树 AppImage**；桌面／移动资源准备不代表新版原生安装或 Android 设备验收。

试听限已绑定 PCM16 WAV，一次一轨；不执行时间提示，也不代表物理扬声器听测或场景运行的暂停／跳转。行为音轨目录只核对已保存身份与声明，不读取 WAV，不证明可播放性，也不跟踪后续删除或改写的字符串引用。新资源导入、解绑与清理、空间声源、混音总线及结束观察继续独立推进；Bevy 两条通道仍未接入项目组装与声音。

共享 PCM 校验器移入引擎公共层，Godot 来源指纹随之更新，旧本机构建需重新生成；适配器与协议版本不变，旧独立 ZIP 保留自身运行代码。工程 ZIP 仍需对应工具，尚非独立游戏发行程序。Nuislang／ns-nova、外部 IDE／LSP 与嵌入运行视口继续按各自接口接入。
