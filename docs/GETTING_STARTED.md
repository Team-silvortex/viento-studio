# 快速开始

先选择运行方式，再创建或打开一份工程。应用、工程和构建缓存分别保存；工程中的正文、类型、模板与资源可以独立迁移。

[当前平台范围](STATUS.md) · [日常工作流](PROJECT_WORKFLOW.md) · [文档中心](README.md)

## 选择入口

| 需要 | 入口 |
| --- | --- |
| 使用已有桌面安装包 | 从应用图标进入作品库；支持范围以该安装包版本为准 |
| 使用当前源码功能、新建工程或导入完整包 | 从源码启动桌面版，见下文 |
| 已有工程，想在浏览器编辑或体验合成样例 | 启动本机编辑服务，见下文 |
| Android 预览 | 按 [移动端说明](../mobile/README.md) 构建与导入，先确认功能和设备限制 |

当前源码版本是 0.0.6，本次未制作新的安装包。具体范围见 [当前状态](STATUS.md#版本与交付)。

## 从源码启动桌面版

准备 Node.js 24、Rust 稳定版及 [Tauri 系统依赖](https://v2.tauri.app/start/prerequisites/)，在仓库根目录执行：

```sh
npm ci
npm run desktop:dev
```

首次运行会下载并校验固定版本的 Node sidecar，准备资源并编译桌面宿主。完成后在首页选择 **新建作品库**，填写名称、保存位置和起始工程模板；也可以 **打开已有文件夹** 或 **导入迁移包**。

当前源码提供空白、游戏、文学、戏剧和软件设计。空白工程适合自己定义类型，其余包提供起始文档模板；创建后都由这份工程独立维护。已有工程的正文和类型不会因选择器新增模板而被替换，见 [工程模板](PROJECT_TEMPLATES.md)。

桌面打包、平台依赖、资源准备和清理集中在 [桌面说明](../desktop/README.md)。已构建的安装包内置 Node，普通使用者无需另装开发工具。

## 从浏览器打开工程

只运行本机编辑服务需要 Node.js 24 和 npm 依赖。先准备已有的工程目录，再显式指定：

```sh
npm ci
VIENTO_WORKSPACE_ROOT=/完整路径/我的工程 npm start -- --no-open
```

按终端打印的地址打开页面，默认是 `http://127.0.0.1:4173/web/?mode=edit`。启动会从正文生成派生索引；保存后继续更新预览。该命令不会替你创建空白工程。需要只读访问时，同样指定工程并运行 `npm run browse -- --no-open`，打开终端打印的浏览地址。

查看默认目录可运行 `npm run workspace -- paths`。环境变量仅为这次命令选择工程，日常设置和外置素材绑定见 [本机数据目录](LOCAL_DATA_STORAGE.md)。服务参数集中在 [脚本说明](../scripts/README.md)。

## 完成第一份文档

1. 先切换到 **编辑** 模式，再打开 **项目类型与模板**，确认已有类型，或新增自己的类型与起始正文。预览后保存并应用。
2. 新建文档，选择类型和保存位置，填写标题与内容。源码与字段表共用草稿；首次保存后也可使用分段编辑。
3. 在桌面／浏览器中通过 **插入素材** 添加图片、视频或音频；先保存正文，再进行分享或备份。
4. 需要关联档案时，在 **世界与对象** 中添加引用、归属或资源绑定，并先预览修改。角色自己的背景可直接写入角色档案；独立长篇背景可归属角色，详见 [文档模型](OC_DOCUMENT_MODEL.md)。
5. 分享给读者选择文档 HTML / Markdown 包；在另一个工程复用部分内容选择资源包；换机并继续编辑选择完整 `.viento.zip`，见 [导出](EXPORT.md)。

切换模式、返回窗口或保存遇到冲突时，按提示保留和处理草稿。导出读取已保存的内容；保存完成而预览刷新失败时，可重试刷新。详细操作见 [项目工作流](PROJECT_WORKFLOW.md)。

## 体验二维场景构建

仓库的 [examples/scene2d](../examples/scene2d/README.md) 是完整的合成工程。复制整个目录到自己的工程位置后，可通过上述浏览器命令或桌面首页打开它；默认空白工程和游戏设计模板不会自动生成可运行场景。

无需安装 Godot 即可在仓库中检查样例计划，此操作只读取工程：

```sh
npm run project:build -- --command plan \
  --root examples/scene2d --scene documents/scenes/demo.json
```

要真正构建和运行，当前需 Linux 本机以及可执行的 Godot 4 编辑器。将工具放在工程之外，为编辑服务指定绝对路径：

```sh
VIENTO_GODOT_BIN=/绝对路径/Godot可执行文件 \
VIENTO_WORKSPACE_ROOT=/完整路径/scene2d体验副本 \
npm start -- --no-open
```

打开 **构建与运行** 后，可先切换 **场景预览** 查看已保存的布局，无需启动 Godot。要验证运行行为，切回 **构建任务**，依次检查计划、构建场景，再选择无头测试或窗口预览。窗口预览需要图形会话；无头测试验证运行逻辑。产物是需要对应 Godot 工具执行的生成工程，记录与缓存位于本机应用缓存目录。场景字段、任务取消、诊断和限制见 [构建指南](PROJECT_BUILD.md)。

## 参与开发前的检查

```sh
npm run check -- --app-only
```

这会检查程序语法、版本、接口与临时样例；没有配置原生辅助工具或 Godot 时，相关集成测试会明确跳过。无需为应用检查选择日常作品。原生、浏览器及设备验证按 [测试指南](TESTING.md) 执行；代码和文档维护约定见 [贡献指南](../.github/CONTRIBUTING.md)。
