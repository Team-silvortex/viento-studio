# 0.2.10 版本记录

2026-11-13。本版收拢从二维作者布局到实际玩法的主线：可在视口之外布置世界，用独立相机与 HUD 组织运行画面，通过场景导航和关卡重试连接有限游戏流程；新增可编辑的「晶石庭院」参考工程和减少手填编号的参数辅助。

## 主要变化

- **世界工作平面与逐实例物理回放**：二维编辑取景与运行视口分离，框外对象可查看、选择和布置，支持全部／选择取景及负坐标网格。受限物理回放可按稳定实例 UUID 独立编辑方向和跳跃边沿，切换目标时间轴，保存、迁移并按实例验收。[编辑工作平面](PROJECT_BUILD.md#世界工作平面与运行视口)、[物理输入](SCENE_PHYSICS2D.md)、[实测](test-results/physics-instance-replay/README.md)
- **二维运行主相机**：独立作者文档支持固定中心、实例跟随、偏移、缩放与可选世界边界；设置内提供逻辑构图拖动和组装视口参照。来源变化撤销旧审阅，首次创建采用可恢复的三文件保存；编辑取景与运行相机分别维护。[相机指南](SCENE_CAMERA2D.md)、[构图实测](test-results/scene-camera2d-composer/README.md)、[边界实测](test-results/scene-camera2d-limits/README.md)
- **屏幕 HUD**：内置编辑文本和数值条、有序叠放、九点锚及只属于编辑器的状态样本；Godot 组装只读项目共享状态，随实际视口重新布局。首次保存共同建立正文、登记和场景引用，提供中断恢复。[HUD 指南](SCENE_HUD2D.md)、[实测](test-results/scene-hud2d/README.md)
- **导航与关卡重试**：普通 Godot TXT 起始脚本支持按动作／事件进入另一个组装成员；重试可在目标行为就绪前原子覆盖显式标量初始值。旧访问请求撤销，未列状态与共用执行预算保持，保存和依赖诊断沿既有流程。[导航](SCENE_NAVIGATION.md)、[重试](SCENE_RETRY.md)、[原生与交付实测](test-results/scene-retry/README.md)
- **行为参数辅助**：按名称选入当前场景实例、明确组装中的成员和已保存输入动作，填入前重新核对来源；值仍是普通字符串。官方完整重试脚本另可显式补齐三项原始默认值，保留已有参数；可选接口变化只撤销相关辅助，普通编辑和原文审阅保持。[操作指南](SCENE_BEHAVIORS.md#按名称填写成员实例与输入动作)、[名称参考实测](test-results/scene-behavior-reference-picker/README.md)、[空白两场景试点](test-results/scene-retry-parameters/README.md)
- **晶石庭院参考游戏**：普通作者工程组合四场景、三枚晶体、计分、实体门、伤害、胜负与不同成员重试，配合相机／HUD／声音／动画；原窗口和标准生成 ZIP 离线分别验证。33份文档、9份原创素材及12份文档模板可复制编辑、整体迁移或选择式导入；素材采用 CC0-1.0，其余作者文本按仓库 GPL v3。[示范工程](../examples/topdown-collect/README.md)、[验证与交付](test-results/topdown-collect/README.md)

## 数据、架构与交付

Godot 执行描述符及新项目组装的最外层生成器为 **0.46.0**。相机、世界边界、HUD、重试使用独立生成层；既有媒体、物理和动画按内容选择各自内部协议，不随应用版本统一升级。执行指纹变化后，需要显式重建冻结工程，不自动改写作者作品或已安装程序。

本版新增的独立相机文档支持 v1／显式边界 v2，HUD 文档为 v1，逐实例物理输入为 v2；相机与 HUD 首次创建分别使用事务日志 v13／v14。它们只在明确操作时写入，不进行批量旧作品迁移。语义合同、宿主保存／恢复、编辑视图与 Godot 适配分别维护，为未来 ns-nova 原生替换保留语义、稳定身份和验收样例。

功能图谱收拢 **198 功能／600 实现／815 绑定／3260 评分单元／163 工作流**。本次11项功能改为源码交付，对应39个交付评分由2改为3；其他评分和旧证据保持，源码收录不表示设备安装验收。[图谱](FUNCTION_ATLAS.md)、[0.5.0 产品门槛](MILESTONE_0.5.0.md)、[后续路线](ROADMAP.md)

各开发专题保留升版前的原版本、失败／跳过、日志和来源摘要；升版后的实际检查单独见 [0.2.10 发布检查](test-results/release-0.2.10/README.md)。参考游戏与空白两场景试点覆盖不同范围，不合并声称已经从空白完成整款游戏。暂停／鼠标菜单、同场景即时重启、跨启动存档、长期游玩、字体随包与独立游戏程序发行尚未完成；Bevy 未与本轮 Godot 能力对等，也没有新增 Android 或其他系统验收。

`.viento.zip` 保存作者工程和素材，`.viento-build.zip` 交付可审查的生成后端工程，接收方仍需兼容工具。本机已安装 Linux AppImage 仍为 **0.2.0**；本次提交推送发布源码，不构建或更新安装程序。
