# 当前能力与平台

截至 **2026-10-28**，Viento Studio 的主线是 **设定 → 设定投影 → 场景实现 → 组装打包 → 工程交付**。本页区分源码交付、开发阶段验证和实际安装验收；详细操作从[文档中心](README.md)进入，开发顺序见[路线图](ROADMAP.md)。

原文、登记、素材是作者数据；解析结果、预览和生成工程是派生数据。专用编辑区沿 **检查 → 完整审阅 → 应用草稿 → 普通保存** 交接；首次创建等跨文件动作另走有界事务。临时预览、选择、取景和运行观察不直接取得保存权限。

二维实例目前限 1–128 个，v3 的组织组不改变绝对坐标或叠放顺序。配方显式生成独立 Scene2D 后进入运行链，后续编辑生成场景不会自动回写配方。物理空间图展示作者几何，不是物理模拟器；空间手势只修改声明几何；角色滑动由 Godot 运行层求解。

## 平台接入

表中“源码已接入”说明有对应实现；“实测”限定具体宿主和任务。未验收的平台不据此判定为不能运行，也不承接其他平台的通过结论。

| 宿主／执行通道 | 已接入范围 | 已有证据与当前边界 |
| --- | --- | --- |
| Linux 本地编辑服务＋Chrome | 当前作者编辑、World、资源、场景、组装及构建工作台 | 事件位置面板有三语／两尺寸独立组件及受控本地服务的构建对话框接线证据；合成快照不替代完整应用或引擎验收。其他作者流程按各专题范围验证 |
| Tauri 桌面 | 作品库、本地工程、原生归档、媒体和 Web 编辑宿主 | 0.2.0 AppImage 已验编辑媒体、导出、配方到 Godot 无头链及动画试算；0.2.1–0.2.6 的源码增量尚未随新安装程序验收 |
| Windows／macOS | 桌面构建与宿主源码 | 系统选择器、解码、生命周期、签名及具体安装产物须在目标系统验收；Linux 证据不能替代 |
| Android 预览宿主 | 私有工程目录、正文／字段编辑、三语、起始工程、完整 v2／v3 包导入导出 | 类型配置界面、World、媒体插入播放、选择式导出、场景编辑与引擎执行尚未接入移动宿主；完整包仍保留相关作者数据。设备覆盖按[移动端说明](../mobile/README.md)与专题记录区分 |
| Godot 4 | 图片、GDScript 行为、项目组装、声音、动画和当前二维物理；无头及独立窗口；另有 3D 导出 | 本版观察链与媒体请求有真实无头专题证据；回执不代表扬声器验收。3D 粒子使用独立图形／软件图形证据，不能用 dummy 渲染器证明像素或物理 GPU |
| Bevy 数据通道 | 无图二维场景、可信运行程序、有限方向回放和实例采样 | 与 Godot 分别验收；未接图片、声音、窗口、物理或 GPU 通道 |
| Bevy Rust 作者通道 | 独立 Cargo 源工程、就绪／固定步自身位置回调、参数与事件 | 已有实际 Cargo／Chrome／工程交付证据；需固定工具链与缓存，未接有限输入回放、图形窗口和热更新 |
| ns-nova／yalivia／Nuislang | 原生接入目标 | 尚无产品执行适配器或原生 GUI 验收；后续按真实可调用工具链接入 |

只读浏览服务不开放语义写入、项目配置或引擎执行；资源包仅开放清单与导出。Web/Tauri 的共享资源准备测试、移动纯模块测试都不等于系统窗口或设备验收。执行通道的详细能力见[中间层](BACKEND_MIDDLEWARE.md)与[Bevy](BEVY_BACKEND.md)。

## 尚未实现的目标

调度时钟、请求状态及事件位置已经可观察，但当前仍是有限会话；完整语义账本、身份去重与 FIFO 未裁剪，累计预算也不因轮转或场景切换重置。持续运行、宿主实时准入和其他跨尾部引用需要独立合同。

近期优先补足二维玩法与交付闭环：更完整的物理模型与运行观察、明确的跨编辑区工作流、更多从空白工程开始的实测及独立发行产物。Bevy 的新能力需要逐项适配验证；3D 的模型素材、空间变换层级、行为及组装也单独推进。

LSP 标准接口、跨视图统一撤销、Live Build、内嵌运行视口、原生 ns-nova GUI／执行器及 GPU 计算通道仍在路线内。当前粒子参数能表现雨雪，但没有积雪、粒子碰撞或完整天气玩法系统。进入条件见[路线图](ROADMAP.md)。
