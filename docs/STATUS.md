## 验证边界

0.0.6 发布前检查通过：版本与 API 契约一致，283 个 JavaScript 文件通过语法检查，应用回归 **1108 通过、0 失败、0 跳过**，包含真实 Godot 和原生辅助程序集成；完整桌面宿主编译与 Rust 测试 **48 通过、0 失败、1 项大作品往返测试按配置忽略**。桌面与移动资源准备也通过，完整记录见 [0.0.6 发布验证](test-results/release-0.0.6/results.json)。

功能专项 [场景预览记录](test-results/scene-preview/results.json) 验证了 Linux 源码：

- 启用真实 Godot、原生归档和移动存储辅助程序的应用检查 **1108 通过、0 失败、0 跳过**；283 个 JavaScript 文件通过语法检查。
- Chrome 154 在未配置 Godot 的临时工程中验证真实图片像素、中心位置、尺寸、投影继承／覆盖、着色叠放与对象命中。覆盖缩放、平移、网格、键盘选项卡、中英日和 390px 窄屏。
- 快速切换的旧响应不能覆盖新场景；无效场景移除旧画面并显示字段诊断。预览操作保持作者文件原字节；从预览编辑并保存后自动读取新快照，保留场景 UUID 和原文格式。
- 后台专项 **17 项通过**，覆盖图片冻结与摘要校验、本机鉴权、缓存上限、过期释放、断连取消及服务退出。预览 UI／画布专项 **17 项**、父选项卡 **4 项**通过，验证资源生命周期、焦点、缩放保留和构建任务隔离。
- 原生归档／移动存储辅助程序编译及最终桌面资源准备通过。此轮没有修改 Rust 源码，也未重复完整 Rust 单元测试；此前 **48 通过、0 失败、1 忽略** 的记录保留在 [投影创建验证](test-results/oc-projections/results.json)。

这一轮没有重新制作安装包，没有验收 Tauri 窗口或 Android 设备，也未重复图形运行窗口验证。预览是保存状态的静态布局，不验证移动或运行输入。正常 Godot 窗口、任务取消与宿主退出回收的此前证据保留在 [构建工作台记录](test-results/build-workbench/results.json)；场景编辑、迁移及原文保真见 [场景编辑记录](test-results/scene-edit/results.json)。历次报告保持原样，执行方法见 [测试指南](TESTING.md)。

## 尚未实现的目标

- Nuislang 原生构建与执行、ns-nova / yalivia 接入、GUI 迁到 ns-nova；Bevy 等第二副引擎仍是候选。
- 通用工程类型插件、任意行为／状态机、Live Build、嵌入运行视口、GPU 计算与资源通道。
- 独立游戏程序导出、构建会话的宿主崩溃恢复、跨重启任务身份恢复。
- 通用混合 ChangeSet、永久撤销历史，以及 Android 上尚未接入的上述桌面能力。

Windows / macOS 的构建配置已有，原生交互仍需目标系统验收；Android 真机、更多 WebView 和厂商环境也仍待覆盖。完整设计与验收门槛见 [路线](ROADMAP.md) 和 [原生方向 ADR](adr/0008-native-nuis-and-bootstrap-runtime.md)。
