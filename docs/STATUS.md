Scene2D 来源模型已在 JS 层与构建计划分离，预览字段可定位到当前原文；旧 v1 计划、快照和生成文件保持兼容。来源范围随正文修订校验，过期或近似位置不误选，未保存草稿保留。Scene2D v2 已区分实例 `instanceId` 与定义 `objectId`，同一 OC／投影可在场景中重复使用；选择、位置历史、来源和 Godot 运行事件均按实例区分。新场景默认 v2，旧 v1 保留原规则，点击“启用场景实例”后经预览保存才升级。实例仍限 1–128 个，新增 v3 支持 0–128 个组织分组、最多 16 层；大纲可折叠、检索、整组选择及定位组名原文。分组不改变绝对坐标或叠放顺序，无行为场景仍使用 plan/runtime v2。单场景未保存原文已可显式预览，支持返回编辑器修改后重开；错误保留最近有效画面，来源定位核对当前草稿摘要。预览不改登记或构建输入，草稿限 128 KiB UTF-8。当前源码模式可显式“调整草稿布局”，经完整正文审阅后仅把坐标补丁应用回文本草稿，再由主编辑器普通保存；取消保留原草稿，过期画面不能回写。保存态表单／事务布局保存仍要求先结束文本草稿。单文件片段组合已有独立与已登记模式的只读 CLI，配方复用普通文档和资源包流程，并可预览已保存或当前未保存原文、定位真实贡献来源，详见下段；单实例覆盖可检查后应用到当前原文草稿；共享模板编辑、删除覆盖／恢复继承、空间变换、多文件提交、跨视图统一撤销、剧本事件和规模扩展待实现。

Studio 规则继续向 Rust 核心迁移，位置历史、dirty 判断、保存阶段与请求归属已迁移；源码布局的严格 JSON、v1／v2／v3 身份／坐标／分组检查和仅数值 token 补丁也已下沉，原文前后仍限 128 KiB。源码回写不再依赖浏览器 YAML 模块，相关 HTTP 包目录入口已撤除。后端 JSON/CST、完整场景语义、投影继承、资源与关系、回执正文／摘要校验、HTTP 访问与实际事务、大部分 World／构建规划仍在 JS；可选核心能力声明保持旧布局操作兼容，不增加场景格式或自动迁移工程。近期行为后端优先 GDScript 和 Rust，C# 暂缓；当前只接入显式注册的 GDScript Node 参数／信号绑定，不支持任意方法 RPC、热更新或跨引擎源码互译。

0.0.8 的[场景片段组合](SCENE_COMPOSITION.md)接受一份严格 JSON 配方：片段内演员和逻辑组可多次放置，每次显式指定生成 UUID、局部覆盖与位置偏移。Rust 原生与 WASM 共用无状态组合规则，输出普通 Scene2D v3；Node CLI 可只读独立文件或工程已登记文档并向 stdout 输出，不修改作品。来源 bundle 用原始字节 SHA-256 绑定配方，提供 JSON Pointer 贡献来源，不提供精确回写范围。配方使用现有类型和 `.json` 正文登记，普通编辑／保存允许未完成内容，完整备份保留原文；选择式资源包从当前模板与覆盖派生定义／图片闭包，并在读包和导入时复验。派生依赖不自动写入元数据，无效配方不能展开或选择式打包，删除顶层格式标记回归普通 JSON。生成场景通过已有 `scene.create` 单独登记后进入原构建流程，编辑生成场景不会更新 recipe。场景预览已接已保存和未保存配方，只在内存展开并复用 v3 模型；字段贡献分别定位到模板、局部覆盖、偏移和身份映射，继承来源继续指向投影。预览不返回构建快照或布局保存权限，配方从构建／运行选择中分离。当前源码配方可编辑六类单实例局部覆盖：按稳定放置／局部键生成保留原字节的 Rust 补丁，经完整预览检查后应用到同一原文草稿，持久化继续普通保存；未改字段保留继承，取消或过期提案不改草稿。共享模板编辑、删除覆盖／恢复继承、画布拖动回写、嵌套片段、跨文件引用及生成结果双向同步尚未接入。

这些能力的范围各自受契约约束：批量属性提交只接受现有对象的属性修改，不能混合创建、关系和资源动作；Scene2D 的几何预览仍只处理角色引用、图片和布局；构建可另行挂载明确声明的行为，原有方向键及 `idle` / `moving` 状态并未成为通用状态机。游戏起始模板本身用于设计文档，可执行内容还需显式场景声明。

执行中间层现有两条受限实现：Godot 4 与 Bevy 0.19.1 无头运行程序。Bevy 只声明无图场景的构建、方向输入和移动逻辑，图片、GDScript／Rust 作者行为、窗口、离屏、内嵌视口和 GPU 均未接入；不支持的计划由能力检查拒绝。宿主选择一个可信后端，界面根据描述符开放操作，没有引擎选择下拉框。HTTP 不接收后端模块、工具或输出路径。作者 Scene2D 格式和无行为 plan／runtime 1／2 保持，Godot 显式行为使用 plan／runtime 3。工具与生成产物不进入作者迁移包，范围见 [Bevy 指南](BEVY_BACKEND.md)。

0.0.8 源码另在既有构建工作台接入[运行对象观察](RUNTIME_OBJECTS.md)：纯 JS 观察核心从已验证冻结计划取身份／来源，独立于原始事件环保存启动／结束坐标和状态变化。Godot／Bevy 沿用已有 plan／runtime 1／2／3；状态事件不含坐标时明确标出位置样本过期。工作台仅检索和返回作者声明；宿主 inspect 只查询本服务当前运行任务，不占执行槽、不查工具、不暴露引擎 Entity 或方法。当前另接[有限控制回放](RUNTIME_CONTROL.md)：无行为 plan 1／2 可以有限方向程序按固定步骤报告完整位置；普通观察 DTO 不变，控制任务附完成步数和明确步骤样本。连续实时采样、反射、RPC 与运行修改未接入。
