# 0.1.8 版本记录

2026-10-23。本版收录 0.1.7 之后的七项动画与脚本增量：自然完成与片段衔接、状态表生成及重编辑、参数绑定修复、脚本使用位置、静态状态图和事件载荷条件，贯通表格编辑、普通 TXT 保存、行为绑定、Godot 执行与工程交付。

## 变更

- **动画自然完成与片段衔接**：非循环动画自然到达末端后，在安全点通知当前访问的有效订阅。循环、停止和手动定位不冒充完成；新命令、离场或结束请求使旧通知失效。新增普通衔接脚本和独立完成面板，分别查看完成、投递及动画／片段／行为来源。
- **从状态表生成脚本**：配置初始状态、事件转换与自然完成转换，生成普通 Godot TXT 脚本，再用已有片段选择器填写各状态的参数。Rust 维护有界规则，独立发射器生成源码，表格只负责输入；运行仍使用现有命令与完成记录。
- **重新编辑状态表脚本**：新脚本携带同文件版本声明；已知声明和完整源码精确匹配时，可从当前原文草稿重新打开表格。修改经前后源码审阅、应用草稿和普通 Save 回到同一 TXT；保留 BOM 与统一换行，手改源码继续使用普通文本编辑。
- **脚本参数接口与绑定修复**：行为编辑器根据严格版本化状态表源码显示缺失、未声明等参数差异。可显式补齐参数，或将旧参数更名为缺失目标并保留值；来源改变使旧审阅失效。普通保存才写入绑定，其他参数不自动删除或迁移。
- **脚本使用位置与绑定导航**：从已保存 TXT 查询当前工程的登记引用和实际行为绑定，查看精确原文并跳转主编辑器。导航沿用未保存草稿确认，可接续参数修复、保存与刷新查询；查询与导航保持只读。
- **静态状态图与字段定位**：新建和重编辑共用只读状态图，显示初始状态、孤立节点、自循环、反向边及全部转换，可定位对应字段。展开、选择和定位保留源码审阅；无效表格清除旧图，过期按钮不能操作新会话。
- **按事件载荷选择转换**：事件可附加布尔、数字或字符串条件，支持相等／不等及数值大小比较。类型不符或条件不满足时处理事件但不转换、不发动画命令，其他订阅继续运行。条件控件、图中说明、生成源码、重编辑和普通保存全部接通；精确数值按 IEEE 754 字节生成，避免 GDScript 小数字面量舍入偏差。

上述界面提供中、英、日说明。操作见[场景动画](SCENE_ANIMATION.md)、[行为参数与脚本使用位置](SCENE_BEHAVIORS.md)和[项目事件](PROJECT_EVENTS.md)。

## 格式与兼容

当前 **22 模块／43 项声明能力**；图谱为 **139 功能／421 实现／619 绑定／2476 评分单元／102 工作流**。Godot 适配器更新为 **0.16.0**；Bevy 数据适配器 **0.3.0**、Rust 适配器与模板 **0.2.0** 保持。产品升版不提高已有成熟度评分。

新构建的含动画项目使用 **protocol 7／清单 8**，接通独立自然完成记录与订阅；旧 protocol 1–6 继续按各自精确形状读取，无动画项目仍生成 protocol 4。已有作者动画 schema、稳定编号、元数据关系和素材不因产品升版迁移。应用标识与用户数据路径保持。

共享 Rust 主协议保持第 1 版，状态表与事件条件通过各自可选能力标记接入；没有核心能力时，不以 JavaScript 回退规则替代。运行协议、后端实现、表格语义与界面分别维护。

状态表源码声明的 schemaVersion 仍为 1：无条件表使用 `godot-gdscript-v1`，含条件表使用 `godot-gdscript-v2`。旧 v1 发射器保持原字节；v1 不接受条件，v2 要求至少一条条件，显式移除最后条件可重新生成 v1。v2 完整 TXT 限 64 KiB，计入 BOM 与 CRLF；旧 v1 保持原 128 KiB 限制。旧无声明脚本、未知版本、混合换行及附加或手改源码不会被表格自动覆盖。

## 交付边界

本次提交推送 **0.1.8 源码**，不制作安装包或更新本机安装，不创建版本标签或 GitHub Release。最近保留的 [Linux 安装验收](test-results/native-installed-0.1.1/README.md)仍为 0.1.1 工作树 AppImage；本次没有新增安装、Android、其他桌面设备或硬件图形画面验收。

动画仍是 Scene2D 视觉层，每场景共享一根播放头；状态表没有运行时所有权仲裁。逻辑状态只代表播放请求已受理，是否实际执行应查命令记录；完成投递的“已处理”只代表同步回调成功。静态图不执行脚本、不展示实时运行状态，也不提供图上连线编辑或持久布局。

条件只比较单个事件标量，不包含复合表达式、共享状态条件或多分支优先级；同一状态的同名事件仍只有一条转换。内嵌 NUL 在 Rust 与声明中保留，但 Godot 字符串载荷不能据此宣称完整往返，限制和原生探针见[条件验收](test-results/animation-state-conditions/README.md#保留修复与限制)。

参数发现当前只覆盖严格版本化状态表源码；使用位置只覆盖当前工程的已登记引用与保存态绑定，不推断动态或未登记依赖。没有全工程自动迁移、片段删除保护或任意 GDScript／Rust 逆向解析；查询无结果不证明可安全删除。

骨骼、混合、缓动、关键帧事件、运行时播放速率、3D 与 Bevy 动画继续独立推进。动画场景暂不接有限控制重放／用例运行；Godot 工程 ZIP 仍需对应工具，尚非独立游戏发行程序。
