# 0.1.4 版本记录

2026-10-15。本版收录 0.1.3 之后的首次声音创建、多场景项目组装、运行中切换、会话共享状态、事件发布订阅与行为声音控制。创作表单、通用规则、运行观察和 Godot 执行继续通过独立接口衔接，作者数据和素材保留原存储位置。

## 变更

- **首次创建场景声音**：在已保存 Scene2D 的“场景声音设置”选择已登记 WAV、配置 1–16 条音轨，完整审阅后以可恢复事务保存声音正文、声音登记及场景关联。每轨可选定时播放或由行为触发，允许混用；切换轨道、方式和语言保留输入。已有音轨继续使用独立字段编辑与普通保存。
- **项目级多场景组装**：维护 1–32 个已保存场景及启动入口，共同冻结资源，检查、构建并交付一个 Godot 工程。组装来源、成员来源和生成文件可独立检查；工程 ZIP 包含核验后的脚本、声音及其他依赖。
- **运行中切换场景**：行为可请求进入已冻结的成员场景；离场停止声音并撤销旧访问接口，运行观察保留访问顺序和对应来源。同一场景再次进入获得新访问身份。
- **会话共享状态**：行为可读写或删除有界的布尔、数字和字符串值，结果跨场景保留，每次新运行从空状态开始。独立三语只读面板显示键值、修订和最后写入来源；这不是跨启动存档。
- **项目事件发布与订阅**：当前场景的行为明确订阅并按序处理标量消息，支持回调继续发布，队列排空后再切场景。离场撤销订阅，新运行清空；独立记录分别定位发布与订阅来源。
- **行为声音控制**：普通行为或事件回调可请求播放／停止当前场景已声明的音轨，与定时提示共存，也支持没有定时提示的声音声明。独立执行记录分别定位控制行为和音轨原文；受理请求与实际执行分开，失败／取消不伪造未执行回执。
- **内置起始内容与交付**：场景切换、共享状态、项目事件和事件声音提供中英日起始说明，经普通草稿审阅、保存及绑定后使用；导出的 Godot 工程保留同一项目运行接口。

当前为 **21 模块、40 项声明能力**；图谱为 **127 功能、352 实现、534 绑定、2136 评分单元、90 条工作流**。Godot 适配器为 **0.11.0**，当前生成项目协议为 **4**，纯读取器保留显式旧协议 1／2／3；旧单场景协议保持。Bevy 数据适配器仍为 **0.3.0**，独立 Bevy Rust 适配器及模板仍为 **0.2.0**。应用版本和后端身份分别管理。

使用方法见[场景声音](SCENE_AUDIO.md)、[项目组装与切换](PROJECT_ASSEMBLY.md)、[共享状态](PROJECT_SHARED_STATE.md)、[项目事件](PROJECT_EVENTS.md)及[行为声音控制](PROJECT_AUDIO_CONTROLS.md)。

## 交付边界

本次提交推送 **0.1.4 源码**，不制作安装包、更新本机安装、创建版本标签或 GitHub Release。新增功能需从源码启动或自行构建。最近的 [Linux 实际安装验收](test-results/native-installed-0.1.1/README.md)仍为 **0.1.1 工作树 AppImage**；资源准备不等于新版 Tauri、Android 或其他系统设备验收。

项目组装目前由 Godot 实现，Bevy 两条通道均未接项目组装与声音。声音限非空间 PCM16 WAV；空间声源、混音总线、暂停／跳转、实时音量、自然结束观察和已有音轨结构表单仍待接入。共享状态不跨启动持久化，项目事件不提供留存重放、网络或异步回调。有限无头验证仍为两步，不代表任意作者脚本的完整时间模拟。

既有本机构建遇后端身份或生成指纹变化需重新构建，旧独立 ZIP 保留自己的运行代码。空提示需要新版共享核心，旧安装仍可能拒绝。工程 ZIP 仍需对应 Godot 工具，尚非独立游戏发行程序；Nuislang／ns-nova 原生执行、外部 IDE／LSP 和嵌入运行视口继续独立推进。
