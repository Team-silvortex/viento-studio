# 0.2.5 版本记录

2026-10-26。本版补齐二维角色与平台之间的玩法链路：自由平面角色发布移动碰撞事件，重力角色主动下穿单向平台、随水平平台往返，平台端点再驱动作者事件、动画与声音。同时分离原始观察留存和运行生命周期，将事件、状态与媒体的累计准入收拢到共用预算层，为后续持续交互打基础。

## 变更

- **依赖安全修复**：包含 0.2.4 发布后的提交 `6d9560ff`，将 Ajv 的间接依赖 `fast-uri` 从 **3.1.8** 更新至 **3.1.9**，处理该包的四项 URI 公告。锁文件、定向回归及当时的 npm 审计见[修复记录](test-results/security-fast-uri-2026-10-25/README.md)；该结果不代表全部依赖或 Rust 审计归零。
- **自由平面移动碰撞**：现有“Godot / 角色移动碰撞”脚本可用于停止或滑动响应的自由平面角色，无需启用重力。复用本步实际求解结果，按实例发布阻挡开始／结束；停止输入后仍贴墙也可能结束，含义仍是移动阻挡变化，不是几何分离。
- **单向平台主动下穿**：新增“Godot / 单向平台下穿”普通脚本。按键边沿提交请求，下一物理步复核真实支撑，只为对应角色与平台临时建立碰撞例外，完全分离后恢复。其他角色保持承重，持续按住不会连续穿透下一层。
- **水平往返平台**：静态矩形可配置终点水平偏移和速度，并与单向碰撞组合。重力角色依据实际支撑随平台移动，起跳、下穿和离开后停止承载；输入、重力与承载位移共用原有求解。表单沿检查、审阅、应用草稿和普通保存生效。
- **平台端点作者事件**：新增“Godot / 平台端点事件”脚本，将起点／终点通知转换为具名项目事件，供既有动画和声音订阅。每端点每步至多通知一次，初始位于起点不通知；多圈跨越合并并按首次抵达顺序派发。载荷为平台实例 UUID，行为来源独立保留。
- **明确原始记录留存**：交互会话保留最近 128 条原始摘要，工作台显示日志与事件的累计／保留／移出数量。启动记录移出后仍能正确判断生命周期；失败和取消保留已接收证据。完整业务账本与原始尾部窗口分开维护，有限 smoke 测试仍保留原有完整记录。
- **共用有限执行预算**：事件注册、发布、投递和载荷字节，以及状态修改、音频、动画请求共用原子准入。多维成本全部验证后才提交，拒绝不部分扣费；业务序号、动画预留戳、当前队列与存储容量保持独立。重复订阅、同值写入及删除不存在的键不消耗累计额度。

编辑入口和留存说明提供中、英、日文案。脚本仍是可检查、修改与迁移的普通 TXT，需要显式保存、关联和绑定，不自动推断实例或媒体关系。操作见[二维物理指南](SCENE_PHYSICS2D.md)及[项目构建](PROJECT_BUILD.md)。

## 格式、分层与兼容

Studio 仍为 **23 模块／45 项声明能力**；功能图谱为 **175 功能／527 实现／737 绑定／2948 评分单元／139 工作流**。发布归属调整不提高成熟度评分。

物理作者格式增加 **schema 5** 的可选 `platformMotion`，仅显式启用并保存时升级；关闭运动删除相应字段但不降低格式。Rust／WASM 通过独立 `inspectPlatformMotion` 操作验证，保持原主 ABI 与旧格式路径。项目运行协议仍按实际内容选择 **4／7／10／11**，物理观察协议和本轮各行为局部端口均为 **1**。

Godot 执行适配器与新项目预算生成层为 **0.32.0**。二维能力依次使用独立的 0.28 自由平面碰撞、0.29 下穿、0.30 水平平台及 0.31 端点层；0.32 将共用预算接入已知项目运行模板。旧生成器与既有 GDScript 源冻结，单场景原产物保持；新 helper、策略、端口与包装按严格库存验证并随源工程交付。层间复用实际求解结果，不重复推进物理。

适配器指纹变化后，旧冻结构建仍可读取；在当前 Studio 中运行或按当前适配器核对交付需重建。已导出的独立 Godot 工程继续依赖对应工具。应用标识 `io.viento.studio`、用户数据路径、作者素材及稳定身份保持。

## 交付边界

本版为 **0.2.5 源码交付**，提交并推送主分支；本次不制作或安装新程序，不创建版本标签或 GitHub Release。本机 Linux x86_64 AppImage 仍为 **0.2.0**，原[安装验收](test-results/native-installed-0.2.0/README.md)保持其原范围。

运行仍是**有限会话**：事件累计 128 次发布，状态修改 1024 次，音频／动画请求各 256 次，另有累计注册／投递／字节、场景访问 64 次、协议帧 4096 条、进程输出与时限。flush、场景切换和 deferred 不重置预算；业务序号不循环，语义账本未裁剪。原始记录轮转不会解除执行上限，宿主调度周期和有界因果记录合同仍待完成。

平台当前只支持水平往返和重力角色承载；持续几何接触、垂直／旋转／多段平台、侧向推挤、动态刚体、力／冲量、材质、关节、3D 与 Bevy 物理仍待接入。下穿按真实形状分离恢复，不保证固定耗时；水平平台自身不自动避障。旧直接位置控制回放继续拒绝含物理工程。

`.viento-build.zip` 交付可审查、可搬迁的后端源工程，运行需要相应工具。独立游戏发行程序、其他桌面系统、Android 设备与新桌面安装验收不在本版范围内。
