# ADR 0003：单属性命令与原文保存

日期：2026-09-27。状态：采用于 V-M2 第一条纵切。软件保持 0.0.2，沿用 experimental semantic v1 与原作品格式。

## 操作与权威来源

本阶段接通 `property.set`，修改一个已登记、已知文档类型的已映射标量。GUI、CLI 和 HTTP 调用相同的命令规划器与 Node 执行器。`object.create`、`relation.add`、`resource.bind` 尚未接入语义命令；这些动作涉及多记录修改，需要后续事务设计。

World / Object 的 `readOnly: true` 表示查询得到的投影不能直接持久化或整体 PATCH。属性命令重新解析权威原文并修改对应范围，没有新增可写属性表。宿主通过 `semanticCommands: ["property.set"]` 单独声明执行能力；命令目录只是契约，不是授权。

请求必须提供 `mode`、World ID、World / Object / source 三个 revision、对象 ID、属性路径、字符串形式的值和 `actorRef`。字段序号仅在给定源版本中有效。拒绝未知字段、额外参数、缺失版本、未登记身份、未知类型及不符合类型的值；没有 `force` 参数。`actorRef` 是调用者声明的来源标签，不是经过认证的用户身份或持久审计记录。

`preparePropertySet` 共用原有字段解析及序列化实现。修改后重新解析，核对字段数量、标签、类型、分组、其他字段值及未映射项数量。改变文档结构或其他字段的值必须回到源码编辑器处理。未修改范围逐字节保留；修改范围使用该格式的标量写法，可能改变引号或 YAML 块字符串形式。

## 预览、应用与回执

`preview` 不创建锁、登记、缓存或其他作品文件，返回原文片段前后对比、预计的新 revision、`proposed` ChangeSet 和带版本约束的反向命令。`apply` 重新执行全部校验；无需保存预览令牌，但不能省略版本条件。GUI 要求先预览再应用，CLI / HTTP 可以显式提交完整的 `apply` 请求。

ChangeSet 仍只是提案。保存回执是独立对象，`status` 为 `applied` 或 `unchanged`，不会把提案状态改成持久提交。反向命令必须再次预览 / 应用并通过版本校验；它恢复属性值，不承诺恢复修改范围之前的引号、转义或排版。没有历史日志、跨重启撤销栈、持久幂等键或通用 ChangeSet 执行器。

无变化时不替换原文件、不改变其修改时间。写入完成后返回已经计算的源版本和世界 revision，之后的索引或视图读取失败不改变保存成功这一事实。GUI 区分“原文已保存”和“预览更新失败”；请求断开或超时则保留草稿，要求刷新核对，不自动重试写入。

## 并发与文件发布边界

Node 采用既有文档队列，再取得跨进程登记锁。取得锁后重新读取完整投影；现有文档编辑 API 的非创建保存也使用该锁，创建操作继续使用原有登记锁。CLI 与 HTTP 使用相同锁顺序。另一个进程正在持锁时返回可重试的 `409 world_write_busy`；同一进程中串行等待，重新校验后拒绝旧 revision。

只发布一个文件：在同一目录写临时文件、同步内容、保留权限，发布前再次核对世界与原文字节及路径边界，最后原子替换目标。校验失败清理临时文件，保留原文。所有写入方若遵守此锁，不会用旧版本覆盖新版本。

外部编辑器并不遵守应用锁。发布前可检测已观察到的外部修改，包括相同大小、保留 mtime 的修改；最后校验与替换之间仍存在外部写入竞争窗口。因此本阶段**不是多文件事务、Build 一致性快照或断电恢复承诺**。不把预测 revision 当作全工程原子提交代次。V-M3 仍须处理提交日志、恢复和各类写入方协调。

## 宿主与界面

`POST /api/world/commands` 沿用文档写 API 的令牌校验、JSON 类型 / 1 MiB 请求上限、限流和桌面会话隔离，预览请求也走同样的鉴权。CLI 必须明确指定根目录，并从 JSON 文件或 stdin 读取完整请求。

GUI 仅在支持命令的编辑宿主显示修改操作。有未保存文档、正在新建或忙碌时不能发起属性修改。属性草稿参与离开确认、浏览器卸载和原生窗口关闭检查；执行期间阻止重复操作。冲突保留输入并使旧预览失效，不自动把字段序号套到新版本。成功后更新文档索引和世界视图；失效的已保存编辑基线会清除。

Android 与纯静态浏览宿主尚不声明 World 命令能力。没有新安装包或真机语义写入验收。验证记录见 [V-M2](../test-results/world-m2/results.json)。
