# ADR 0001：新产品版本与旧数据兼容

日期：2026-09-27。状态：采用。范围：0.0.1 迁移交接，不启用下一代 v4 数据格式。

## 决定

规范仓库为 `Team-silvortex/viento-studio`，沿用前身的 Git 历史。npm / Cargo 产品名为 `viento-studio`，界面名为 Viento Studio。官方示范作品仍叫 Epic of Viento Line，其 ID、示范定义、文件名和历史记录不因产品更名而修改。

产品版本从 `0.0.1` 开始，使用三段数字，允许多位 minor / patch，不允许前导零。`version.mjs --next` 对数字版本只增加 patch；历史 `b.X.Y` 解析与进位规则保留。版本解析同时覆盖源码归档脚本。

保留应用标识 `io.viento.studio`、既有配置 / 数据目录、作品 UUID、文档 / 素材 ID 和关系。软件版本不决定作品格式。v1 按旧目录读取；v2 继续使用 `design-data` / `data-template`；v3 使用 `documents` / `templates`；新建作品仍为 v3，不自动把旧作品升级或移动。

## 安装版本与切换

| 平台 | 0.0.1 策略 | 从 0.4.6 切换 |
| --- | --- | --- |
| Android | `versionName=0.0.1`；`versionCode=1000001` | 同应用 ID、同签名覆盖安装；编号大于旧 4006 |
| macOS | 显示版本 0.0.1；`CFBundleVersion=1.0.1` | 保留数据目录，替换应用；签名 / 公证另行验收 |
| Windows NSIS | 版本 0.0.1；显式 `allowDowngrades=true` | 手动运行安装器允许跨版本线切换；安装行为须在 Windows 验收 |
| Linux AppImage | 文件及显示版本 0.0.1 | 关闭旧程序后运行新版，同一作品目录可直接打开 |
| Linux deb | 包版本 0.0.1 | 包管理器视为降级；备份后显式允许所选本地包降级安装 |

新数字版本 `M.m.p` 的 Android 编号为 `(M + 1) × 1000000 + m × 1000 + p`，macOS 构建编号为 `(M + 1).m.p`。这是安装计数器的一个新纪元；产品显示版本没有增加大版本。minor / patch 须小于 1000，Android 编号不得超过 2100000000，预检拒绝溢出及重复区间。Android 不使用按构建次数自动加一，保证相同源码配置得到相同编号。

仓库未启用自动更新服务。较小的产品版本不应被当作旧版自动更新提示的保证。不要为切换版本卸载并清除作品数据；Android 签名不一致时先用旧应用导出完整项目，在可恢复条件下另行安装。Windows / macOS 的本次配置检查不等于设备验收。

## 格式与兼容夹具

[冻结样例](../../scripts/tests/fixtures/predecessor/)是依据前身 `bda0d3c4e5d8f90b4fff4914317809630c933583` 契约建立的合成数据，不包含日常作品。测试读取固定字节，不使用当前的注册器生成预期数据。

| 作品格式 | 桌面 / Node | Android | 本次约束 |
| --- | --- | --- | --- |
| v1 | 读取、索引、完整包导入导出 | 未登记旧包不支持直接导入 | 公共清单可在归档时物化；作品身份与正文保留 |
| v2 | 保留旧目录与所有登记 | 已登记包支持导入、编辑与导出 | UUID、归属、素材绑定、兼容标记不变 |
| v3 | 保留类型、模板与扩展 | 已登记包支持；界面功能按宿主能力表 | 不把软件 0.0.1 解释成 workspace v1 |

[兼容测试](../../scripts/tests/predecessor-compatibility.test.mjs)覆盖索引不改原文、BOM / CRLF / 空格、Node 导出 → Rust 恢复 → Rust 再导出 → 第二次恢复。移动端 v2 / v3 双向编辑另由 [原生互通测试](../../scripts/tests/mobile-archive.test.mjs)覆盖。没有提供原生工具时须保留跳过标记，不能报告完整兼容验收。

## 回退

应用源码和作品分别回退。原作品、旧安装物及迁移前快照保留；新版本编辑仍使用旧数据格式，可用完整项目包在前身恢复。新写入应单独备份，不能用旧快照覆盖新内容。未来 v4 / 语义内核需新的 ADR、格式拒绝写入机制和双向兼容矩阵，不由本次交接默许启用。
