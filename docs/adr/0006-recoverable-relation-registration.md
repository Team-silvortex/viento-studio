# ADR 0006：保真追加对象关系

日期：2026-10-02。状态：采用于 V-M2 / V-M3 关系纵切，沿用 experimental semantic v1 和 workspace v2 / v3。

## 决策

`relation.add` 连接两个已登记且原文可用的对象。请求固定 World 和两端对象的 revision；可移植 Core 检查身份、重复、自连接与归属环，生成单登记修改计划及预计投影。先支持 `part-of` 和 `references`，不引入第二份关系数据库。未知文档类型可以连接，因为不修改其正文或解析结果。

登记采用 JSON token 插入，拒绝重复键等歧义结构。保留全部现有字节，包括无法用 JavaScript Number 精确表达的未知数字；不把整份登记 parse/stringify 后回写。语义 revision 与字节冲突检测分离：格式变化可保留，发布时必须仍匹配计划的原始字节摘要。

扩展 [ADR 0004](0004-recoverable-source-changesets.md) 和 [ADR 0005](0005-recoverable-object-creation.md)：version 3 意图只允许修改一个既有文档登记，并携带新增关系与其余登记的规范化摘要。恢复重新执行同一插入函数，验证 after 镜像未夹带其他修改，验证登记身份、路径、剩余图及两种图状态，再验证全部目标文件，最后才恢复。登记目录内只允许忽略该意图推导出的单个临时文件；公共读取仍受屏障约束。

GUI、CLI、HTTP 共用命令。GUI 必须预览后保存，编辑输入使预览失效；冲突或恢复保留草稿，不能自动重试。归属会影响双方导航，保存后请求完整文档索引重建；派生预览失败不改变已保存事实。`undoMode: none`，没有伪装成用户撤销的崩溃回退。

## 兼容与边界

不改变文档／作品／归档 Schema。新执行器继续处理 version 1 / 2 意图；旧执行器拒绝 version 3 并保持读取屏障。完成后的共享归属按已有归档协议在桌面和移动存储间往返，移动端尚未接入此语义命令。

本决策不提供任意登记编辑、混合关系／属性批次、关系删除、自定义关系写入或资源绑定。其余登记摘要保护恢复时的目标和图结构，不构成长期历史或 Build 快照。外部写入者的最后时刻竞争仍不属于锁协议保证。

使用、恢复规则和验证见 [对象关系](../WORLD_RELATIONS.md)。
