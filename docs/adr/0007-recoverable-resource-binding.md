# ADR 0007：沿用素材身份的可恢复绑定

日期：2026-10-02。状态：采用于 0.0.4 之后的 V-M2 / V-M3 资源绑定纵切。

## 决策

`resource.bind` 在旧文档登记中追加 `{ assetId, role }`，投影映射为 ResourceBinding。对象、素材身份和权威来源保持原样。用途由工程作者定义；唯一性为对象、资源与用途的组合，不预设人物肖像、背景音乐等领域规则。

固定 World、Object 和 Resource 登记的 revision。可移植 Core 不执行 I/O，宿主在登记锁内重新读取和规划后发布。离线资源仍可绑定：绑定是设计关联，文件内容的可执行性和摘要验证属于未来 ResourceLock / Build。禁止把现有 `present-unverified` 状态表述为已验证的资源。

复用关系追加的 JSON token 编辑器，保证未知字段、大整数及既有绑定的字节保真。新的 intent version 4 只允许单登记追加一个绑定，记录前后镜像、绑定内容及其余登记摘要。恢复重新执行受限插入，拒绝重复绑定或夹带的任意修改，核对资源登记后才执行原有提交／回退协议。现有 version 1 / 2 / 3 恢复和公共读取屏障不变。

GUI 提供资源、用途、预览、保存和取消，遵守对象面板现有草稿保护及单次提交约束。全量索引刷新确保原编辑器和资源引用视图使用新登记。保存成功与索引刷新成功分别报告。

## 兼容与边界

作品仍为 workspace v2 / v3，semantic Schema v1；意图编号不表示作品格式升级。完成的绑定不需要新归档格式。旧程序拒绝未完成的 version 4 意图，必须先由支持该协议的执行器恢复。Android 原生存储可以迁移这些绑定，但本轮不开放 Android 语义写入。

不包含资源导入、正文媒体嵌入、解绑／替换、混合事务、长期幂等历史或 Build 快照。其余登记使用语义摘要，被修改登记使用准确字节摘要。应用锁不能消除外部程序在最后校验与发布之间的竞争。

操作与验证：[资源绑定](../WORLD_RESOURCES.md)。前序协议：[ADR 0004](0004-recoverable-source-changesets.md)、[ADR 0006](0006-recoverable-relation-registration.md)。
