# 0.2.4 版本记录

2026-10-25。本版将二维物理从碰撞编辑推进到角色玩法闭环：观察实际移动与阻挡、配置重力和跳跃、使用静态单向平台，再通过普通作者脚本将运动与碰撞事件接入动画和声音。物理声明、运行观察、事件发布与媒体控制分别维护。

## 变更

- **物理运行观察**：项目无头测试及窗口截图测试记录有界角色物理步，查看请求／实际位移、碰撞位置和法线，按实例、访问与步骤筛选，并返回双方冻结声明。观察只读，不改变作者文件或既有运行对象位置语义。
- **角色重力与跳跃**：在现有物理字段编辑器中选择重力与跳跃，配置重力、起跳速度和最大下落速度。角色沿水平移动，着地后按键边沿起跳；长按和空中再次按键不会连续起跳，关闭模式后恢复自由平面控制。
- **起跳／落地作者事件**：新增普通脚本 **Godot / 角色起跳与落地**，从实际接受起跳和首次／再次着地取得通知。**Godot / 项目事件播放声音** 可订阅任意具名项目事件并按实例筛选；动画继续使用已有状态表或事件片段脚本。
- **静态单向平台**：静态矩形可显式选择单向碰撞，角色从下方穿过、从上方承重；容差为 1–64，默认 1。编辑沿检查、完整审阅、应用草稿和普通保存执行；关闭单向设置不自动降低作者格式。
- **角色移动碰撞事件**：新增 **Godot / 角色移动碰撞**，对启用重力／跳跃的角色按每步移动阻挡集合发布开始／结束；同一步去重、结束先于开始。载荷是对方实例 UUID，自身身份保留在发布来源，可显式筛选对方实例。停止向墙移动也可能结束本步阻挡，因此此接口不等于持续几何接触或分离通知。

新增作者入口和观察提供中、英、日文案，普通 TXT 仍需保存、登记、引用和明确配置参数。角色、脚本、动画与音轨使用独立稳定身份，不从同一 OC 定义推断实例归属。步骤与参数见[二维物理指南](SCENE_PHYSICS2D.md)。

## 格式、分层与兼容

当前仍为 **23 模块／45 项声明能力**；功能图谱为 **169 功能／511 实现／721 绑定／2884 评分单元／133 工作流**。五项功能各有实现与验证证据，发布归属调整不提高成熟度评分。

物理作者格式增加 **schema 3** 的角色 `characterMotion` 和 **schema 4** 的静态矩形 `oneWay`。新运动要求滑动响应；旧文档不自动迁移，仅显式启用并保存新设置时升级相应格式。关闭可选功能删除相应字段但保留格式，原无关字节、空间偏移和尺寸保持。Rust/WASM 通过独立可选 `inspectMotion`／`inspectOneWay` 操作检查新格式，旧 schema 1／2 操作和主 ABI 保持。物理子计划仍为 v1。

Godot 执行适配器为 **0.27.0**。新物理构建通过独立 **0.23.0** 观察层接入 `physics.observe2d`；实际角色运动使用 **0.24.0** 运动层和 **0.25.0** 运动事件层；实际单向平台增加 **0.26.0** 包装；含运动角色的构建增加 **0.27.0** 移动碰撞事件层。旧生成器和无相应字段的分支继续保持。运行求解只执行一次，事件端口读取实际结果，不依赖有界测试观察流；场景退出撤销旧访问连接，不合成结束通知。

独立物理观察协议 `VIENTO_PHYSICS2D` 为 **1**，项目运行协议仍按既有动画内容选择 **4／7／10／11**。两种角色事件端口均为版本 **1**，通过普通作者绑定发布既有标量项目事件；不扫描任意脚本文本推断计划能力。生成脚本、参数和库存随后端工程交付，静态平台与角色运动能力按实际声明要求；两个 Bevy 通道明确拒绝尚未接入的物理能力。

执行适配器指纹变化后，旧冻结构建仍可读取；在当前 Studio 中运行或按当前适配器核对交付需重建。已导出的独立 Godot 工程继续依赖对应工具。应用标识 `io.viento.studio`、用户数据目录、既有作者素材和稳定身份保持。

## 交付边界

本版为 **0.2.4 源码交付**，提交并推送主分支；本次不制作或安装新程序，不创建版本标签或 GitHub Release。本机 Linux x86_64 AppImage 仍为 **0.2.0**，其[安装验收](test-results/native-installed-0.2.0/README.md)保留原范围。Android 配置同步为 `versionCode` **1002004**，macOS 构建编号为 **1.2.4**，不代表已生成或验收这些安装产物。

物理仍限 Godot 二维项目组装。自由平面角色不获得运动或移动碰撞事件端口；持续几何接触、移动／旋转平台、主动向下穿透、斜坡策略、跳跃缓冲、动态刚体、力／冲量、材质、关节、3D 和 Bevy 物理仍待接入。单向面固定朝上，有限容差不构成任意大单步的防穿透保证。

旧直接位置控制回放继续拒绝含物理工程。`.viento-build.zip` 交付可审查的后端源工程，运行需相应工具；独立游戏发行程序、其他桌面系统、Android 设备与新桌面安装验收不在本版范围内。
