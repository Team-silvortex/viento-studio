# 0.2.8 版本记录

2026-11-04。本版继续完善二维项目从作者编辑、场景组装到运行验收与工程交付的工作流，补充 Bevy 项目入口用例与有序验收组、Godot 垂直往返平台及事件控制平台启停，并整理工程结构和使用文档。

## 主要变化

- **Bevy 项目入口验收**：在受限的 Bevy 数据项目中，可针对冻结入口场景编辑、保存、载入并运行位置／状态用例，也可将已保存用例组成有序验收组，逐份查看结果和独立报告。用例与验收组绑定场景身份，可通过资源包连同必要依赖迁移；项目、构建、快照与入口的身份分别核对。断言不符会记录为验收未通过并继续余项，执行错误或取消则停止后续用例。支持工作台及受限 CLI；不因此支持其他成员场景切换、项目键盘映射、图形窗口或 Bevy 物理。[Bevy 指南](BEVY_BACKEND.md#验收项目入口)、[验收组指南](RUNTIME_CASE_SUITES.md)、[开发阶段实测](test-results/bevy-project-runtime-suite/README.md)
- **垂直往返平台**：二维物理作者 schema 6 新增静态矩形平台的有符号 Y 偏移和速度，正值向下、负值向上；Rust/WASM 负责声明检查，编辑器保留检查、审阅、应用草稿和普通保存流程。Godot 可让有真实支撑的重力角色随平台升降，平台或乘客受阻时暂停该平台并在障碍移除后继续，也可使用已有平台端点事件。垂直支撑探测与物理观察中的移动扫掠分开；两者的结果不必相同。水平轨迹沿用原有语义，作者文档不会自动迁移。[物理指南](SCENE_PHYSICS2D.md#配置垂直往返平台)、[开发阶段实测](test-results/scene-physics2d-platform-vertical/README.md)
- **事件控制平台启停**：普通 **Godot / 事件控制平台** TXT 可绑定水平或垂直移动平台，通过初始状态及项目事件请求暂停／恢复；现有触发区脚本可发布进入与离开事件，组合成压力板。平台每个接收步只接受首个有效请求，在下一物理步应用；起始脚本在竞争时保留最新意图并重试，不保证多控制者公平。读取的开关状态不代表平台一定发生位移。脚本、引用、绑定和参数需明确保存。[配置指南](SCENE_PHYSICS2D.md#用事件控制平台启停)、[开发阶段实测](test-results/scene-physics2d-platform-control/README.md)
- **结构和维护**：更新[工程布局](WORKSPACE_LAYOUT.md)、[快速开始](GETTING_STARTED.md)及相关工作流文档，区分源码、作者数据、缓存和交付物。清理工具补充 Bevy 默认构建缓存位置；本机整理记录及数据保留范围见[磁盘整理记录](test-results/disk-cleanup-2026-11-04/README.md)。

## 数据与交付边界

原文、素材和登记仍是作者数据。用例、验收组、平台物理声明与脚本均需显式保存；运行记录及生成工程属于派生数据。资源包按已选项目及依赖迁移，选择组装本身不保证包含可选验收用例或验收组，导出前应核对预览。生成的 `.viento-build.zip` 需要对应的引擎或可信运行工具，不是独立游戏发行包；作者脚本执行不构成沙箱。

Godot 执行适配器为 **0.40.0**：垂直能力由 0.39.0 内层处理，实际含移动平台的项目再叠加 0.40.0 启停层；未声明移动平台的生成分支保持原有内容。Bevy 数据后端继续只支持其受限场景及入口工作流，Bevy Rust 作者行为、其他平台与物理能力各自判断。旧托管构建受执行适配器指纹保护，运行或交付前需按提示重新生成，不应改写摘要绕过检查。

升版前的完整应用检查记录为 8,995 项：8,344 通过、651 项条件跳过、0 失败；这是[开发阶段记录](test-results/scene-physics2d-platform-control/full-check.log)，不将跳过计为真实引擎验收。各专题保留其原始时点和实际环境。本版升版后重新完成相同规模的完整检查，另有 Rust 核心 420/420、版本与源码归档 8/8、真实 Godot 13/13 和 Bevy 2/2 通过；[本版发布检查](test-results/release-0.2.8/README.md)记录具体命令、工具和范围。源码提交不会自动更新安装；本机已安装版本仍为 **0.2.0**，不据此推定其他平台、Android 或实体设备的验收结果。
