# 0.1.9 版本记录

2026-10-23。本版收录0.1.8之后的六项动画增量：有序事件分支、退出快照、逐次进入记录、控制器回看、共享状态条件和组合条件，贯通表格编辑、完整源码审阅、普通保存、Godot运行与只读观察。

## 变更

- **有序事件分支**：显式开启按顺序匹配后，同一状态的同名事件可以声明多条转换，依次尝试条件并选择首个匹配；可选无条件兜底只能位于同组最后。排序保留输入与行身份，并撤销旧源码审阅。未匹配不转换，匹配后的动画请求失败不继续尝试兜底。
- **退出前状态快照**：在场景切换、结束或错误清理前采样实际控制器字段，区分同片段不同状态、同脚本不同绑定。冻结计划提供作者来源，可返回绑定或脚本原文；未采集时保留空缺，不以命令回执推测状态。
- **逐次成功进入记录**：保留初始进入、事件／完成切换和同状态重启，同帧同片段也不合并。独立生成包装层保留作者源码与返回值，严格核对真实字段和已接受请求；进入记录、已执行命令、自然完成与末态分别显示。
- **控制器历史回看**：按场景访问与绑定选择一次进入，用上一条／下一条查看完整顺序，对照后续执行回执和本次访问末态。平铺过滤不裁剪控制器历史，追加记录和语言切换保留选择，来源导航沿用草稿与会话保护。
- **项目共享状态条件**：事件转换可比较项目键值，与事件载荷条件混用。读取发生在事件实际交付时，写入状态不会自行触发转换；键缺失或类型不符时，包括不等比较也不匹配。编辑器分别保存载荷／共享状态输入，完整审阅后仍走普通TXT保存。
- **全部／任一满足组合**：每个事件转换可组合1–8项标量条件，混用事件载荷与共享状态，按作者顺序短路求值。支持添加、删除、排序、新建与重新编辑；单条件与组分别保存草稿缓冲，模式切换明确提示，空组和嵌套组被拒绝。
- **大规模表单刷新修复**：一次同步刷新复用声明与能力快照，缓存固定DOM引用并避免逐行反复读取整张表；审阅与事件仍实时重验。独立规模回归中，逐步新增至64条转换约1.70秒完成，64×8条件的计数及异常释放检查通过。

界面同步提供中、英、日说明，窄屏输入与焦点保持已有验证。操作见[场景动画](SCENE_ANIMATION.md)，共享状态与事件的原有契约分别见[项目共享状态](PROJECT_SHARED_STATE.md)和[项目事件](PROJECT_EVENTS.md)。

## 格式与兼容

当前 **22模块／43项声明能力**；图谱为 **145功能／437实现／642绑定／2568评分单元／108工作流**。Godot适配器更新为 **0.18.0**；Bevy数据适配器 **0.3.0**、Rust适配器与模板 **0.2.0**保持。产品升版不修改已有成熟度评分。

新构建的严格状态控制器项目使用 **protocol 9／库存10**，包含逐次进入与终止采样；普通动画项目保持protocol 7，无动画项目保持protocol 4。旧协议1–8及旧库存继续按各自精确形状读取，快照阶段的protocol 8／Godot0.17.0／库存9证据保留当时条件。新严格控制器项目的非资源、资源、清单和ZIP预算同步贯通，支持最多1024份非资源文件与128份资源。

共享Rust主协议保持第1版，有序分支、共享状态和组合条件各由独立可选标记接入。旧入口继续拒绝新形状，不以JavaScript规则替代缺失核心。状态表源码声明的schemaVersion仍为1，生成器按实际特征选择：

| 生成器 | 使用范围 |
| --- | --- |
| `godot-gdscript-v1` | 无条件且未显式开启有序模式 |
| `godot-gdscript-v2` | 单一事件载荷条件，未使用以下新特征 |
| `godot-gdscript-v3` | 显式有序事件模式，未使用共享状态或组合条件 |
| `godot-gdscript-v4` | 含共享状态条件，未使用组合条件 |
| `godot-gdscript-v5` | 含至少一组全部／任一满足条件，允许混用单条件及有序分支 |

完整声明仍限32KiB，组合条件按每个数字叶子预留32字节；v2–v5完整源码含BOM与CRLF限64KiB，旧v1保持128KiB。单项组仍使用v5；显式移除新特征后才按剩余声明选择对应生成器。0.1.8的v1/v2发射器字节保持，加入v5时也保留v3/v4发射器；旧脚本不会因打开或产品升版自动改写。重编辑仍要求已知封套与完整源码精确匹配，手写或修改后的任意脚本继续使用普通文本编辑。

应用标识、用户数据路径、作者文档格式、稳定编号、元数据关系和素材保持。本次没有批量作品迁移。

## 交付边界

本次提交推送 **0.1.9源码**，不制作安装包、不更新本机安装、不创建版本标签或GitHub Release。最近保留的[Linux安装验收](test-results/native-installed-0.1.1/README.md)仍为0.1.1工作树AppImage；本次没有新增安装、Android、其他桌面设备或硬件图形画面验收。

动画仍使用每场景共享播放头。进入记录表示播放请求已接受，执行情况须查看独立命令账本；所选进入之后的回执不构成逐转换因果区间，末态来自该次访问最终采样。当前没有触发原因、逐叶求值轨迹、被拒分支、实时状态图、断点或视觉重播。

组合条件限平面标量组，没有嵌套表达式或状态变化自动转换。Godot字符串NUL的既有限制继续适用。每实例播放头、所有权仲裁、混合、骨骼、3D和Bevy动画仍分别推进。Godot工程ZIP需要对应工具，尚非独立游戏发行程序。
