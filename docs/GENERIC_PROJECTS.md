# 通用项目与起始模板

工程以自己的文档类型和源文件组织内容，不要求固定的角色、技能或游戏字段。当前开发源码的新建工程使用 v3 格式，可选择空白、游戏、文学、戏剧或软件设计起始模板；默认空白，正文目录为空。类型和文档模板复制进工程后独立维护。

开始操作见 [项目工作流](PROJECT_WORKFLOW.md)，模板包及类型字段的完整说明见 [工程与文档模板](PROJECT_TEMPLATES.md)。本文描述格式和内容归属；具体平台与交付形式的差异见 [当前状态](STATUS.md)。

## 新项目的目录

| 位置 | 保存内容 |
| --- | --- |
| `workspace.json` | 工程身份、名称、格式版本、目录及文档类型声明 |
| `documents/` | 作者正文，按需创建子目录 |
| `templates/` | 本工程的文档起始模板 |
| `metadata/documents/` | 文档 UUID、类型、源路径、关系及素材绑定 |
| `metadata/assets/` | 素材 UUID、位置、分类与内容指纹 |
| `assets/` | 默认素材存储，可通过本机配置绑定外置目录 |
| `.viento/` | 兼容标记、本机状态、迁移记录与派生缓存；各子项有不同迁移规则 |

作品文件夹与应用安装、源码仓库分开。目录树、清单约束、外置素材和备份规则以 [作品库布局](WORKSPACE_LAYOUT.md) 为准；系统默认位置见 [本机数据目录](LOCAL_DATA_STORAGE.md)。不要把整个 `.viento/` 当成缓存删除，只有相应的派生缓存可重建。

正文是标题、属性、背景和章节的权威来源，元数据不再复制一份可编辑正文。简短背景可写在角色自身文档中；长篇或共享背景通过文档 UUID 建立 `part-of` 归属，可在 **世界与对象 → 添加关系 → 归属** 中登记。具体语义见 [文档模型](OC_DOCUMENT_MODEL.md)。

同一工程格式供桌面和 Android 使用。移动端可按所选或导入的定义使用类型与模板，但并未提供桌面的全部配置、素材或构建界面。

## 项目决定文档类型

`workspace.json` 中的 `documentTypes` 决定新建菜单、分类、建议目录、解析规则和模板。已登记文档由其 `documentType` 选择类型；保存到其他正文子目录，不会让解析器重新猜测类型。

在顶部或设置中打开 **项目类型与模板**，可以新增类型、编辑模板、预览解析结果，再保存应用。也可手工编辑清单和工程内模板后重新打开工程。类型定义示例、命名限制与安全保存规则集中在 [项目类型的声明](PROJECT_TEMPLATES.md#项目类型的声明)。

类型标识与显示名称分开；不同工程可复用相同标识和模板文件名，互不影响。模板改变之后的新建正文，解析规则改变同类型文档的展示，二者都不批量改写已保存原文。指定模板丢失时会提示，不从内置 OC 模板补写内容。

默认目录只是新建建议，不执行源文件迁移。手工移动已有文档需要同步登记位置，保留原 UUID；当前类型设置不提供隐式重命名或批量移动。

## 迁移与旧项目

新建 v3 工程使用 `documents/` 和 `templates/`；旧 v1、v2 项目继续读取 `design-data/` 和 `data-template/`。打开或复制旧项目不自动改变格式、搬动正文或素材。没有显式类型的历史 v2/v3 项目仍保留旧 OC 默认定义；兼容模板包与旧宿主调用规则见 [版本与兼容](PROJECT_TEMPLATES.md#来源摘要版本与兼容)。

完整 `.viento.zip` 项目包携带项目清单、正文、模板、元数据、素材及兼容标记，排除缓存和本机绝对路径绑定。外置素材收进包内的相对素材存储；导入逐文件校验并保留工程、文档和素材 ID。只复用选定内容时使用 [资源包](RESOURCE_PACKAGES.md)。

已有项目采用共享类型定义需要先检查，再显式应用；不会改写正文、关系或资源绑定。命令和拒绝条件见 [校验与已有项目采用定义](PROJECT_TEMPLATES.md#校验与已有项目采用定义)。

## 解析与展示规则

通用解析器按原文的字段、标题、段落、列表、表格、代码及 JSON / YAML 值生成布局。`structured` 面向字段与正文，`prose` 面向叙事和对白；`parserOptions` 定义解析边界，`fieldGroups` 按精确字段名分组，未选内容继续保留。详见 [解析与展示规则](PROJECT_TEMPLATES.md#解析与展示规则)。

编辑器、模板预览、媒体草稿预览及文档分享使用共同的解析与布局入口，缓存不能覆盖作者源文。实验场景同样保存为普通已登记 JSON 文档，由独立 [构建适配器](PROJECT_BUILD.md) 消费明确声明的场景语义，不改变工程持久格式，也不会把任意故事或设计文档自动转换为游戏。
