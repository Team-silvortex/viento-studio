# 场景实例行为

本页按 **脚本草稿与保存 → 场景绑定 → 参数／信号编辑 → 构建运行 → 来源诊断** 说明行为工作流。当前源码版本为 **0.2.4**，本机安装仍为 **0.2.0**；当前平台与交付范围见[状态页](STATUS.md)。历次增量前言移至[历史归档](history/scene-behaviors-2026-10-25.md)，旧专题仍按实际执行条件阅读。

行为声明是独立 JSON，源码是普通已登记 TXT，不写入 OC 定义或场景演员字段。Scene2D v2／v3 的显式绑定生成 plan／runtime 3；无行为场景沿原 plan／runtime 1／2。Godot/GDScript 与 Bevy/Rust 使用相同的绑定编辑流程、各自的执行适配器；作者选择后端不会切换宿主或转换源码。World、workspace 与 Scene2D 作者格式不因此升级。

## 内置脚本创建

在主编辑器操作栏点击 **新建脚本**，选择 Godot 的 **空 Node**／**参数与信号示例**／**Godot / 场景切换**／**Godot / 共享状态**／**Godot / 项目事件**／**Godot / 事件声音**／**Godot / 事件动画片段**／**Godot / 动画完成后衔接片段**，或 **Bevy Rust / 空行为**／**Bevy Rust / 参数与信号示例**／**Bevy Rust / 固定步移动**，再选择工程已有文档类型，以及正文目录内的 `.txt` 路径。界面显示完整脚本预览；点击 **创建脚本草稿** 后，在内置原文编辑器继续编写，再使用普通保存创建文件并登记。工程无需专门的 `script` 类型，也无需安装执行工具链才能创建。已有文件与路径冲突由普通保存检查；保存失败保留草稿供修改或重试。

[Godot / 动画状态表](SCENE_ANIMATION.md#从状态表生成动画脚本)使用独立表格生成并审阅源码；[Godot / 物理触发区](SCENE_PHYSICS2D.md#从接触到项目事件和动画)将真实接触转换为项目事件。两者仍需普通保存、场景绑定和参数配置。当前另提供 **Godot / 角色起跳与落地** 和 **Godot / 项目事件播放声音**，通过真实角色事件及可选实例过滤连接动画／音轨；具体配置见[角色运动事件](SCENE_PHYSICS2D.md#用角色运动事件驱动动画与声音)。

**Godot / 事件声音** 订阅 `sound`，使用已声明的 `track_id` 请求播放／停止；需明确填写当前成员场景的音轨 UUID，也可通过[音轨选入文本参数](#将音轨编号填入行为参数)辅助填写；脚本创建不会自动生成音轨或行为绑定。普通单场景运行会安全返回。请求受理、实际执行记录和双来源导航见[行为驱动场景声音](PROJECT_AUDIO_CONTROLS.md)。

**Godot / 事件动画片段** 仅订阅文本参数 `event_name`（默认 `checkpoint`），收到事件后选择 `clip_id` 并从头播放；空 `clip_id` 表示完整动画，空事件名禁用订阅。脚本就绪时不发布事件或主动播放；整场景保持默认自动播放，显式逐实例范围保持初始停止，退出时主动取消订阅；旧项目缺少片段选择端口时不执行。创建 TXT 不自动增加参数或绑定，行为参数仍需显式审阅和普通保存。片段可按名称[选入编号](#将动画片段编号填入行为参数)，实际执行与回执边界见[事件动画用法](SCENE_ANIMATION.md#用项目事件触发动画片段)。

**Godot / 动画完成后衔接片段** 新增普通文本参数 `finished_clip_id` 和 `next_clip_id`，分别选择要等待和随后播放的片段；空值代表完整动画。可复用片段名称选择，匹配自然完成后才提交选择／播放命令，详见[自然完成用法](SCENE_ANIMATION.md#动画自然完成与片段衔接)。

**Godot / 项目事件** 订阅 `checkpoint` 并延迟发布一个值，接收后写入 `last_event`；只在项目运行生效，离开场景后自动撤销订阅。同步回调、顺序与预算见[项目事件](PROJECT_EVENTS.md)。

**Godot / 共享状态** 在每次实例就绪时累加 `visit_count`；只在项目运行中生效，新运行清空。读写、删除、预算和只读观察见[共享状态](PROJECT_SHARED_STATE.md)。

**Godot / 场景切换** 使用 `target_scene_id` 字符串参数请求进入组装成员，单场景运行时不切换；流程和有限运行边界见[项目内切换](PROJECT_ASSEMBLY.md#运行中切换场景)。

Godot 空 Node 只有 `extends Node`；Rust 空行为提供返回 `Ok(())` 的 `ready` 函数。两种参数与信号示例都使用下文的 `checkpoint`、`amount` 和 `arrived`，源码仍分别属于各自后端。Rust 固定步移动示例显式注册回调，以 `velocity_x`、`velocity_y` 两个数字参数移动自身实例，并发送 `moved` 信号。起始内容只填充新草稿，不覆盖工程文档类型模板，也不添加参数、信号映射或场景关系。保存成功后，回到 **构建与运行**，使用[首次添加行为](#从场景首次添加行为)选择这份已登记 TXT；场景已有行为文档时，转到[管理已有行为](#管理已有行为)添加脚本引用。新增绑定仍以空参数和空信号映射开始，需要时再用行为编辑器明确配置。

当前有未保存草稿、正在创建其他文档或宿主忙碌时，先完成当前操作；取消脚本窗口不会写文件。预览与创建草稿之间若文档会话、正文目录或类型目录变化，需重新打开核对。此入口属于独立 `org.viento.scripts` 模块，提供 `authoring.script`。创建和编辑只生成普通草稿，不解析或执行 GDScript／Rust，也不提供 LSP 或自动发现导出属性。Rust 编译由独立 Bevy Rust 执行适配器在显式构建／运行时负责。

[脚本创建专题](test-results/script-authoring/)记录三语、390px 界面、普通保存、首次行为、参数／信号、真实 Godot 与生成工程异地导入验证；安装包与移动实机范围另行验收。

## 原文缩进编辑

脚本、JSON、YAML 和其他普通原文共用源码工具条。选择 **制表符**、**2 个空格** 或 **4 个空格**，用 **增加缩进／减少缩进** 调整当前行或选中多行；快捷键为 **Ctrl / ⌘ + ]／[**。选区恰好停在下一行开头时，不会连带修改该行。新载入正文会按已有首处缩进给出初始选项，随后可手动选择；它只是文本辅助，不判断脚本语言或自动格式化。

Tab 仍用于焦点导航。中文／日文输入法组合期间、保存或加载期间和弹窗打开时，缩进不改原文。支持原生文本事务的浏览器可沿用撤销／重做；无法执行时保留原文并提示。按钮只修改普通草稿，随后仍用普通保存；BOM 保持开头，换行沿用现有保真序列化规则（未改的前后行保持原字节，改动区域采用原首个换行风格）。这是正文模块的通用能力，不增加执行后端、LSP 或语法高亮。

## 原文位置与跳转

源码编辑区底部显示当前逻辑行、列和总行数。点击 **跳转到行**，或在正文中按 **Ctrl / ⌘ + G**，输入行号后跳到该行开头；自动折行不增加逻辑行数，定位会按实际排版将目标滚动到可见位置。取消或 Esc 返回原选区和滚动位置。

行列从 1 开始，列按 UTF-16 码元计数（多数 Emoji 占两列），开头的 BOM 不计入列号。反向选区显示光标活动端的位置。此操作只移动光标，不改正文、未保存状态或撤销记录；输入法组合、保存／加载、只读状态或其他弹窗期间不执行跳转。窗口打开后若正文或编辑会话变化，需关闭后重新定位。

当前提供位置状态和跳转窗口，保留原生软换行；侧边逐行行号、语法高亮和 LSP 另行接入；构建诊断的只读上下文见下节。中英日与 390px 实测、普通保存兼容记录见[原文导航专题](test-results/source-navigation/)。

## 原文诊断上下文

在 **构建与运行 → 构建诊断** 点击 **打开原文** 后，源码旁会保留这一条诊断的说明、来源字段和定位状态；展开 **诊断详情** 可查看原始代码与消息。准确位置经过原文版本核对，自动折行后的目标也会滚动到可见区域。旧版本、大致位置和缺少位置分别说明，不猜测范围。

正文修改后显示“尚未重新检查”；撤销回原文字节也不视为问题已解决。需要显式重新检查并打开新的诊断，才能替换这份结果。关闭提示、切换语言和查看详情不改正文或保存；切换文档或退出源码编辑会清除当前提示。窄屏下内容区可滚动，同时保留源码编辑区域。

这是正文模块的单条只读诊断上下文，不是持续后台检查或工程问题总表。诊断数据、界面、来源核对及执行后端分别维护，未增加 LSP 或脚本运行权限。实测及边界见[诊断导航专题](test-results/source-diagnostics/)。

## 内置行为编辑

已登记且格式有效的绑定文档现在可以通过独立的 **编辑场景行为** 面板修改。它属于 `org.viento.scene-behaviors`，声明能力为 `scene.authoring.behaviors`。界面、可移植原文补丁、只读依赖核对和文档草稿宿主分别接入，不需要启动 Godot 或外部 IDE。

1. 打开已有绑定 JSON，进入编辑并切到源码模式，再打开 **编辑场景行为**。
2. 选择现有绑定，或新增／移除绑定。已有 `bindingId` 保持稳定；新增绑定获得独立 UUID，同一个场景实例可以有多份行为，至少保留一条绑定。目标实例来自该场景，脚本选项来自本文档已经引用的已登记 TXT。
3. 添加、修改或删除参数，明确选择文本、数字或布尔类型；信号映射分别填写脚本信号名和对外事件名。字段名、类型和数量继续遵守下文的原有协议。
4. 点击 **检查行为修改**，核对修改路径和前后完整原文。候选同时检查已登记的场景、角色定义、脚本与引用关系；具体脚本导出类型和真实信号仍在构建／运行时由后端检查。
5. 点击 **应用到原文草稿** 后，再使用主编辑器普通保存。关闭或取消面板不会应用尚未确认的表单；切换文档、改变原文／保存基线或依赖后，旧审阅不能继续应用。

编辑表单固定原声明的场景、后端和语言，仍只修改当前原文草稿；首次创建使用下述独立入口。已有声明的元数据关联不由编辑表单增删，新增可选脚本依赖先通过[管理已有行为](#管理已有行为)单独审阅并保存引用。TXT 脚本继续在内置源码编辑器编辑，不解析或执行 GDScript，也不提供 LSP。表单本身不授予执行权限；Rust 行为由下文的独立后端接入，3D 行为及其他执行语言继续分别实现。

可移植 JS 核心复用无第三方浏览器依赖的 JSON 源码索引：JSON.parse 负责语法准入，词元扫描只记录范围、预算和重复键。原文补丁按稳定绑定身份定位。未修改的绑定、BOM、行尾、转义和数值写法保留；同结构修改只替换变化的值。参数或信号集合结构变化时，仅重新排版相应容器；增删绑定仅重建必要分隔符。未知字段、未来版本、重复键或无效声明不会被表单自动清洗，仍可在源码模式修复。候选仅改变内存，普通保存继续负责磁盘修订和外部冲突。

首次编辑专题的核心、宿主、依赖服务、界面和浏览器证据分别保存在[行为编辑专题](test-results/scene-behavior-authoring/summary.json)；[浏览器记录](test-results/scene-behavior-authoring/browser-smoke.json)限定其实际运行环境。该专题用真实 Chrome 和 Godot 验证表单修改、普通保存、两实例运行事件、工程交付下载及异地导入。该专题不包含安装包或 Android 实机验收；现行安装范围以状态页为准。

## 将音轨编号填入行为参数

在 **编辑场景行为** 中提供可选的 **读取场景音轨**。先保存场景声音声明，再打开该场景的行为绑定 JSON：

1. 点击 **读取场景音轨**，查看已保存声音文档的来源。读取不会修改参数或现有审阅。
2. 在任意**文本**参数旁选择音轨，再点击 **填入音轨编号**。仅切换选项不会修改参数；数字和布尔参数不提供该选择器，也不会自动改成文本。
3. 核对参数名及所用脚本的约定，点击 **检查行为修改**，审阅后 **应用到原文草稿**，最后使用普通保存。取消面板不应用本次表单修改。

目录只提供当前场景已声明的稳定音轨 UUID；例如事件声音脚本使用 `track_id`，其他参数须由作者明确决定含义。编辑器不按参数名字推断用途、不解析脚本，也不新增引用关系或跟踪后续音轨删除。所选 UUID 仍是普通字符串，保存后的脚本类型和实际播放由构建／运行独立验证。声音文件尚未保存的改动不会出现在目录中；行为原文可以已有未保存草稿，既有草稿和普通保存基线继续保留。

没有声音关联时显示空目录；关联歧义、声明无效或来源变化时不返回旧选项。宿主未提供这一读取能力时，原有参数编辑仍可使用。目录读取失败保留当前表单和审阅供重试；来源或会话失效后需重新打开。验证范围见[行为音轨选择专题](test-results/scene-behavior-audio-picker/README.md)，不据此推导安装或设备验收。

## 从场景首次添加行为

首次创建从一条绑定开始，可增删绑定，并明确选择 Godot 4／GDScript 或 Bevy／Rust；默认保持 Godot。先保存 Scene2D 场景和准备使用的已登记 TXT 脚本，再进行下列操作：

1. 在 **构建与运行** 中选择已保存的 Scene2D v2／v3，点击 **添加场景行为**，填写新绑定文档的类型与 JSON 路径，选择与 TXT 内容一致的 **行为后端与脚本语言**。
2. 在绑定列表中选择一项，为它指定场景实例和已登记脚本。用 **添加行为绑定／移除选中绑定** 调整清单，至少保留一条，最多 32 条；整份清单最多引用 8 份不同脚本。切换列表保留各项设置，新增项获得独立 `bindingId`，删除一项不会重新分配其他绑定身份。重检和切换语言也保留当前文档及绑定 UUID。
3. 可以给不同实例选择同一脚本，也可以给同一实例添加多份行为。每项初始参数和信号映射均为空，创建后通过独立行为编辑器配置。
4. 点击 **审阅新行为**，核对全部绑定的完整 JSON 和去重后的场景／脚本依赖；任一实例、脚本、身份或数量无效时，整份清单需修正后重新审阅。
5. 点击 **保存行为与关系**。新绑定正文、新绑定登记、原场景登记中的 `behavior` 关联仍由同一次可恢复的三文件事务提交。新登记包含场景和每份所选脚本的 `references` 依赖，重复使用同一脚本只登记一次；场景正文、脚本正文及场景登记中的其他内容保持原样。

场景已经有任意 `behavior` 关联时，首次创建入口拒绝再挂一份。已有绑定应转到 **编辑场景行为** 修改；引入尚未关联的脚本则先走下述独立管理入口。首次创建的三文件事务与已有文档的脚本引用事务分别维护。

修改选项后需要重新审阅。切换后端保留全部绑定身份、实例和脚本选择，但不会转换源码；当前宿主执行器也不会随作者表单切换。World、场景对象或场景原文版本变化时保存拒绝旧预览；发生未完成提交时，先恢复并核对结果。事务冻结必要场景、全部所选脚本和角色定义的只读证据供恢复验证，不把这些证据写回作者文件。创建完成后打开新绑定原文，使用已有行为表单填写带类型参数和信号映射，审阅后应用草稿并普通保存。

可移植 `scene-behavior-create-plan.mjs` 只把已经分配身份的清单规划为现有行为正文，并返回稳定排序的去重脚本身份；格式、绑定和源码数量继续由既有行为校验器准入。它不读取宿主、文件或 DOM，也不分配身份或执行后端。`behavior.create` 继续接受中立后端与语言声明；界面的后端选项不代表脚本语法、参数类型或信号已经通过运行验证，修改后仍需重新检查计划、构建和测试。未登记脚本先通过内置入口创建并普通保存。

首次多绑定清单专题没有增加系统模块、声明能力、作者格式、运行协议或执行后端；后续 Bevy Rust 通道独立增加执行实现，仍复用原作者格式与 protocol 3。已有声明的场景／后端／语言迁移、LSP 和 3D 行为仍分别接入。旧首版证据保留在[首次创建专题](test-results/scene-behavior-creation/)，新增清单操作及其验证范围记录在[多绑定创建专题](test-results/scene-behavior-multi-create/README.md)；各记录不互相替代，也不声明新的安装或设备验收。

## 管理已有行为

此入口用于查看已保存场景的唯一行为文档，并为它补充已登记脚本引用。

1. 先在主编辑器创建或修改 TXT 脚本，并用普通保存完成正文与登记。回到 **构建与运行**，选择已保存的 Scene2D v2／v3，打开 **管理已有行为**。
2. 查看行为文档、已关联脚本及各脚本被绑定使用的情况；在 **新增脚本引用** 中选择尚未关联的 TXT，点击 **审阅新增引用**。
3. 核对目标后点击 **保存引用**。此操作通过既有 `relation.add` 事务，只向行为文档的登记追加 `references`；行为正文、脚本正文、现有绑定与场景登记保持原样。保存后重新读取目录确认结果。
4. 点击 **打开行为原文**，在源码模式进入独立的 **编辑场景行为**，新增绑定或更换绑定脚本，并配置参数／信号。审阅后 **应用到原文草稿**，最后使用主编辑器普通保存。添加引用本身不会创建或更换绑定。

目录只提供已登记、可读的 UTF-8 TXT，单份至多 64 KiB，至多 256 个可用候选；这是选择目录的预算，行为正文仍限制 1–32 条绑定、实际使用至多 8 份脚本。已有 `reference`／`references` 等非 `part-of` 关系均认作显式依赖，只有归属关系的脚本仍需另加引用；已关联但尚未使用的脚本可以保留。

没有 `behavior` 关系时显示空状态，返回构建后使用首次添加入口。多个行为关系、目标缺失、声明与场景不符或依赖无效时停止管理，不猜测目标或自动修复。读取、审阅、保存和打开原文均核对来源及会话；外部修改后须重新读取。保存结果尚未确认时先核对目录，不重复提交；取消本次选择不会撤销已经保存的引用。

此管理区不移除引用、不改场景／后端／语言，也不执行脚本；绑定草稿与普通保存继续由各自编辑模块负责。引用管理沿用既有作者格式与关系事务，不增加运行协议或后端能力。验证与交付范围见[已有行为关联专题](test-results/scene-behavior-links/README.md)，既有专题和安装记录保留原条件。

## 作者文件与登记

三类数据各有稳定 UUID：场景文档、绑定文档和行为源码文档。场景的元数据通过 `kind: "behavior"` 关系明确指向绑定文档；最多选择一份。绑定文档通过普通的非 `part-of` 引用关系，登记其场景和每份源码依赖。正文中的 UUID 与登记边必须一致；示例用已有 `reference` 关系。

绑定文档使用严格 JSON：

```json
{
  "format": "viento-scene-behaviors",
  "schemaVersion": 1,
  "sceneObjectId": "dddddddd-dddd-4ddd-8ddd-dddddddddddd",
  "bindings": [
    {
      "bindingId": "99999999-9999-4999-8999-999999999991",
      "instanceId": "bbbbbbbb-bbbb-4bbb-8bbb-bbbbbbbbbbb1",
      "implementation": {
        "backendId": "org.viento.godot4",
        "language": "gdscript",
        "sourceObjectId": "ffffffff-ffff-4fff-8fff-ffffffffffff"
      },
      "parameters": { "checkpoint": "east", "amount": 40 },
      "events": [ { "signal": "arrived", "event": "checkpoint" } ]
    }
  ]
}
```

每份绑定文档只声明一种后端和语言；`instanceId` 必须属于该场景。重复的 OC 定义允许存在，绑定和事件使用实例 UUID 区分。`bindingId` 在同一文档中唯一，同一个实例可以挂多份具有不同绑定身份的行为。

当前限制：绑定正文 32 KiB，1–32 份绑定，最多 8 份源码；每份源码 64 KiB，合计最多 512 KiB。每份绑定最多 32 个具名参数、8 个信号映射。参数和信号名使用 ASCII 标识符，参数只接受布尔值、有限数字和不超过 4096 个 UTF-16 码元的文本（如多数 Emoji 占两个码元）；整数不能超出 JavaScript 安全整数范围。不支持数组、字典、资源引用、任意 Variant 或隐式类型转换。

普通保存可保留尚未完成的绑定和源码，完整工程包继续保存其原字节。构建和选择式资源包会检查完整声明及依赖，不能用没有登记的文件或本机绝对路径补齐。源码必须是已登记 TXT 文档；无需把 `.gd` 文件或引擎缓存放入作者素材目录。

## Godot 实现与事件

样例源码是普通 TXT 原文，生成时按源码 UUID 原字节复制为 `behaviors/<UUID>.gd`：

```gdscript
extends Node

signal arrived(checkpoint: String, amount: float)
@export var checkpoint: String = "dock"
@export var amount: float = 0.0

func _ready() -> void:
    arrived.emit(checkpoint, amount)
```

适配器检查脚本编译；运行时读取脚本自己的导出属性和信号元数据，先核对类型，设置参数并连接信号，再把独立 Node 加入对应演员节点。行为须能以无参数构造函数创建 Node。参数只能写脚本自身的导出属性，不能借参数接口写 `name`、`script` 等 Node 内建属性；整数参数可赋给浮点导出属性，分数不能赋给整数导出属性。

映射信号最多携带四个明确类型的标量参数。运行事件包含 `protocol: 3`、`event: "behavior"`、`bindingId`、`instanceId`、`objectId`、声明的事件名 `name` 和参数数组 `arguments`。身份来自冻结绑定，信号参数不能改写事件归属。协议读取器检查已知身份、事件别名、标量和生命周期，拒绝在 ready 前或 finished 后发送行为事件。

脚本按当前本机用户权限运行；生成项目和独立进程不是代码沙箱。初次接入保留既有方向键移动测试，不提供跨引擎源码互译、任意方法调用 RPC、热重载或通用状态机。上文的行为编辑表单只修改声明，不扩展运行权限。Godot 执行器只接 GDScript；Bevy Rust 使用下文的独立后端身份。缺少所选语言或能力时拒绝构建，不自动翻译源码。

## Bevy Rust 实现与事件

`org.viento.bevy-rust` 使用既有行为 schema 1 和 plan／runtime 3。TXT 保持作者原文，生成器按源码 UUID 复制到 `src/behaviors/b_<UUID>.rs`（UUID 中的连字符改为下划线），为每份独立绑定调用一次 `ready`：

```rust
use crate::runtime::BehaviorContext;

pub fn ready(ctx: &mut BehaviorContext) -> Result<(), String> {
    let checkpoint = ctx.string("checkpoint")?.to_owned();
    let amount = ctx.number("amount")?;
    ctx.emit("arrived", vec![checkpoint.into(), amount.into()])?;
    Ok(())
}
```

行为表单需要声明文本 `checkpoint`、数字 `amount`，以及 `arrived` 到对外事件名的映射。`ctx.string`、`ctx.number` 和 `ctx.boolean` 返回类型化结果，缺失或类型不符时返回错误；不会从 TXT 自动推导或补齐参数。先把借用字符串转为拥有的值，再向上下文发出信号。`emit` 使用当前绑定的信号映射，事件身份、数量和标量预算继续由现有准入层核对。

当前通道仅支持 Linux 无图行为场景、就绪回调、显式固定步位置操作和有界无头测试；图片、窗口、有限输入回放、热更新及 3D 行为均未声明。原生 Rust 源码在工具链与本机程序中执行，独立进程不是代码沙箱；编辑器不执行这些代码。固定工具链、离线依赖、临时编译回收及 Cargo 源工程交付见[Bevy 配置指南](BEVY_BACKEND.md#配置与缓存)，首轮就绪回调证据见[独立记录](test-results/bevy-rust-behaviors/README.md)，固定步证据见下节。


## Bevy Rust 固定步行为

适配器与模板 `0.2.0` 增加显式固定步回调，沿用行为 schema 1 和 plan／runtime 3。**新建脚本 → Bevy Rust / 固定步移动** 提供以下 TXT 起始内容：

```rust
use crate::runtime::{BehaviorContext, FixedStep};

pub fn ready(ctx: &mut BehaviorContext) -> Result<(), String> {
    ctx.on_fixed_update(fixed_update)
}

fn fixed_update(ctx: &mut BehaviorContext, step: FixedStep) -> Result<(), String> {
    let vx = ctx.number("velocity_x")?;
    let vy = ctx.number("velocity_y")?;
    ctx.translate([vx * step.delta_seconds, vy * step.delta_seconds])?;
    let [x, y] = ctx.position();
    ctx.emit("moved", vec![x.into(), y.into()])?;
    Ok(())
}
```

普通保存后，沿已有创建或引用管理入口关联脚本，再在行为表单明确设置两个数字参数 `velocity_x`、`velocity_y` 和 `moved` 的事件映射。事件携带当前 `[x, y]` 两个数字；模板不自动添加参数、绑定或关系。只使用 `ready` 的旧脚本不必注册固定回调。

每个绑定先执行一次 `ready`；`on_fixed_update` 只允许在此阶段登记一次，重复登记或从固定回调中登记都会报告生命周期错误，即使作者忽略返回值也不会提交当前调用。回调使用函数指针，本轮不提供闭包捕获或跨步可变脚本状态。当前无头 smoke 随后执行固定两步，每步 `delta_seconds = 0.25`，`tick` 依次为 0、1；每步先处理既有默认方向移动，再按绑定清单顺序调用已注册的固定回调。这是有界测试生命周期，时间步与次数不是作者可配置的控制回放或连续游戏循环。

`position()` 返回当前绑定实例的位置；`set_position([x, y])` 和 `translate([dx, dy])` 只改变该实例，坐标和计算结果必须有限。同实例多绑定依次可见上一个成功回调的位置，无法通过这些接口修改其他实例、作者场景或 OC 定义。单次调用的候选位置、事件与回调登记在返回成功后共同提交；返回错误、panic 或被作者忽略的参数／位置／事件接口错误都会阻止该次提交。此前成功调用的结果保留；这里的事务不回滚任意 Rust 副作用，也不是代码沙箱。

每个绑定在一次完整运行内最多发出 64 个事件，预算包含 `ready` 和后续固定回调，不按时间步重置。事件继续使用冻结绑定身份和已声明信号映射；失败诊断仍指向原绑定文档，修改后需重新构建。编译错误继续定位到 TXT 原文。旧源码可重建，旧适配器生成的工程需重新生成后再运行。

固定步沿用既有作者格式与运行协议；实际验收范围见[固定步专题](test-results/bevy-rust-fixed-step/README.md)，不能从无头执行结果推导图形窗口、安装或移动设备支持。

## 冻结、诊断与迁移

计划 v3 包含绑定来源、精确源码原文和实例配对；整个工程观察仍包含正文、登记与摘要。构建与运行共用同一纯规划入口，恢复时重算绑定，核对工具、生成器、执行适配器和每份生成文件，不能直接信任产物里改写的脚本或绑定。源码工程离线后仍可回放已完成构建。

编译诊断根据生成的源码 UUID 映回冻结 TXT 原文；运行参数诊断映回绑定文档的 JSON Pointer。精确范围和正文修订由冻结作者数据确定，引擎输出不能指定编辑器路径。点击诊断后沿用已有的原文导航和过期定位保护。

选择式资源包从绑定正文重新推导场景与源码 UUID，并复验元数据边、实例和内容预算；读包及导入同样复核。已锁定的外部依赖在导入时验证具体内容和摘要，场景和源码这些直接依赖不能借目标工程里碰巧存在的同 UUID 文件补缺。包内场景必须同时声明其角色定义依赖，不能借未声明的目标对象；若场景本身是已锁定的外部依赖，则可沿其已锁定元数据边读取传递角色，读取仍核对内容摘要和并发修订。场景、定义、图片、绑定和 TXT 原文随闭包迁移，生成工程和缓存不进入包；完整 `.viento.zip` 仍按原规则保存作品。

职责与后端七项能力见 [执行中间层](BACKEND_MIDDLEWARE.md)，场景操作见 [构建与运行](PROJECT_BUILD.md)，迁移见 [资源包](RESOURCE_PACKAGES.md)。本轮实际验证保存在 [行为运行记录](test-results/scene-behavior-runtime/results.json)，既有报告保留原条件。

## 原文查找与替换

源码编辑区的 **查找与替换** 适用于所有当前文本，不要求工程声明脚本类型或执行后端。Ctrl / ⌘ + F 在源码区域打开工具；输入字面文本后可查看匹配数量，用上一个／下一个、F3 / Shift + F3 或查找输入中的 Enter / Shift + Enter 定位。默认区分大小写，可明确关闭该选项；查询和替换输入均可粘贴多行文本。查找不编辑原文；自动折行保持，匹配仍按原文 UTF-16 位置定位。

**替换当前** 只修改当前精确选中的匹配；先导航到目标再替换。**全部替换** 对当前文档的非重叠匹配执行一次原生编辑，可一次撤销；替换值按字面文本处理，`$&`、`$1` 和反斜杠不会变成替换语法。替换先进入普通草稿，保存、外部冲突和诊断待复验继续沿原有流程。

源码区的 Ctrl / ⌘ + Z 撤销，Ctrl / ⌘ + Shift + Z 或 Ctrl + Y 重做，复用当前文本框的浏览器编辑历史；桌面 WebKit 保留历史却未路由快捷键时由独立宿主接线补齐。仅在当前可编辑源码获得焦点时处理，保存／加载忙碌、弹窗和输入法组合期间不拦截；没有第二套正文历史，也不承诺跨文档或重启持久化。Linux 安装版已核对查找替换后的完整原文撤销／重做，见 [安装验收](test-results/native-installed-0.1.1/README.md)。

查找／替换输入框中的图片粘贴和文件拖放不会转交正文素材导入器。工具绑定当前源码会话，切换或重新加载文档后清除旧上下文；加载、保存、弹窗和输入法组合期间保护正文。空查询没有匹配；原文及最终结果不超过 4 Mi UTF-16，查询最多 4096 码元、替换输入最多 65536 码元、匹配最多 10000 处，超限拒绝，不只替换部分结果。此处为单文档字面操作，不提供正则表达式、全工程替换或语言服务。


## 将动画片段编号填入行为参数

可选片段目录提供已保存动画中的片段名称与编号。先在动画字段编辑器定义并保存[命名动画片段](SCENE_ANIMATION.md#命名动画片段)，再打开同场景的行为清单，点 **编辑场景行为 → 读取动画片段**。

1. 在需要引用片段的参数行选择 **文本** 类型。使用 **Godot / 命名动画片段** 或 **Godot / 事件动画片段** 脚本起始内容时，该参数通常为 `clip_id`；助手不会根据参数名猜测用途，也不会自动新增参数。
2. 选择列表中会显示片段名称、起止秒数和完整 UUID。选项暂选不会修改参数；点 **填入动画片段编号** 才替换该行文本，并撤销之前的修改审阅。
3. 点 **检查行为修改**，审阅完整原文，再 **应用到原文草稿**，最后在编辑器普通保存。项目组装运行时，原有 GDScript 接口消费保存的字符串编号。

读取和刷新只查看当前行为所属场景的已保存声明；未保存动画字段不进入目录。没有动画关系、合法旧动画没有片段、schema 3／4 的片段列表为空会分别得到空目录提示，仍可直接输入普通参数。读取失败、关闭、切换绑定或参数行等情况下，过期回复不能填入另一个输入；中英日切换保留未完成文本、焦点与选区。

音轨选择和动画片段选择分别读取、各自撤销在途请求；可选目录不可用不影响普通行为审阅与保存。目录只检查动画声明和归属，不读取图片、执行脚本或要求完整场景构建成功。动画目标实例或图片正在修复时仍可枚举已经声明的片段；登记整体损坏仍可能阻止 World 快照读取。

填入的 UUID 是普通文本，不产生静态引用关系，不保护后续片段删除，也不自动重写脚本。目录可读不代表当前场景可以构建；实际构建继续验证目标、资源和脚本类型。清空 `clip_id` 以选择整份动画属于该起始脚本的约定，不是所有文本参数的统一规则。

源码 HTTP、普通保存、真实浏览器与 Godot 的分段验收见[片段参数选入记录](test-results/scene-behavior-animation-picker/README.md)。本轮没有安装包、Android 或 Bevy 动画验收。

在动画侧调整片段前，可通过[查看动画片段使用位置](SCENE_ANIMATION.md#查看动画片段使用位置)查看本场景已保存行为参数中的完整编号文字匹配，并就地定位参数原文；此查询不自动修改参数或保护片段删除。


## 按状态配置片段

已保存的状态表脚本可在当前绑定中使用 **状态与动画片段 → 读取状态片段配置**，按名称为每个状态选择本场景片段，再显式应用到参数表。完成转换遇到循环片段会提示；缺片段、重复目标参数、错误类型和 32 项预算分别检查。随后仍使用普通原文审阅和保存。操作、取消与来源变化规则见[动画状态片段配置](SCENE_ANIMATION.md#按状态配置动画片段)。

## 根据脚本接口修复参数

在 **编辑场景行为 → 脚本参数接口** 查看当前绑定的参数要求。选择已保存的状态表脚本后，面板按该 TXT 的版本声明列出 `clip_<状态键>`，提示缺失、未声明、重复、类型不匹配或片段编号格式问题。提示只针对当前选中绑定；多个实例使用同一脚本时，各自的参数保持独立。

例如把状态 `attack` 改名为 `strike` 并保存脚本后，行为里原有的 `clip_attack` 会显示为未声明，`clip_strike` 会显示为缺失。在旧参数旁明确选择目标 `clip_strike`，点击 **更名并保留值**，即可把原片段编号保留到新名称；已经存在的名称、类型不合和重复行不能作为转移目标。助手不会猜测新旧状态的对应关系，也不会自动删除未声明参数。

**补齐缺失参数** 只把当前接口缺少的默认值加入本地表单，保留所有已有值。状态表生成器的片段参数默认留空，含义是**播放完整动画**。需要命名片段时，继续使用 **读取动画片段 → 填入动画片段编号**。空值不会关闭状态；合法 UUID 也不证明片段在当前场景仍然存在，实际构建与运行另行验证。

修改后点击 **检查行为修改**，审阅完整前后原文，**应用到原文草稿**，再普通保存。取消保留原正文；仅暂选更名目标不会使表单变脏。脚本或其他登记依赖在检查后变化时，需要重新打开行为编辑，以免把旧接口审阅应用到新的来源。辅助信息暂时不可用不改变普通参数编辑与保存能力。

只有同文件版本声明及完整生成源码均通过校验的状态表 TXT 才提供参数接口。手改源码、未知生成版本和缺少核心能力会给出状态提示，继续按普通参数编辑；无声明的普通 GDScript、Rust 或旧状态脚本不推断接口。这是当前绑定的显式修复辅助，不是全工程引用迁移或通用语言服务。协议、脚本文件、作者登记与已安装程序均不随辅助操作自动迁移。

实际验证及平台边界见[参数接口与修复验收](test-results/animation-parameter-bindings/README.md)。


## 从脚本查看使用位置

打开已经登记保存的 TXT，进入原文编辑，点击 **查看脚本使用位置**。查询跨当前工程的场景，列出登记中以非 `part-of` 关系指向此脚本的文档。它适用于普通 GDScript、Rust 和状态表脚本，不要求源码带参数接口声明。

每份文档分别显示实际行为绑定、仅引用未绑定、普通文档引用、无效行为、损坏 JSON 或来源缺失。合法绑定显示场景、实例、后端／语言、参数和 `/bindings/N`；同一文档里多个绑定分别列出，不按文件名或参数名猜测归属。这里只读取已登记引用，不解析动态代码，也不补找未登记的依赖；没有结果不表示脚本可以安全删除。

1. 点击 **查看绑定原文**，在窗口内读取当次查询保存的完整原文，并选中该绑定。**查看文档原文** 则查看整份引用文档；它也可以帮助检查无法解析的正文。来源缺失时不提供原文。
2. 点击 **在编辑器中打开原文**，先复核脚本与目标的保存身份，再通过主编辑器打开。当前脚本存在未保存修改时，沿用原有确认；取消会保留草稿。若在导航过程中原文又变化，编辑器显示当前来源状态，不把旧范围当成精确位置。
3. 对合法行为文档，继续使用 **编辑场景行为** 和上一节的参数接口辅助，明确选择需要修复的绑定，审阅后应用草稿并普通保存。返回脚本重新查询，即可查看新的保存结果；其他绑定不自动迁移。

**刷新使用位置** 重新读取保存态目录。只读原文和参数值代表上次查询，窗口打开后不会自行跟随外部编辑。当前 TXT 可以有未保存草稿，但查询仍以它的保存基线为准，不会保存或覆盖这份草稿。切换文档、关闭窗口、重读或可选服务失效会撤销旧结果的操作归属。

查询不需要场景能够构建，不读取图片或运行脚本。最多读取 128 份引用文档，每份正文及当前脚本不超过 128 KiB UTF-8，完整响应最多 2 MiB；超限整次返回错误，不截断成看似完整的结果。登记整体损坏或并发保存冲突会单独报错，可修正后重试。

源码浏览器、双目录工作流与只读保护的验证见[脚本使用位置验收](test-results/script-usage/README.md)，该专题不覆盖安装或移动设备验收。


## 逐实例动画端口的身份边界

运行播放范围属于动画文档，不属于行为参数。作者在动画字段中选择“每个实例独立播放”，检查、审阅并保存后，从项目组装重新构建；选择片段、补齐 `clip_<状态键>` 参数或临时切换预览范围都不会替作者开启它。状态表v1–v5作者源码不用迁移，仍通过现有 `viento_project` 方法选择、播放和订阅完成。

整场景范围的所有绑定控制一个播放头；逐实例范围按绑定所属实例分开，同一实例的多份绑定仍共享该实例播放状态。没有该实例动画轨道时，端口不会改为控制其他角色。事件启动和完成衔接行为若要控制同一角色，需绑定同一实例；同实例多控制器的优先级和混合不由本轮自动仲裁。

协议11的公开动画端口以实际端口对象登记原始访问、完整绑定和行为实例。后续命令、完成订阅／撤销及状态进入采集核对这些身份；修改公开字段、替换整份绑定为另一条合法记录不能改变其来源与目标。失败诊断仍指向原登记绑定。此约束防止公开端口错配，不提供GDScript代码沙箱；作者代码仍有引擎与本机进程权限。

逐实例项目使用协议11／清单12；当前执行适配器为0.27.0，具体生成器和整场景分支见[协议选择表](PROJECT_BUILD.md#当前项目协议选择)。单独场景构建和Bevy尚不接入该范围；精确使用方法、stop语义及验证见[动画指南](SCENE_ANIMATION.md#为正式运行选择播放范围)和[本轮记录](test-results/animation-instance-runtime/README.md)。
