# 0.0.9 版本记录

2026-10-08。把 0.0.8 之后的工具身份检查、运行验收用例、工程保存与迁移、有序验收组及成员报告纳入源码交付。应用版本更新不修改作者工程、元数据、素材或既有运行协议。

## 变更

- **检查工具身份**：构建工作台和 CLI 共用可信宿主检查，复用 Godot／Bevy 的版本识别与完整二进制摘要。中英日显示确认版本或受控失败原因，检查不改变草稿、任务或成功产物；实际构建／运行仍重新验证工具。来源离线时保留最近有效场景目录，已经成功冻结的产物继续运行和观察。
- **通用运行验收**：控制程序与逐步位置／状态预期组成独立纯用例，在两个后端的真实采样上使用同一评判。只支持无作者行为的冻结 plan 2、稳定实例 UUID，最多 128 条检查，位置采用显式逐轴绝对容差。进程成功与断言失败分别记录，取消、超时和缺样本保留未完成事实。工作台和 CLI 均可运行；参考预期仅由用户明确生成。
- **工程内用例文档**：保存场景 UUID 与原纯用例，复用普通文档登记、原子写入和正文修订保护。载入、保存、另存及未确认回执有明确的草稿保护；选择式资源包派生场景依赖，标准完整迁移保留稳定身份与正文原字节。已载入用例在来源离线时仍可重跑同场景的冻结产物。
- **有序验收组**：保存同场景成员身份与顺序，任务分配前捕获全部正文并检查联合预算，宿主逐份复用原无头会话。断言失败继续，执行失败／取消停止余项并等待退出；各成员会话及独立批次回执保留。验收组保存、CLI 和迁移沿用工程工作流。
- **成员详情与 JSON 导出**：每份已执行成员独立保存定义、终态、真实步骤采样及重新计算的评价，前面的失败不会被后续成员覆盖。工作台显示预期、实际值、容差与失败步骤，并由明确点击下载独立 JSON。纯规则、可信文件 pin、当前任务归属和三语界面分开；来源离线仍可回读，文件篡改、旧任务和迟到响应拒绝。报告保存失败停止余项，保留已提交的执行与断言事实。
- **链路修复**：补齐选择式包中已知场景的成员依赖检查，拒绝异步准入期间已被清理的冻结构建，隔离 GUI 的轻量契约与作者解析依赖，修复最终会话保存时的取消竞争及英文窄屏标题布局。功能图谱与工作流证据随源码更新，既有报告和来源指纹保持原样。

操作入口见[构建与运行](PROJECT_BUILD.md)、[执行中间层](BACKEND_MIDDLEWARE.md)、[运行验收用例](RUNTIME_CASES.md)、[有序验收组](RUNTIME_CASE_SUITES.md)和[成员报告](RUNTIME_CASE_REPORTS.md)。模块职责见[当前架构](ARCHITECTURE.md)与[功能图谱](FUNCTION_ATLAS.md)。
