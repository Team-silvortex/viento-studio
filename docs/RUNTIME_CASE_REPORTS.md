# 批次成员详情与报告导出

本页能力已纳入 [0.0.9 源码交付](RELEASE_0.0.9.md)。保留的“未发布增量”标题和阶段验证描述对应此前 0.0.8 工作树，旧报告版本与条件保持；已安装程序需另行更新。

这项能力随 **0.0.9 源码**交付。它接在[有序验收组](RUNTIME_CASE_SUITES.md)后面：每份实际执行的成员完成后，宿主保存一份独立报告，界面可以查看并下载。先前用例的失败步骤不会被后续会话覆盖。

## 操作

1. 在构建工作台保存并运行验收组。
2. 已完成成员的「查看用例详情」按钮可用。后续成员仍在运行时也可以查看前面的报告。
3. 详情分别显示执行结果和验收结果，以及实例、步骤、预期位置／状态、实际位置／状态、逐轴容差。界面步骤从 1 开始；JSON 的 `stepIndex` 保持从 0 开始。
4. 点击「导出用例报告 JSON」，下载 `runtime-case-report-<用例 UUID>.json`。查看或关闭详情不会触发下载。

中文、英文和日文入口一致。查看与导出不改变用例、验收组、正文草稿、光标或运行任务，不用实际值自动更新预期。这里只导出单个已完成成员；批次顺序与汇总仍由原验收组回执记录。

## 报告内容与通用层

`viento-runtime-case-report` schema 1 具有八个固定字段：`format`、`schemaVersion`、`context`、`executionStatus`、`targets`、`definition`、`samples` 和 `evaluation`。

`context` 保存冻结场景的相对来源路径与 UUID、构建 UUID、快照摘要、后端标识、验收组 UUID 与捕获的正文摘要、成员 UUID 与捕获的正文摘要、运行会话 UUID。来源路径属于当时的冻结计划，作者之后重命名文件不会改写它。正文摘要是捕获原字节的 `sha256:` 修订，不能从格式化后的用例定义重新推导。

`targets` 只有稳定实例 UUID 与对象 UUID；同一对象可以有多个实例。`definition`、`samples` 与 `evaluation` 复用已有用例及步骤采样规则。[纯模块](../engine/runtime-case-report.mjs)重新计算全部检查，并要求存储的评价与计算结果完全一致；返回脱离输入的深度冻结数据。它不读文件、作者解析器、DOM 或引擎。

报告上限是 **2 MiB 的实际 UTF-8 紧凑 JSON，包含末尾换行**。原单用例的 64 步、128 实例、1024 个实例×步骤、128 条检查限制保持。解析不接受未知字段、非有限数、稀疏数组、访问器、额外原型、循环引用或无效 Unicode。

纯校验能证明数据结构及评价相互一致；单独拿到一份外部 JSON，不能证明它由真实引擎执行，也不能据此认证其原作者字节。GUI 的可信来源由当前宿主任务和文件 pin 共同保证。报告没有导入、跨任务历史查询或自动恢复入口。

## 终态与失败

| 情形 | 执行结果 | 报告中的验收结果 |
| --- | --- | --- |
| 所有步骤完整，预期全部满足 | `succeeded` | `passed` |
| 所有步骤完整，至少一条预期不满足 | `succeeded` | `failed`；验收组继续执行后续成员 |
| 执行失败、取消或超时 | `failed`／`cancelled`／`timeout` | `incomplete`；保留已经接收的步骤与各条检查事实 |
| 后续成员在创建会话前失败 | 非成功终态 | `incomplete`，空采样，`sessionId: null` |
| 排队、正在执行或未运行 | 尚无终态 | 没有成员报告，按钮不可用 |

报告保存失败时，宿主停止剩余排队成员并报告 `runtime_report_write`；已经提交的成员执行结果、通过／失败检查与采样仍保留。因此批次任务可以 `failed`，而已完成成员或最终断言汇总仍为 `passed`。磁盘错误不会被最终完整汇总掩盖。

步骤样本不能重建原会话中事件与采样的完整交错顺序，详情不会伪造运行对象回放。

## 宿主、缓存和权限

[可信文件层](../scripts/lib/runtime-case-reports.mjs)在宿主选定的独立 suite 缓存目录写入 `member-<UUID>.json`，权限为 0600，临时文件独占创建后原子发布，已有报告不被覆盖。回读只按成员 UUID 推导文件名，拒绝目录链或最终文件符号链接、文件替换、超限文件、UTF-8／评价不一致；再核对原文件 SHA、完整上下文与规范定义 SHA。文件 pin 和绝对路径保留在宿主内部。

HTTP 使用原本机认证的 `POST /api/project-build`，正文只允许 `action: "suite-report"`、`jobId` 和 `documentId`。它只查询**当前服务的当前验收组任务**。读取不检查工具、不打开作者正文或冻结构建，也不占用执行槽；已经捕获的报告在作者来源离线或构建文件被外部清理后仍可读取。新计划、构建或运行任务取得归属后，旧任务报告不再通过接口读取。关闭服务等待正在读取的报告结束，拒绝迟到结果；新服务不扫描或接管旧缓存。

缓存报告不属于工程正文／素材／元数据，不进入选择式资源包或标准完整工程迁移。显式下载的 JSON 可以自行保存；当前没有缓存历史管理或跨重启报告恢复。CLI 批次命令原样返回宿主回执目录，该目录里可以找到成员 JSON；没有新增任意路径 HTTP 读取或外部报告导入。
