# 0.2.2 版本记录

2026-10-24。本版补齐二维物理从首次创建到空间查看的作者工作流：从已保存场景选择实例，审阅并保存物理声明与关系，再在独立编辑面板中选择碰撞体、检查参数、应用草稿和普通保存。已有 Godot 碰撞、触发事件及动画链路继续沿用。

## 变更

- **按名称选择与修复物理实例**：目录列出已保存场景的对象名称和完整实例 UUID，同名实例分别保留身份。丢失引用明确列出，作者可选择已有实例修复；读取失败时保留标记为未验证的手填路径。使用目录检查的修改在应用前重新核对保存态来源。
- **从场景首次创建物理声明**：构建页新增“场景物理”。选择实例、正文类型和路径，设置第一个碰撞体，审阅完整 JSON 与双向关系后，一次保存物理正文、对象登记和场景关联。已有声明直接打开原文；保存结果未确认时重新读取并核对，不重复发送创建。
- **场景空间图**：读取已保存 Scene2D 的位置和逻辑尺寸，按实例根位置与碰撞偏移显示矩形／圆形范围。点击图形或使用键盘选择对应字段；未检查的参数不显示旧形状，检查通过后显示候选。视口外对象计入显示范围，缺失目标单独列出，不猜测位置。
- **刷新与会话保护**：空间刷新保留未完成输入、选择和审阅；空间读取失败不关闭已有编辑路径。目录、空间和草稿各有独立来源及请求代际，迟到响应和旧关闭事件不能接管重开的窗口。
- **导出指标 CI 竞态修复**：Range 测试等待服务端完成下载记账后再核对状态与次数，避免客户端读完响应但文件收尾尚未完成时误报。新增确定性回归覆盖 206／416 及完整重试，并纳入兼容性工作流；生产导出与指标生命周期保持。

新增界面提供中、英、日文案，覆盖窄屏、焦点、取消与重开。操作见[二维物理](SCENE_PHYSICS2D.md)。

## 格式、分层与兼容

当前为 **23 模块／45 项声明能力**；功能图谱为 **161 功能／482 实现／692 绑定／2768 评分单元／125 工作流**。构建工作区新增 `scene.authoring.physics2d-creation`；物理编辑模块增加可选只读 `getTargets` 和 `getSpace` 端口，不新增系统模块。发布归属更新不提高已有成熟度评分。

独立 `physics2d.create` 命令使用事务日志 **v12**，共同提交正文、登记和场景元数据三份文件；旧日志 **v1–v11** 继续恢复读取。恢复核对冻结场景和定义证据，不覆盖作者依赖正文。新建物理文本限 64 KiB，创建时核对声明规则、稳定实例、世界和来源修订；投影后的运动条件及后端支持仍由构建预检判断。已有声明的后续编辑继续应用普通原文草稿，再由普通保存写入。

空间服务复用保存态场景模型，不读取图片内容、不运行构建或物理求解；纯几何域绑定精确来源快照，渲染器只消费几何并返回选中的碰撞体 ID。空间读取不产生写入凭据，目标目录仍独立保护应用前的身份核对。

物理作者格式仍为 `viento-scene-physics2d` **schema 1**、物理子计划 **v1**；Rust/WASM、Godot 执行适配器 **0.21.0** 及运行协议不因本版改变。含逐实例动画的项目继续使用协议 **11**，旧整场景控制器、普通动画和无动画项目继续按 **10／7／4** 分支。Bevy 适配器、应用标识、用户数据目录与素材保持；打开旧作者文档不自动迁移。

## 交付边界

本版为 **0.2.2 源码交付**，提交并推送主分支；本次不制作或安装新程序，不创建版本标签或 GitHub Release。本机已安装程序仍为 **0.2.0**，其[安装验收](test-results/native-installed-0.2.0/README.md)保持原范围。

物理当前限 Godot 二维项目组装。空间图支持查看与选择，未接拖拽、缩放／平移工具或模拟；动态刚体、力／冲量、重力、关节、材质、3D 和 Bevy 物理仍待接入。旧直接位置控制回放拒绝含物理工程。工程 ZIP 仍需对应引擎工具，尚非独立游戏发行程序；源码交付不代表安装版、Android 或其他设备验收。
