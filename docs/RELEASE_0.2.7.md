# 0.2.7 版本记录

2026-10-28。本版推进二维场景从编辑、项目组装到构建、运行和交付的工作流，补充逐角色运动驱动、物理输入回放与验收、项目键盘映射，以及受限的 Bevy 数据项目组装。

## 主要变化

- **角色运动意图**：在 Godot 项目中，启用重力角色且控制方式为 `none` 时，可通过绑定的普通行为脚本按实例提交水平移动与跳跃意图。起始脚本支持自定义输入动作；提交被接收不等同于角色实际移动或跳跃。物理求解继续由后端完成，已有作者脚本不会被自动替换。[物理指南](SCENE_PHYSICS2D.md#用行为脚本驱动单个角色)
- **物理回放与验收**：在工作台编辑有界的逐步输入，查看引擎实际物理观察；回放文档和验收文档分别保存输入及预期，并可通过资源包迁移关联场景。验收比较指定实例、步骤的位置和移动扫掠碰撞，运行完成与验收通过分别报告。此功能目前限单场景、无作者行为／声音／动画的 Godot 物理项目，不代表完整接触或落地判定。[物理指南](SCENE_PHYSICS2D.md)、[回放文档测试](test-results/physics-replay-documents/README.md)、[验收测试](test-results/physics-replay-acceptance/README.md)
- **项目输入映射**：新增独立的键盘输入映射文档，由项目组装显式引用，Godot 构建负责转为引擎动作。编辑器可编辑、审阅和保存动作与物理键，并对官方角色运动及下穿模板缺少的动作给出非阻断提示。映射不会自动修改脚本或行为参数；同一物理键可以触发多个动作，也可能同时触发 Godot 的内置 `ui_*` 动作。[项目组装](PROJECT_ASSEMBLY.md)、[输入映射测试](test-results/project-input-map/README.md)
- **Bevy 数据项目组装**：可以组织和检查多个成员场景、指定入口，生成可审查和离线交付的后端项目。有限控制回放针对冻结的入口场景，可指定实例并查看步骤样本；不包含场景切换、项目键盘映射、物理或图形窗口。图片、行为、声音与动画等不支持的项目内容会明确拒绝，Bevy Rust 作者通道仍独立。[Bevy 指南](BEVY_BACKEND.md)、[入口回放测试](test-results/bevy-project-control-replay/README.md)

## 数据与交付边界

原文、素材和登记仍是作者数据；映射、回放与验收文档通过显式保存进入工程，预览和运行结果属于派生数据。资源包会携带受支持文档及其依赖，迁移仍应核对所需内容。生成的 `.viento-build.zip` 是需要对应引擎或可信运行工具的后端工程，不是独立游戏发行包；运行作者脚本的工具不构成沙箱。

执行适配器的指纹已变化，已有冻结构建在运行或交付前可能需要重新生成，不应修改摘要绕过检查。Godot 与 Bevy 的能力和验证范围分别判断，真实物理设备、各桌面系统及 Android 不能从本机无头或合成输入结果推定。

发布检查和升版前开发证据分别见 [0.2.7 发布检查](test-results/release-0.2.7/README.md)。本版源码提交不会自动更新本机安装；本次未宣称新版安装或设备验收。
