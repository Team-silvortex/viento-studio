# 0.1.3 版本记录

2026-10-15。本版收录 0.1.2 之后的多行为创作、已有脚本引用管理、Bevy Rust 作者行为与固定步更新，以及独立场景声音链路。作者编辑、共享规则、具体后端与工程交付继续分开；应用数据目录和既有工程保存、迁移规则保持。

## 变更

- **首次多行为绑定**：一次建立 1–32 条实例／脚本绑定，最多使用 8 份去重脚本；同一实例可挂多个行为，多个实例可复用脚本。清单保留稳定身份与逐项设置，完整审阅后复用原三文件事务；参数和信号仍在独立行为编辑器配置，再普通保存。
- **管理已有行为**：从已保存场景查看行为与脚本引用，明确审阅并保存新引用，再打开原文编辑绑定、参数和信号。关联仅修改登记，正文编辑仍应用普通草稿；目录过期、取消、未知提交结果、来源切换和退出分别守护。
- **Bevy Rust 作者通道**：独立 `org.viento.bevy-rust` 适配器把已登记 TXT、稳定实例绑定、参数和信号接到实际 Cargo 检查、原文诊断、无头运行及 Cargo 源工程交付。固定 Cargo／rustc 1.95.0 和 Bevy 0.19.1，使用锁文件与离线缓存；旧 Bevy 数据通道保持。
- **Rust 固定步行为**：兼容原有 `ready` 脚本，并允许显式注册固定步函数，读取和修改自身实例位置。先执行内置移动，再按清单顺序调用行为；单次回调成功才提交位置、注册与事件，失败回调不影响先前成功绑定。每份绑定累计最多 64 条行为事件。内置中英日起始内容可直接创建移动脚本，Studio 当前验证两步、每步 0.25 秒。
- **场景声音**：独立 Rust 声明和显式时刻采样支持 1–16 条音乐／音效轨道、1–64 个播放／停止提示、0–60 秒时间及独立音量／循环。已有声音 JSON 可在专用字段面板审阅后应用草稿，再普通保存；场景、资源、稳定身份与数组顺序保持，编辑不自动播放。
- **Godot 声音与资源交付**：通过场景的唯一 `audio` 登记关系解析声音，冻结真实 PCM16 WAV，Godot 为每轨生成独立播放器并驱动提示。声音时钟与演员完成交叉核对，保留高精度时间边界；工程 ZIP 包含核验后的运行文件和 WAV 原字节。`music`／`effect` 表示用途，不是混音总线。
- **源码归档完整性**：声音合成样例的正文、登记和 WAV 随源码纳入版本控制及归档输入；同时排除 Bevy 固定模板中的 `target` 编译缓存；工具和真实作品继续排除。

当前为 **21 模块、38 项声明能力**；图谱为 **121 功能、318 实现、490 绑定、1960 评分单元、84 条工作流**。Godot 适配器为 **0.6.0**，Bevy Rust 适配器及固定模板为 **0.2.0**；旧 Bevy 数据适配器仍为 **0.3.0**。应用版本与各后端身份分别管理。

操作说明见[场景行为](SCENE_BEHAVIORS.md)、[Bevy 后端](BEVY_BACKEND.md)、[场景声音](SCENE_AUDIO.md)、[工程交付](BACKEND_PROJECTS.md#交付生成工程)及[二维功能映射](FUNCTION_MAPPING_2D.md)。

## 交付边界

本次提交推送 **0.1.3 源码**，不制作安装包、更新本机安装、创建版本标签或 GitHub Release。新增功能需从源码启动或自行构建。最近的 [Linux 实际安装验收](test-results/native-installed-0.1.1/README.md)仍为 **0.1.1 工作树 AppImage**，早于本版增量；准备资源不代表新版 Tauri 窗口或 Android 设备验收。

Bevy Rust 当前限 Linux 无图二维行为，接收方需要匹配的实际工具链与预缓存依赖；ZIP 不含二进制或 `target`。两条 Bevy 通道均拒绝声音，未接图片、窗口、GPU、行为输入回放或热更新。Godot 声音只支持非空间 PCM16 WAV（单／双声道、8–96 kHz、每份不超过 32 MiB）；声音新建向导、结构增删、行为事件触发、混音总线、空间音频以及声音与有限控制回放的组合尚未接入。工程 ZIP 仍依赖开发引擎工具，尚非独立游戏发行程序；Nuislang／ns-nova 原生执行、外部 IDE／LSP 和嵌入运行视口继续独立推进。
