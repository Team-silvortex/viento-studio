# 0.3.1 版本记录

2026-11-20。本版收录 0.3.0 之后的首次行为配置增量：在保存前填写各绑定参数，按真实名称连接实例、组装成员、输入动作和音轨，减少先保存空配置再重开及手抄编号的步骤；同时修复应用 CI 作业超时与测试进度不可见的问题。

## 主要变化

- **首次创建直接配置参数**：每条绑定分别保留原始参数 JSON、绑定身份和未完成输入。选择已识别官方脚本后，作者明确点击才补齐缺失默认项，已有键和值保持；普通或手改源码不猜接口。参数与全部绑定一次审阅后，进入原有正文、登记和场景关系的三文件事务。[操作指南](SCENE_BEHAVIORS.md#首次创建时配置参数)、[开发验证](test-results/scene-behavior-create-parameters/README.md)
- **按名称连接对象与输入**：在首次保存前选择本场景实例；明确选择项目组装后，还可选择成员场景或已保存输入动作。作者指定当前 JSON 中已有的 String 参数，再重新读取来源并填入；同定义多实例保持独立身份。不增加参数键、隐藏关系或共享状态，也不推断参数用途。[名称连接](SCENE_BEHAVIORS.md#首次创建时按名称连接参数)、[空白作者纵切](test-results/scene-behavior-create-references/README.md)
- **首次创建选择声明音轨**：直接读取当前场景已保存的声音声明，将选定音轨身份填入现有 String。同一素材的不同音轨分别显示，素材身份不能代替音轨身份。填入不播放声音、不读取素材字节、不创建音轨，也不保护后续删除；实际播放由构建与运行另验。[音轨选择](SCENE_BEHAVIORS.md#首次创建时选择音轨)、[实际 WAV 与播放器验证](test-results/scene-behavior-create-audio/README.md)
- **保留草稿与审阅边界**：读取、选择、同值和失败保留参数及有效审阅，实际修改才要求重审；迟到响应无法覆盖已切换绑定或已编辑输入。已有完整审阅时，辅助写入前复核整个多绑定清单的 32 KiB 预算，超限保留原 JSON 与保存资格；尚未完成的其他绑定继续留给普通检查。
- **CI 可完成并可观察**：应用作业从 15 分钟调整为 30 分钟，加入共享 Rust 核心构建缓存；应用测试以 TAP 实时转发进度和错误诊断，并继续传递失败退出码。测试断言与兼容性作业保留。[验证指南](TESTING.md#应用检查)

## 架构与数据

参数规则、名称引用、音轨引用及各自视图分开维护。创建来源与目录使用独立进程内品牌；声音声明继续由 native/WASM 校验，缺少能力时保留手工 JSON 与普通审阅，不用 JS 替代领域规则。来源、会话与已保存修订在异步返回后复核，最终仍复用原有完整检查和 `behavior.create` 保存链。

本版不升级作者格式、事务日志、宿主 API、运行协议或 Godot／Bevy 版本，不迁移旧作品。参数选择也不授予后端新能力或让 Bevy 获得声音支持。便携规则覆盖 BOM／CRLF 与原始数值词元；浏览器 textarea 按标准规范化直接输入的行尾，不能外推为浏览器逐字节往返原始 CRLF 文件。

应用版本与执行适配器版本分别维护。Godot 当前描述符继续为 **0.49.0**，具体生成层与协议按内容选择；已有影视、菜单、暂停、重启和脚本往返继续保留。[0.3.0 记录](RELEASE_0.3.0.md)与各旧专题保留原始执行范围。

## 验证与交付范围

三个开发专题分别从官方空白结构经真实 Chrome 控件创建作者工程，再将实际保存数据交给真实 Godot：参数和名称链验证两成员重试与 HUD 初始化，音轨链验证带实际 WAV 的事件声音、独立轨道、增益与循环。中英日 390px、取消零写、保存重开、迟到请求及来源保真分别留证。音轨使用 Headless／Dummy 驱动观察流与播放器，没有扬声器听测；原生键盘使用 Xvfb／Mesa 和合成输入，不代表实体设备验收。

上述开发报告保留各自的 0.3.0 工作树执行时点、完整检查计数、失败现场与来源摘要；专项之间有重叠，不相加为覆盖率。本次升版后的实际命令、版本一致性、源码分发及完整检查结果见[0.3.1 发布检查](test-results/release-0.3.1/README.md)，条件跳过不能写成对应工具或平台通过。远端 CI 状态以实际工作流运行结果为准。

本次交付源码，**本机 Linux AppImage 仍为 0.2.0**，不构建或更新安装程序，也没有新增 Android 实体设备或其他系统安装验收。`.viento.zip` 继续用于完整作者工程与素材迁移，`.viento-build.zip` 继续交付可审查、需要相应引擎工具的生成工程。

整款参考游戏从空白完成、首次动画片段选择、已有未保存行为原文的脚本往返、跨启动存档、长期持续运行、字体闭包和无引擎工具独立发行仍待推进。本版不代表 0.3 阶段出口或 [0.5.0 验收门槛](MILESTONE_0.5.0.md)已完成，后续按[路线图](ROADMAP.md)推进。
