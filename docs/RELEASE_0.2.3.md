# 0.2.3 版本记录

2026-10-25。本版把碰撞空间图的偏移与尺寸调整接入现有物理作者流程，并为 Godot 角色增加停止／沿碰撞面滑动选择。作者仍先检查和审阅完整原文，再应用草稿、普通保存并构建运行。本轮同时重构现行文档，让使用入口、架构边界、后续计划与历史证据各自集中维护。

## 变更

- **碰撞偏移空间编辑**：显式开启调整模式后，拖动选中形状，或用方向按钮／键盘修改相对实例根的偏移；提供查看缩放、显示全部与聚焦选中。拖动中只显示临时轮廓，松手才交还参数表；场景实例位置保持。
- **碰撞尺寸空间编辑**：矩形右、下、右下手柄围绕固定中心调整完整宽高，圆形手柄调整半径；按钮与键盘提供精确微调。查看、偏移和尺寸模式互斥，形状类型、碰撞中心及偏移保持。
- **角色停止／滑动响应**：首次创建和已有声明编辑都可选择响应。旧声明默认遇障碍停止；显式滑动在斜向遇墙后保留沿碰撞面的剩余位移。Godot 项目构建、真实运行和独立生成工程交付贯通相同选择。
- **输入、来源与会话保护**：空间手势拒绝越界、过期视图、未检查输入和缺失目标；取消、多指、失焦、捕获丢失及关闭重开不提交参数。零变化保留数字写法与审阅，只有变化字段更新。首次创建在摘要等待后再次核对响应能力，能力撤回时不发送失效请求。
- **文档重构**：首页与文档中心按任务导航，状态分别标明源码与安装范围，架构／模块／引擎文档集中描述职责，路线和测试指南分别维护后续目标与验证方法。旧长篇记录迁入带日期的历史快照，保留原章节锚点、原报告与执行条件。

新增交互提供中、英、日文案，沿用检查、完整审阅、应用草稿与普通保存。操作与限制见[二维物理指南](SCENE_PHYSICS2D.md)，文档入口见[文档中心](README.md)。

## 格式、分层与兼容

当前仍为 **23 模块／45 项声明能力**；功能图谱为 **164 功能／493 实现／703 绑定／2812 评分单元／128 工作流**。空间编辑复用已有物理作者模块及只读空间端口，不增加保存命令；发布归属与文档来源更新不提高已有成熟度评分。

空间偏移和尺寸使用独立纯提案，绑定来源视图、碰撞体和原几何，复用 Rust 数值规则；渲染器负责临时轮廓、手势与查看状态，控制器核对会话与表单后更新字段。矩形完整尺寸为 1–8192、圆形半径为 0.5–4096、偏移各分量为 −8192–8192；越界拒绝，不隐式截断或量化。图形编辑不运行物理求解，也不取得作者文件写权限。

`viento-scene-physics2d` **schema 1** 保留旧字段与停止语义。新增 **schema 2**，仅角色允许可选 `collisionResponse: "stop" | "slide"`，省略时停止；显式选滑动才升级，改回停止不自动降级，静态体与传感器不接受响应字段。保真补丁仅改变 schema、响应和显式编辑的字段，保留无关原文字节。首次创建继续复用 **v12** 三文件事务与恢复。

Rust/WASM 使用独立 `scenePhysics2D.inspectResponse` 及可选响应能力标记，原检查入口和主 ABI 保持。物理子计划仍为 **v1**；仅实际滑动角色要求 `physics.character-slide2d`。Godot 执行适配器为 **0.22.0**，schema 2 使用独立 **0.22.0** 响应包装；旧 schema 1 物理 **0.21.0** 生成器与无物理产物保持原路径。项目运行协议按既有动画内容选择，没有新增物理线协议。两个 Bevy 通道明确拒绝物理响应计划。

执行适配器指纹改变后，旧冻结构建仍可读取，但在新版 Studio 中运行或按现行适配器核对交付需重建。已导出的独立 Godot 工程不依赖 Studio 的执行指纹。应用标识、用户数据目录和既有作者素材保持；打开旧文档不会自动升级格式。

## 交付边界

本版为 **0.2.3 源码交付**，提交并推送主分支；本次不制作或安装新程序，不创建版本标签或 GitHub Release。本机 Linux x86_64 AppImage 仍为 **0.2.0**，其[安装验收](test-results/native-installed-0.2.0/README.md)保留原范围。Android 配置同步为 `versionCode` **1002003**，不代表已构建或验收同版本 APK。

物理仍限 Godot 二维项目组装。空间图提供几何编辑，不提供运行轨迹、碰撞求解或自由平移；动态刚体、力／冲量、重力、地板／斜坡策略、摩擦、关节、材质、3D 和 Bevy 物理仍待接入。滑动采用有限次碰撞剩余位移计算，视觉动画与物理根分开；`moving`／`idle` 仍表示输入意图，实际受阻需观察位置。

旧直接位置控制回放继续拒绝含物理工程。`.viento-build.zip` 交付可审查的后端源工程，运行仍需对应工具；独立游戏发行程序、其他桌面系统及 Android 设备验收不在本版范围内。
