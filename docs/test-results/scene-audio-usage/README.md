## 验证重点

纯核心捕获精确数据字段，保存态声音／行为各至多 32 KiB，声音编辑草稿至多 64 KiB；匹配所有文本参数中的完整小写 UUID，不裁剪空格、不折叠大小写、不按参数名或脚本内容猜测。私有品牌与完整来源五字段约束目录，保留未保存新轨道编号的可能匹配。

Node 从一次 World 快照读取已登记场景明确关联的声音及可选行为，验证登记、回链和语义。不要求脚本可执行或 WAV 存在，不受创建素材选择器的 256 个候选限制；底层仍读取工程文档、校验登记关系和检查素材状态。无关联行为、有效但零匹配、坏关系及超预算／冲突是不同结果，失败不能显示为“无使用”。HTTP 沿用作者鉴权、限定 JSON POST 与请求大小、拒绝查询参数、no-store，不开放浏览模式。

宿主在保存基线摘要和每次异步读取后核对来源及独立可选能力代次。查询丢失能力会撤销旧回复，不影响普通已审阅提案或试听。UI 按实时表单计算 cue，读取只更新查询面板，保留未完成输入、输入节点、焦点、暂选轨道及批准。仅显式展开／切轨时滚动，回包／刷新不滚动。

真实浏览器使用缺失 WAV 的临时合并样例，查询发出 **0 次素材字节请求**。取消不改草稿或文件；Apply 只改普通草稿，随后普通 Save 精确保留 BOM／CRLF，仅更改 `documents/audio/demo.json`，其他 **18** 个作者文件保持。文字匹配仅提示：移除真实 cue 后既有轨道移除仍可用，行为文档不被自动改写。

## 复现和平台边界

[浏览器脚本](../../../scripts/tests/scene-audio-usage-smoke.mjs)需要本机 Chrome；默认新建证据目录，作者工程始终是临时副本。先运行桌面、移动准备，再执行 [prepared-runner.mjs](prepared-runner.mjs)。准备副本使用注入的只读端口，不代表 Android 已提供 HTTP 端点；模块调用采用检查环境的 Node，未启动桌面嵌入运行时。

本轮没有 Godot／Bevy、新安装、物理音频或移动设备验收。全部 **7751** 份旧示例／历史／报告及 **2164** 个旧评分对象保持，安装 AppImage 和版本未变。只回收本轮新建且经字节核对的桌面准备目录，保留原有移动副本，见[保护记录](preservation.json)与[清理记录](cleanup.json)。
