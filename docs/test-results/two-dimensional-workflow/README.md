## 连续实测的起点与终点

起点由生产服务在临时空白工程中登记一个通用 OC、导入仓库 SVG，并登记样例配方。这部分是测试夹具，未宣称全部通过创建界面完成，也未宣称本轮验证了投影创作界面。

从此起点开始，真实浏览器选择配方并预览，审阅完整展开原文；中英日 390px 保留输入和操作按钮，取消没有作者写入。保存仅新增场景正文和登记，随后在同一工程内新建 TXT GDScript、普通保存、首次添加场景行为、编辑参数及信号映射并保存。四个实例和分组身份、父子关系保持。

真实 Godot 检查计划、构建和无头运行：首领按预期移动 40px，其余实例不动，返回 `materialized_checkpoint(materialized_scene, 73)`。浏览器下载工程 ZIP，独立核对清单、解压到新目录、核对脚本字节并由 Godot 再次导入成功。所有初始作者文件（含配方 BOM／CRLF、登记、定义及素材）保持；运行与交付不写作者数据。

此交付包仍需兼容 Godot 工具，不是独立游戏安装包。没有图形游戏画面、安装版 Tauri、原生文件选择器、Android、Bevy 作者 Rust 行为或其他平台执行验收。配方生成后独立维护，不自动同步或覆盖已有场景；配方直接构建和新建配方助手仍未包含。
