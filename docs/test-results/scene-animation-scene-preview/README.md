# 已保存场景中的动画预览

0.1.5 后工作树新增独立播放入口：**构建与运行 → 场景预览**。默认静态；播放、暂停、时间定位只改变视觉层，停止恢复保存状态并保留平移缩放。画面使用同次快照的实际位置、颜色和图片，标签与属性保留逻辑坐标。动画活动时禁用布局，改从对象列表选择；停止恢复画布选择。

同一冻结 source／plan 生成可选动画封套，严格绑定来源修订与稳定实例。坏动画单独显示 invalid，静态仍可用。旧宿主、草稿、配方保持静态，读取不调用完整构建／行为／声音，不增加图片缓存池或作者写入。
