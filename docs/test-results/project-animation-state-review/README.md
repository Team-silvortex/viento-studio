# 控制器状态历史回看验收

日期：2026-10-23。0.1.8后工作树，未升版、提交、推送或更新安装。基于[逐次进入记录](../project-animation-state-entries/README.md)增加独立只读回看；旧验收保持原时点。

## 已接通链路

完整p9运行观察 → 既有严格协议校验 → 按访问/场景/绑定的品牌模型 → 选择一次进入 → 前后记录、后续执行与终止采样分别展示 → 冻结来源导航。

同状态重启、同帧连续进入独立保留；同脚本不同绑定和再次进入场景分别回看。平铺搜索不裁剪当前控制器的完整顺序。追加命令、末态或记录不抢选择与焦点；新任务及所选记录替换会撤销旧选择。关闭回看返回可见入口或搜索框；来源跳转区分开始资格和等待期间的续行资格，避免自身加载撤销正常导航，同时拒绝过期来源。

后续命令限同组且序号大于所选记录的已执行截止值，不按下一进入划分因果区间。多个同截止记录可共享相同回执。终止快照来自本次访问最后采样，不代表所选历史时刻的即时状态；未采集保持空缺。
