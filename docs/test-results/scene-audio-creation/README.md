# 首次场景声音创建验收

2026-10-15，基线 `ed9c01d`／0.1.3 后工作树。**21 模块／39 项声明能力**，版本号保持，未提交推送或更新安装。使用方法见[场景声音](../../SCENE_AUDIO.md#从场景首次添加声音)，精确环境、来源和结果见[汇总](summary.json)。

## 完成的工作流

已保存 Scene2D → **场景声音设置** → 选择已登记 PCM WAV → 配置 1–16 条音轨 → 审阅完整正文和依赖 → **保存声音与关系** → **打开声音原文** → 既有字段编辑／普通保存 → Godot → 工程 ZIP 异地导入运行。

创建规划使用原 Rust 声音检查器。纯规则、目录／回执、宿主资源验证、v10 三文件事务与独立表单分别维护；旧行为 v9 保持。仅新增声音正文、声音登记并修改场景登记，素材和场景正文保持。多轨共享音频按资源身份去重，不把 WAV 塞入恢复日志。

## 真实使用与故障边界

最终浏览器复制官方声音示例，去掉原声音声明和关联，选择已有 WAV 新建两轨。取消与审阅不写文件；中英日 390px 保留输入和身份，返回、取消、审阅、保存均可达。一次保存恰好改变三个作者文件；返回既有字段编辑器后，普通保存只改声音正文。再次打开场景声音设置会识别既有文档。

Godot 4.7.2 收到 0／0.125 秒两条播放指令，演员与声音在 0.5 秒完成。Chrome 实际下载 **58,542 字节** `.viento-build.zip`，独立校验 **8 个生成文件／1 份 WAV**，解包到新路径后导入与运行退出码均为 0，声音事件完全一致。

宿主验证包括 workspace v2／v3、既有行为共存、真实 PCM 格式、同尺寸／恢复时间戳的音频替换、外置素材与素材库切换、并发进程首次创建、9 个强制中断边界及恢复再次中断。冻结证据用于三文件恢复；当前 WAV 离线或已被作者修改时，不读取、补建或覆盖它。作者正文 BOM、登记 CRLF 和大整数的保真覆盖保留；登记文件起始 BOM 仍按既有跨宿主规则拒绝，不扩大格式支持。

审查中修复：WAV 路径误套文档扩展白名单；锁忙及明确资源拒绝被误判未知保存；已有关系／绑定中的合法附注、空角色及长标签误被目录契约拒绝；桌面退出遗漏声音和部分脚本／行为窗口。新创建与未知结果确认仍核对完整精确依赖，不因兼容旧登记而放宽新写入。

[首轮全量](full.log)有 1 项重复翻译键失败，删除新增重复项、沿用原翻译后完成最终全量复跑。早期浏览器 JSON／日志保留各自源指纹，最终验收采用上述最后目录；重复中间截图在本轮清理记录中列出。未知提交只读取核对，不自动重复保存。
