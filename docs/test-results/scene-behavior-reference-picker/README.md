# 按名称连接行为参数

2026-11-13；源码保持 **0.2.9**，本机安装保持 **0.2.0**。使用入口见[行为指南](../../SCENE_BEHAVIORS.md#按名称填写成员实例与输入动作)。本轮只补作者编辑辅助，不增加运行协议、后端能力或持久格式。

## 实际操作

打开已有行为JSON，在 **编辑场景行为 → 按名称连接行为参数** 点击 **读取连接目录**。当前场景实例可直接选择；组装成员和输入动作须先显式选择组装，即使只有一份也不代选。选择参考项、选择目标文本参数，再点击 **填入参数值**；随后沿原有检查、完整原文审阅、应用草稿、普通保存。

实例列出名称、稳定实例编号、定义编号与来源，重复使用同一定义的演员分开。成员只取所选已保存组装；动作只取该组装已保存输入映射的动作名与物理按键。没有映射不制造默认动作，手输仍可用。只读选择不会撤销原审阅；显式填入后才修改一个普通String，不推断参数用途，也不创建关系。

示范工程内的从空白操作草案保留上轮制作时说明，其参数选择器“尚在规划”的描述由当前行为指南本节更新；本轮保留全部98份示范作者文件，不把本专题当作从空白复建验收。

## 边界与修正记录

纯目录合同与品牌化来源快照不含I/O；Node服务只读一份有修订的World，宿主核对当前原文来源，独立面板把选择交给现有草稿入口。填入前重读并比较目录与修订，组装、映射、成员、实例或元数据变更会要求重新读取。来源保护采用保守World修订，其他保存也可能要求重新选入；不会静默采用首个组装。

辅助能力丢失只撤销其自身读取，不撤销普通行为审阅或声音／动画读取。读取期间更换绑定／脚本／目标实例、删改目标行、关闭窗口或进入普通检查／应用阶段，旧请求都不能再次填入；失效后仍可继续手输。

[初次目录测试](initial/core-fixture-first.log)的两项失败来自测试对11实例的旧数量预期，以及删除文件后登记关系已使World整体不可读；随后修正夹具并保留选中依赖缺失拒绝验证。首次[浏览器记录](initial/browser-first/)因测试驱动的表达式拼接错误停止，修正驱动后重新跑完整流程；没有据此改产品逻辑。代码审阅另发现等待期间撤回／恢复可操作状态的撤销缺口、失效提示残留及实例详情缺定义编号，均补专项后完成最终浏览器实测。

输入值最终仍是普通字符串，不留下持续跟踪的引用。没有自动批量接线、参数含义推断、实时LSP、未保存外部草稿合并、跨绑定修复、从空白UI复建、同场景即时重启、暂停菜单、移动设备或新安装验收。

首轮完整检查另抓到新增请求提示缺少英／日翻译：9496项中8807通过、688条件跳过、1项翻译覆盖失败，来源前后不变；原[完整记录](full-check-initial/status.json)保留。补齐这一个固定键后，翻译覆盖／传输／UI专项通过，并用最终16份来源重跑浏览器。补翻译前的[浏览器记录](browser-before-i18n/browser.json)独立保留，最终范围统一以最终回执为准。
