新包的通用项目流程覆盖：新建空白通用项目、项目自有类型及自定义 YAML 模板、角色背景与 PNG/WebM/MP4 素材、保存并重开、完整备份与原生导入恢复，恢复后的正文和素材逐字节一致。还检查文档离线导出、原生保存对话框的取消和重试、字段编辑、三语言切换与音频播放/定位（[运行记录](generic-second.log)）。二维流程从界面生成场景、修复诊断、构建并在真实 Godot 中无头运行，作者文件不变（[运行记录](label-final.log)）。

## 旧包相同后端的真实 Godot 测试

使用旧 DEB 的随包 Node `v24.20.0`、后端和 WASM，测试驱动与两个示例作品作为独立夹具复制到解包目录，未从源码目录加载运行资源。13 项角色意图测试全部通过，其中 12 项实际运行 Godot，1 项验证旧生成结果兼容性（[记录](character-intent-elevated.log)）。受限环境首次因 Godot 导入时无法创建本地回环套接字失败，改用允许该本地通信的环境重跑后通过。

另从临时作者作品构建并导出后端项目 ZIP，独立校验后解压到新位置，移走原作者与构建目录，再通过真实 Godot 导入、检查脚本并运行；下穿、落地、音频和动画断言通过（[记录](portable.log)、[详情](portable-report.json)）。ZIP 包含角色意图 helper、port、清单及生成层备份；其动作断言覆盖下穿与音画，角色意图动作由独立测试验证。测试 ZIP 未存入仓库，其 SHA-256 为 `5a5acc861a8231e8947ded6cb59aacacd3dfb27fefc4120e26d3d65dc70f8baa`。

隔离 Xvfb 中启动真实 Godot 窗口，确认 X 输入焦点后用 XTest 合成按键：右键 1.000–1.801 秒、左键 2.101–2.901 秒、空格 3.701–3.901 秒。角色行为直接采用随包普通脚本模板，并校验作者脚本字节一致；独立观察脚本每 6 个物理 tick 抽样，覆盖 tick 6–300 的 50 点。x 从 100 到 292 再回约 100，y 从约 180 上升至 171.64 后落回，physicsFrame 204 发布 `physics.jumped`（[结果](window-evidence.log)、[原始输出](window-output.log)）。跳高断言大于 5，依据夹具跳速 120、重力 980 的连续近似峰值约 7.35；双向移动和跳跃事件另有独立断言。首次临时探针误用 scene port，修正后又将跳高阈值误设为 10，均为测试探针错误，最终复测通过。注入器和测试副本的修改分别见 [keyboard.py](keyboard.py) 与 [window-probe.patch](window-probe.patch)。这是合成 X11 键盘事件与软件渲染窗口，并非物理键盘或用户桌面兼容性验收。
