# 声音编辑器就地试听验收

2026-10-16，基线 `cc4e5aa3`／0.1.4 后未发布工作树。进入 **编辑场景声音 → 读取已绑定素材 → 试听音轨**，按当前表单音量／循环播放已选择的 WAV，**停止试听** 随时结束。一次只试听一轨；不自动执行提示或保存。[使用与边界](../../SCENE_AUDIO.md#就地试听音轨素材)。

## 实现与数据边界

纯准备层 `engine/scene-audio-audition.mjs` 捕获当前来源，重新读取并比较完整绑定目录，再验证本次资源字节的登记大小、SHA-256 和 PCM16 容器规则。最多读取 32 MiB；私有字节快照按请求复制给解码器。描述只含资源身份、名称、声道、采样率、帧数与时长，没有草稿或保存权限。目录仍为 `unverified`；本次试听通过不赋予持续磁盘验证、未来构建或源文件保存的授权。

受限读取器复用 `/asset-files/<UUID>`：同源、不跟随重定向，按登记大小受限流式读取，30 秒超时并支持取消，不新增服务 API。独立 WebAudio 适配器在显式点击中启用输出，管理单个播放器、音量与循环；不可取消的解码串行执行，按目标采样率预估 float32 数据最多 128 MiB，随后复核实际缓冲。任何迟到的读取、摘要或解码都不能复活已取消的播放。

编辑输入、刷新素材、检查／应用草稿、关闭／取消、隐藏页面及释放模块均停止试听；切换中英日保留当前播放与表单。应用只更改普通内存草稿；新草稿可再次试听，之后取消保留先前已应用的草稿。服务或浏览器缺少能力时隐藏试听入口，普通编辑路径保留。

PCM 校验器从 `scripts/lib/audio-wav.mjs` 原样移至 `engine/audio-wav.mjs`，旧路径重导出。Godot 完整来源指纹增加新路径，旧生成缓存需重建；适配器仍为 0.11.0，项目协议仍为 4，声音 schema 仍为 1。真实 Godot 运行回归单独执行，不把浏览器试听称为后端运行。
