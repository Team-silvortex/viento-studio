# 逐实例角色运动意图

2026-10-28，0.2.6 发布后的开发工作树。Godot 项目组装中，只要角色同时启用 `characterMotion` 且 `controls` 为 `none`，新构建选择0.37.0意图层，为其行为绑定在 `_ready` 前注入访问局部 `viento_character_intent`。普通脚本调用 `submit(axis, jump)`：轴为有限的 [-1,1] 数值，跳跃为布尔值；同一角色下一项目步只采纳首个有效请求，受理不证明实际位移或跳跃。未重复提交时轴归零，跳跃不在空中缓存。多个实例独立；暂停时拒绝新请求，已接受请求留待恢复后核对；行为失效、场景退出或重入不能沿用旧请求。作者脚本是普通 Godot Node，此端口约束不构成脚本沙箱。

运动、碰撞、移动平台承载、单向下穿和 jumped／landed 仍由已有单次物理求解决定。已有 `arrows` 输入不变；无符合条件角色的工程仍选择原生成分支。作者格式与项目运行协议不升级，旧冻结构建因执行适配器指纹变化须显式重建。Bevy、自由平面角色、单场景构建和设备安装不在本次支持或验收范围。
