纯变换支持动画 schema 1/2/3；只复制明确源轨道，更换显式新编号与实例后追加，保留原轨道、片段、时间、数值、网格、插值与循环语义。当前完整表单及结果预算均验证，JS 拒绝伪造核心回复。核心不查场景、不生成 UUID、不读取或迁移图片；旧核心没有可选 marker 时普通编辑仍可用。

界面复用已读取的场景实例目录，源／目标都需明确选择。失败或选择变化不撤销已有审阅与预览；目录刷新、来源或表单变化、关闭及能力撤回使迟到结果失效。新内容只进入本地字段，重新检查并审阅后才应用普通草稿，再由普通保存落盘。Chrome 验证三语窄窗口与完整操作，结果详见独立报告。

两种正文布局逐步核对作者文件，只在普通保存时修改动画正文；登记、场景、图片和脚本保持。BOM/CRLF 与 `tracks` 外原文保留；结构提案重建 `tracks` 数组，不承诺其中旧数字写法与空白逐字保持。副本编号独立，当前未保存源值及片段名称保留。

Godot 使用保存后的冻结计划：选入命名片段并定位 0.25 秒，观察到原时间轴 0.75 秒，两个实例视觉偏移均为 150、sprite 帧号均为 3，且各自纹理路径不同。序列帧复制继续使用目标自己的图片。此为受控时钟取样，不声称 GPU 图像或其他后端一致性；浏览器与引擎分别验收。
