# 动画状态绑定的构建前检查

日期：2026-10-24。基线为 0.2.0 之后的工作树；本轮没有升版、提交、推送或更新安装。

## 行为与边界

新建项目组装快照在资源读取、后端选择、工具识别和输出目录创建之前，检查已保存、完整匹配的 v1–v5 生成状态控制器。全部绑定和状态一起检查：参数类型／UUID、非空片段是否属于本场景、场景动画是否存在、逐实例目标是否有自身轨道。空参数仍选完整动画，循环片段可用。最多 256 条诊断，超过时保留前 255 条并报告省略数量。

纯领域模块输出有界诊断；Node 快照层从同一次观察的文档身份、路径和修订恢复 JSON token 范围；构建界面沿原诊断端口提供中英日说明和原文跳转。BOM／CRLF／非 BMP 字符不改变 UTF-16 选区语义。修复仍由普通编辑与保存完成。

普通、手改和未知版本脚本不纳入静态判定。运行目录和冻结恢复未接入新门禁；旧冻结工程仍沿历史契约读取。没有作者格式、Rust ABI、运行协议、Godot 适配器或清单升级。运行中动态无效请求仍必须由引擎拒绝。本轮未实现持续引用保护、自动删除迁移、批量修复、Bevy 动画、安装或设备验收。
