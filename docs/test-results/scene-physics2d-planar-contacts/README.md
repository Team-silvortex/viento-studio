# 自由平面角色移动碰撞 → 作者事件 → 动画与声音

2026-10-26，**0.2.4之后的开发工作树**。接通自由平面角色的移动碰撞事件，复用现有脚本与行为编辑流程。入口为 **新建脚本 → Godot / 角色移动碰撞**，角色可使用停止或滑动，无需启用重力／跳跃；操作详见[物理指南](../../SCENE_PHYSICS2D.md#用角色移动碰撞驱动项目事件)。本轮使用隔离作者工程，未升版、提交、推送或更新本机0.2.0安装。

## 实现范围

- Godot执行适配器 **0.28.0** 将可选 `physics.character-contacts2d` 扩至所有已声明的角色碰撞体。沿用行为局部 `viento_character_contacts` 协议1、`started`／`ended` 两信号和两个字符串身份参数；静态体／传感器不获得角色端口。
- 新层从冻结0.26及更早生成器组合**唯一收集器**，不叠加0.27收集器。混合场景沿用原motor移动与起跳／落地回调；纯平面交互运行加入薄层，调用已有移动方法。无头测试沿原观察循环；两个路径都只复用本步已有原生结果，不再做一次求解或额外碰撞查询。
- 继续比较相邻两步的实际移动碰撞集合，去重、先ended后started并稳定排序。**停止输入后仍贴墙也可能ended**：这表示本步移动不再报告阻挡，不表示几何已经分离。未知原生碰撞体不凭metadata认领作者身份；同一设定的多个实例分别识别。
- 参数仍为 `started_event`、`ended_event`、`other_instance_id`。项目事件载荷是对方实例UUID，发布来源记录自身；媒体按原事件流程订阅。已有TXT可原样用于新构建，新增模板只更新适用说明和缺端口提示，其余17项完整模板记录保持。
- 端口在作者 `_ready()` 前注入，每次场景访问独立；回调不能重入移动，关闭撤销集合与连接，不补发ended。正式运行不依赖有界物理trace。
- 新清单、helper、port、场景原脚本和平面桥接按需随工程交付。保存的平面原脚本按冻结schema1／2模板全文核对；删除、篡改、链接、遗漏清单／helper、孤儿层及混合新旧收集器拒绝。没有角色的工程保持旧输出。
- 作者schema、Rust核心／WASM、项目wire和观察协议保持；旧0.21–0.27物理实现原字节保留。没有增加持续接触查询、移动平台、动态刚体、Bevy物理或独立游戏程序发行。

## 首次失败与复验

完整检查首轮[8219项](full-check-first.log)为7763通过、5失败、451条件跳过；[退出1](full-check-first-exit.json)。五项旧测试直接使用当前适配器，却仍按0.23输出和库存断言。修正为明确冻结对应历史生成器并保持检查与交付注册表一致，当前0.28独立矩阵继续覆盖新增路径；最终重新执行完整应用检查，结果见上表。

- 新原生测试初次复制了历史套件的frozenContactsAdapter，错误调用旧生成分支并得到缺端口错误；两次纯检查与两次定向原生失败日志保留在native-pure／native-first及recheck文件中。纠正测试注册表后当前适配器纯检查、真实首例及完整16项通过。该过程未发现生产求解故障。
- Chrome首跑的位置断言把停止位置与首次触墙位置比较，而Godot之后的碰撞步有约0.015安全边距调整。改为与停止前紧邻的触墙步比较，第二跑通过；后端随后补强库存校验，第三跑对齐最终36份源码摘要并通过。三轮[1](browser-run-1.log)／[2](browser-run-2.log)／[3](browser-run-3.log)及原截图完整保留。
