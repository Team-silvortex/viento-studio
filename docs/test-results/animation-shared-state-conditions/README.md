# 动画共享状态条件验收

日期：2026-10-23。0.1.8后工作树，未升版、提交、推送或更新安装。新增事件转换的共享状态来源，旧[载荷条件](../animation-state-conditions/README.md)、[有序分支](../animation-state-branches/README.md)及[状态回看](../project-animation-state-review/README.md)保留当时验收。

## 已接通链路

新建／重编辑条件来源与键 → 独立Rust准入和回执验真 → v4完整源码审阅 → 草稿 → 普通TXT保存 → 冻结项目构建 → Godot事件回调读取共享状态 → 既有进入记录、完成与末态 → 独立工程ZIP。

无selector继续读取载荷；共享状态使用 `selector:{kind:"projectState",key:"combat.enabled"}`，两种条件可混用有序分支。按事件实际交付时的值判断，状态变化不自动触发。键缺失或类型不同连 `ne` 也不匹配；false、0和空串保留。首个匹配后的动画请求失败会停用，不再尝试兜底。

旧声明入口继续拒绝selector，新统一作者入口显式分流。v4独立发射器复用固定静态生命周期，只有新marker也能生成、读取、投影和重编辑。旧v1–v3生成器文件保持，避免旧API静默丢掉新来源。源码封套须严格匹配实际特征和完整再生，BOM/CRLF及旧参数保持。

界面为无条件／事件载荷／项目共享状态，独立保存两种条件缓冲。缺能力保留输入并可明确切回可用来源；无效来源不降级，重新选择合法来源会重新检查预览并撤销旧审阅。三语和排序保持输入，静态图只显示声明，不读取运行状态。
