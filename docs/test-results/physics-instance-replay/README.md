# 逐角色物理输入回放

本专题记录 **2026-11-11、0.2.9 发布后的未发布工作树**：受限 Godot 物理回放增加输入版本 2，按稳定实例 UUID 独立编辑与执行。应用版本保持 0.2.9，执行描述符为 **0.42.0**；本机最近安装验收仍为 0.2.0。本轮不提交新版本或更新安装程序，旧发布与开发专题保留原时点。

操作见[物理指南](../../SCENE_PHYSICS2D.md#逐角色输入)，接口见[纯合同](../../../engine/README.md#逐实例物理输入的纯合同)，边界见[执行中间层](../../BACKEND_MIDDLEWARE.md#逐实例物理回放的边界)。

## 实现范围

- 输入版本 1 的全局五动作保持；版本 2 每步按实例提供五个显式布尔值，遗漏实例逐步释放，跳跃边沿分别维护。固定 30 步、1/60 秒、全程序最多八个不同输入目标，末步释放；取得完整观察仍限最多八个物理角色。
- 纯合同负责输入、冻结计划目标与受限编辑；HTTP／Node 宿主在任务、会话及暂存分配前复核物理 character／arrows 资格，包括验收内嵌输入。界面目录不授予执行权限；作者文档保存和资源迁移单独检查 Scene2D 实例成员。
- Godot 先认证完整冻结库存，再为本次会话派生受限输入继承链；只替换已识别的输入读取，停止／滑动、重力、碰撞及平台继续使用原求解。未知继承及超预算拒绝，成功、失败、取消及观察回调异常后清除临时脚本和 UID 文件。旧 v1 驱动与全部历史永久生成脚本保持原字节，没有新项目或物理观察线协议。
- 独立目标视图只持有当前选择；明确转换才复制整份全局输入。时间轴／范围操作只改所选实例，同名角色显示目录序号和完整 UUID；轮询及三语保留焦点与原输入。保存、运行、验收及资源包继续沿已有入口。本轮未增加 shell CLI 物理回放选项。

仍限单入口场景、无作者行为／声音／动画的 Godot 项目。Bevy 物理、持续输入、真实键盘设备、跨场景及媒体组合均不在本轮支持范围。适配器指纹改变后需明确重建旧冻结构建，不自动迁移作者文档或旧产物。

- 同一 OC 的两个实例向相反方向运动，在第 **7／13 步**独立起跳并与指定墙体发生真实接触；未列入输入的第三个自由平面角色保持静止，controls:none 实例不被驱动。检查全部样本的步、时间、场景／访问／实例／对象／物理体及冻结原文来源。

- 未知、静态、传感器、controls:none 及无物理体五类目标分别返回422与准确目标错误，界面未知目标也在本地阻止提交。
