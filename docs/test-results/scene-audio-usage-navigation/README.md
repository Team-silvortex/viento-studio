## 实际改动与验证重点

- 核心在私有目录中保留已校验行为原文和 JSON 索引，仅允许该目录自身的匹配对象取精确范围。重复 UUID 分别定位自己的绑定／参数；BOM、LF／CRLF／CR、中文、emoji、转义 UUID 和转义参数名均覆盖，伪造、代理及跨目录对象被拒绝。
- **定位提示** 按当前会话、稳定提示编号、行对象及节点归属检查；重排、换轨、删除或关闭重开后，旧按钮不能指向替换行。复核同时加强既有轨道“查看使用位置”的旧会话守卫。
- **查看参数原文** 只展示上次读取的快照，返回精确只读选区；不切换主文档，不再请求服务，也不取得保存或试听权限。刷新开始、切轨、隐藏、能力撤回和关闭清除快照，迟到回复和旧按钮不能重新展开。
- 日语切换曾改变混合文字的字体匹配和换行，使内部滚动 20→18。原文框显式保留未知作者语言，通用视口测量镜像沿用最近语言属性（包括空串），修复后中英日保持相同节点、选区、焦点和滚动。日语窄屏重新定位另有实际范围测量及截图。

浏览器只修改临时合并样例。取消与查看均不改文件，Apply 仍只应用普通草稿；普通 Save 只更改 `documents/audio/demo.json`，保留 BOM／CRLF，其他 **18** 份作者文件保持。查看期间 **0 次素材字节请求**，选中匹配不增加使用位置请求；未完成数字输入、已批准方案、既有草稿保持。
