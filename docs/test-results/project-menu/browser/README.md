# 运行菜单作者现场

本目录保存最终实际 Chrome 作者流程：普通菜单 TXT 的创建与登记、三个 String 参数的补齐、编辑、取消、校验、应用、保存、重新读取，以及其余三个场景的菜单绑定。

- 11 张原始截图，包含中英日三语各 3 个 390 px 布局及 2 张桌面截图；浏览器错误为 0。原始 `pause-*` 文件名来自复用的捕获标签，图像与报告内容为本轮菜单流程，保持原字节和名称。
- 28 个生产文件、上轮暂停作者现场 102 文件、官方示例 98 文件的前后哈希一致。
- `author-final/` 为保存后的 104 个本地作者文件，登记 36 份文档和 9 个素材。
- `browser.json` 为原始报告；`evidence-inventory.json` 逐项记录本次复制的全部 116 份原始证据文件哈希。

标准迁移包 `author-final.viento.zip` 使用现有作品库导出格式：103 份标准作者数据和 `manifest.json`，包含全部 9 份素材和 9 份素材登记。顶层 `README.md` 不属于该格式的作者数据，作为原样侧文件保留。

`author-archive.json` 记录未修改生产 Rust 导入模块的实际恢复结果：103 份标准数据逐字节匹配，恢复前后构建快照相同；再复制顶层说明即可还原全部 104 份本地文件。本次验证通过临时命令行包装器调用生产导入模块，未自动操作已安装桌面程序的文件选择器。
