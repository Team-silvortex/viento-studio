包装脚本保留作者原文和返回值。记录中的命令序号表示进入时已经执行到的位置，不表示该次请求已播放。终止快照与执行/完成回执各自保留；运行失败、取消和超时不会补造进入或终止数据。每次进入消耗原有请求预算中的 select 与 play，最多128条。

仅新严格控制器项目采用 **protocol 9／Godot 0.18.0／库存10**。普通动画保持p7、无动画p4，旧协议1–8和库存5–9继续读取。新项目1024非资源文件与128资源的预算贯通生成、1152项目文件清单和1154条目ZIP，其他项目保留旧预算。
