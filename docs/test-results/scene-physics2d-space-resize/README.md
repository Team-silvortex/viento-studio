## 操作和分层

矩形提供右、下及右下手柄，围绕固定中心修改完整宽高；圆形右侧手柄修改半径。尺寸与偏移模式互斥。按钮与空间图方向键每次改变 1 单位，Shift 为 10；普通参数输入框保留自己的按键。缩放、聚焦和查看只影响视图。

纯尺寸域绑定品牌视图、碰撞体与原形状，复用原 Rust 数值规则。手势转换复用既有捕获／逆 CTM／取消机制，指针期间只有临时轮廓；松手后控制器核对当前源会话和检查结果，只改变化的 Width／Height／Radius 字符串，撤销旧审阅。原中心、offset、形状类型、其它碰撞体与场景位置保持。重新 Check、完整 Review、Apply 与普通 Save 各自负责。

零变化保留审阅和数字拼写。越界拒绝，不截断或翻转；多指、失焦、捕获丢失、旧视图／手柄、缺失目标、模式改变和关闭重开不能提交。检查或空间刷新后查看范围重新适配场景；空间失败仍可沿原字段修改。没有新增物理格式、服务端口、后端协议或保存命令。
