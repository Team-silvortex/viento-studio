# 行为参数音轨选择验收

2026-10-16，基线 `cc4e5aa3`／0.1.4 后未发布工作树。**编辑场景行为 → 读取场景音轨 → 选择音轨 → 填入音轨编号**，随后检查完整修改、应用原文草稿，再普通保存。[完整操作](../../SCENE_BEHAVIORS.md#将音轨编号填入行为参数)。

## 行为和分层

任意文本参数均可显式选入当前场景已保存的音轨 UUID；数字和布尔参数不提供该助手。读取和选择本身不改值、不使表单变脏、不撤销已审阅修改，点击填入才沿普通编辑路径更新参数。目录保留作者音轨顺序，显示序号、音乐／音效、UUID 及声音声明路径。`track_id` 没有额外语义，不修改脚本、不自动添加关系，也不保证未来删除音轨后字符串仍有效。

独立纯目录契约捕获场景与声明身份，基于完整行为来源生成私有品牌目录。Node 只读接口 `POST /api/scene-audio-directory` 复用现有鉴权，读取 World 元数据快照，验证 Scene2D v2／v3、唯一 audio 关联、反向引用和声音语义；不构建全场景、不读 WAV 字节或校验可播放性。超过 256 个无关素材、WAV 缺失／损坏均不阻塞身份目录。没有关联返回 empty，歧义、错误登记或正文拒绝。

宿主通过独立读取端口复核行为与目录的场景身份／修订，各异步边界检查源归属。表单保持可编辑，迟到读取不重建输入；关闭、改来源和旧行控件不能误填新会话。目录错误保留普通输入和审阅；可选能力使用独立代次，撤回只撤销目录请求，普通行为提案仍可应用。声音目录不加入普通行为审批或保存依赖。
