## 验证流程

真实 Chrome 从两步路径建立草稿，经检查／应用后明确重跑。再次通过真实文件 input 导入；无效 JSON 保留原文，取消保留载入对象和有效回放。修改输入不会自动改预期：首次重跑产生不符并停止；明确编辑预期后重新检查、应用与重跑才通过。导出载入版本与原路径文件分别校验字节。编辑期间禁止冲突文件／运行操作，迟到文件无法覆盖；源码、手动路径和待采用结果保持。

中英日 390px 检查 textarea 节点、焦点、选区和未完成文本保持，无横向溢出；滚动后取消按钮实际命中测试通过。IME Escape 保留编辑，真实 Escape 只取消子编辑并把焦点还给入口。作者条件变化独立撤销旧回放，编辑定义可继续保留；关闭／重新打开作者会话清除临时用例。

取消作者草稿后，原保存态 Godot 工程通过 GUI 规划、构建、运行，真实进入 idle→attack→idle。该运行独立于手动预期对照，不把手动结果当运行回执。25份源码与36份临时作者文件前后字节一致。

## 审计与边界

输入缓冲、检查候选和父载入对象分别持有；revision／原文／会话守卫拒绝陈旧应用。检查失败或超限输入原样保留，没有 maxlength 截断；可读缩进超预算时采用紧凑表示。已有作者状态表、原用例格式与求值核心、Rust/WASM、后端及 protocol10／Godot0.19.0／清单11保持。本轮未升版、提交、推送或更新安装。

用例仍为手动 JSON，无结构化步骤表单或工程登记；明确导出才持久保存。比较仅覆盖目标状态与转换有无，不证明动画实际运行或同目标分支身份。安装版、Android、Bevy 动画及新的原生逐用例跟踪未在本轮验证。
