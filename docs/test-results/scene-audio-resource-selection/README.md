# 已绑定声音素材选择验收

2026-10-16，基线 `cc4e5aa3`／0.1.4 后未发布工作树。通过现有 **世界与对象 → 绑定资源** 为声音文档绑定已登记 WAV，再到 **编辑场景声音 → 读取已绑定素材** 为音轨选择新素材，检查后应用草稿并普通保存。[操作与边界](../../SCENE_AUDIO.md#替换音轨使用的素材)。

## 实现与数据边界

新增只读 `scene-audio-resources.mjs` 与独立 `createSceneAudioResourceProposal`。目录复用现有声音创建查询服务，仅提供已绑定、可用的 WAV 登记；来源、已保存基线、World、声音文档和完整目录以冻结品牌捕获。音轨可替换资源，原身份与提示保持；仅换资源时修改对应 `resourceId` 值 token，保留原文其他字节。此前四种提案继续按原契约工作，不获得资源替换权限。

目录由用户显式读取；普通音量、轨道与提示编辑不依赖这项服务。失败保留表单和当前选择；目录不再包含当前素材时显示不可用并保留其 ID，不自动换音。读取新目录或修改输入撤销旧审阅。应用资源提案前宿主重新读取目录，核对完整上下文与来源摘要；所有异步边界及最终同步写草稿前检查当前来源。服务未提供此能力的平台仍保留原声音编辑。

**绑定与正文保存是两次独立操作。** 取消声音编辑不撤销已经保存的资源绑定；应用后若外部更改登记，构建会再次校验，不能把两步视为跨文件原子事务。替换不删除旧素材、登记或多余绑定。目录保留 `unverified`，不宣称已检查实际 PCM／SHA-256；构建读取并验证字节，只冻结实际使用的去重素材。
