# Bevy 项目入口临时验收：浏览器实测

在隔离的作者工程和构建缓存中，用真实无头 Chrome 156、HTTP 编辑服务及本机 Bevy 0.3.0 运行程序完成端到端验证。使用双场景项目，选择入口实例并运行有限控制回放；另一成员场景中独有的实例不出现在目标列表。

从完整回放采样生成临时验收，首次运行两项检查均通过。随后手动更改一项位置预期，运行成功但验收明确显示未通过，未把执行完成误标为验收通过。生成、运行和检查过程中，26 份作者文件的哈希摘要前后一致；测试过程中不保存用例文档。
