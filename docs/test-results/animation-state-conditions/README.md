## 完成范围

事件转换增加明确的布尔、数字或字符串条件。类型不同时所有运算均不匹配；数字精确比较，负零归一化。未满足条件时处理该事件但不转换、不发动画命令，其他订阅继续运行。无条件与自然完成路径保持。同一状态的同名事件仍只允许一条转换。

独立Rust条件检查/求值与新可选marker保持核心权威；旧操作与v1发射器保留。统一facade把有条件表交给新检查，版本codec把含条件声明绑定到v2固定源码，完整源码最多64KiB（含BOM/CRLF）。数值阈值按IEEE64字节生成，文本按UTF8编码比较。界面控件、表格、图、提案与普通保存分别负责各自状态；条件不新增行为参数。

## 保留、修复与限制

8618份既有示例、历史、证据和版本文件保持；原2452评分与2628证据对象不改写。44份旧v1发射器、旧wrapper及后端文件保持，已安装AppImage保持。WASM因新增可选条件能力更新为717057字节。详见[保留检查](preservation.json)、[来源指纹](source-hashes.json)、[机器摘要](summary.json)和[最终检查](final-check.json)。22模块/43项声明能力、运行协议7、Godot适配器0.16.0与清单8沿用。

真实探针发现Godot解码字符串遇内嵌NUL截断，改为比较UTF8的base64编码防止阈值误命中前缀；空字符串编码另有引擎错误，已单独处理空值并重跑原生。NUL在Rust和声明中保留，不能据此声称Godot载荷完整往返；详见[string探针](string-probe.log)。新条件声明采用数字阈值每项固定32字节的保守32KiB预算，解决Rust与JS小数/指数写法不同导致的边界不一致。初次和中间日志、浏览器证据保留，最终结果以上表为准。

当前仍是单场景共享播放头；不包含复合表达式、共享状态条件、多分支优先级、混合、骨骼或Bevy动画。浏览器使用隔离且预先准备的工程；未更新安装、未验Android或其他系统。
