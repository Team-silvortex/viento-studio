## 复现与适用范围

使用可信的Godot可执行文件路径运行：

```sh
VIENTO_GODOT_BIN=/absolute/path/to/Godot node scripts/tests/scene-physics2d-targets-smoke.mjs
```

脚本默认启动`/usr/bin/google-chrome`；可将其它Chrome可执行路径作为第一个参数。只写临时作者工程与新的专题证据子目录，拒绝复用非空结果目录，完成后清理临时工程和进程。实际运行记录不包含本机安装升级、Tauri窗口或Android设备验收，也不扩展Bevy物理、重力、动力学、关节或仿真预览结论。目录核对保存态身份，场景草稿、投影运动默认值、其它资源以及完整工程有效性仍由各自编辑／构建流程负责。
