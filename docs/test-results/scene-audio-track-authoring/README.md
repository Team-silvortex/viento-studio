# 已有声音轨道复制与移除验收

2026-10-16，基线 `cc4e5aa3`／0.1.4 后未发布工作树。已有声音面板增加 **复制音轨**、**移除音轨**，继续走检查完整原文、应用草稿和普通保存。操作见[轨道管理](../../SCENE_AUDIO.md#复制与移除已有声音轨道)。

## 实现与边界

新 `createSceneAudioTrackProposal` 接受完整轨道与提示。保留轨道的身份、素材和相对顺序保持，新轨道只在末尾追加并复用原文已有素材。轨道结构与提示结构分别按 UUID 复用原文片段；无结构变化时仍按叶 token 修改。三个旧 API 分别保持原契约，私有提案模式在应用前重算。Rust 继续拥有语义，界面与来源宿主只应用普通草稿，不获得文件保存或播放权限。

界面复制当前轨道的设置并分配新 ID，不自动复制或创建提示。最多 16 轨，至少保留 1 轨；仍有提示引用时不能移除，先显式换轨或移除提示。复制、移除、语言切换保留半成品输入，修改会撤销之前的审阅。取消不写入。

移除不删除素材、资源登记或原素材绑定。元数据允许保留最终轨道所需集合之外的绑定；构建只冻结当前轨道实际使用的素材并去重。新资源登记和素材替换没有接入本表单。

**没有提示引用，不表示没有行为引用。** 动态脚本中的轨道 ID 由作者检查和更新，本表单不自动解析或重写；实际调用已删除轨道时，Godot 报告 `runtime_behavior_audio_track`，不会自动改播复制出来的新轨道。

## 实际操作与交付

复制原音乐轨道后单独修改用途、音量和循环，复制动作不增添提示。将旧音效提示显式改到新轨道后，才能移除旧音效轨道；再给新轨添加停止提示。普通保存只修改声音 JSON，场景、素材及登记字节保持。重开后保留新身份与提示绑定，Godot 依次执行音乐播放、0.25 秒新音效播放、0.5 秒两轨停止。

Chrome 下载 **58,516 字节** ZIP，独立验证 **8 个文件／1 份 WAV**；异地导入与运行得到相同事件。SHA-256：`117007c7e4fb976a8841b069aed47c1da15d08ad4fc32b5d06817f0c092aaee4`。这是需要 Godot 的源工程交付，不是独立游戏安装器。

**7545** 份旧示例／历史／证据、已安装 AppImage 及 2136 个旧评分对象保持。[清理记录](cleanup.json)只回收本轮生成且逐文件核对过的桌面资源副本，现有移动副本保留。版本仍为 0.1.4，未提交推送或更新安装包；本轮没有物理声音输出、Android 或其他桌面系统验收。
