## 实装发现与修复

WebKit收到组合状态的Escape后，原子编辑器直接返回，浏览器继续生成不带组合信息的原生`cancel`事件，外层新建脚本弹窗因此尝试询问是否丢弃。第二轮探针确认`KeyboardEvent.isComposing=true`，排除了测试构造失效。修复在可见的子编辑区阻止Escape默认关闭与传播，组合输入和重复按键不取消编辑；普通Escape仅取消子编辑，其他组合输入保持原行为。[诊断](native-smoke-run-2/native-animation-trial-case.json) · [最终探针](native-smoke-run-4/native-animation-trial-case.json)。这是合成IME保护检查，不等于实体输入法设备验收。

第三轮已通过上述修复，但测试完成760px检查后，仍展开的目录抽屉遮罩挡住重开按钮。测试改为在全部窄屏断言结束后恢复宽窗，再真实点击重开；没有修改布局或使用JS点击绕过遮罩。首轮、诊断、测试修正和最终运行分别保留。

## 复现与边界

命令与开关见[本次配置](commands.json)及[Linux原生测试指南](../../TESTING.md#linux-原生界面)。测试使用私有驱动、独立XDG目录、D-Bus、Xvfb和一次性工程；驱动由已核对摘要的发行版软件包私有解包及离线Cargo安装准备，没有安装系统包。本轮工具和解包目录验收后清理，复现时需重新准备。

二维样例的OC、图片和配方在启动前准备，因此未覆盖全部上游创作入口。Godot有限无头运行不等于图形游戏或独立发行包验收。动画手动试算不保存作者状态表，未验证保存态重编辑；假定完成不等于实际动画完成。用例JSON的Blob／File传输经过明确仪器化，未声称该用例格式的原生文件对话框与磁盘下载通过；独立作品库测试覆盖真实GTK分享／工程归档保存。

本轮不外推到Bevy、3D、Android、Windows或macOS，也不改变功能成熟度评分。旧安装、发布和开发专题证据保持原时点。
