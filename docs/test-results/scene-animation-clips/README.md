## 独立复查修复

旧 reader 的浮点容差比较会把字符串 `"0"`、null、false 或空数组隐式转换成 0。现新旧动画协议都先要求有限、非负数值，再对合法数字进行打印误差比较；拒绝不产生回执。新增 transport 桥接同时严格分离并校验三个参数，额外 `document` 不能覆盖冻结声明。两类复现均加入回归；最终中间层专项为 91/91。

全量检查另发现动画与配方共用“打开片段声明”翻译键；现动画入口改为“打开动画片段声明”，保留旧配方翻译。完整三语覆盖与观察专项 23/23 通过，并在最终翻译指纹上重新运行 Chrome；前一次成功浏览器记录也保留。

旧动画控制 starter 增加 `has_method` 守护，没有动画控制能力的项目不会调用不存在的方法。新片段 starter 仍走通用脚本草稿和普通保存。
