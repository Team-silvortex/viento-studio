# 动画组合条件验收

日期：2026-10-23。0.1.8后工作树，未升版、提交、推送或更新安装。既有[共享状态条件](../animation-shared-state-conditions/README.md)和历史证据保留原记录。

## 已接通链路

新建／重编辑全部满足或任一满足 → 添加、删除和排序1–8个标量条件 → 独立Rust准入和桥接回执 → v5完整源码审阅 → 草稿与普通TXT保存 → 项目构建 → Godot按序短路 → 既有进入、完成和末态观察 → 独立工程ZIP。

条件可混用事件载荷与项目共享状态，保留作者顺序。all遇第一项不匹配停止；any遇第一项匹配停止，只读取实际达到的叶子。缺键/类型不符连ne也不匹配；写状态不触发转换，读取发生在事件交付时。重复共享键不合并为快照。与firstMatch分支混用时，只有省略condition才是兜底；匹配后的转换失败不再尝试兜底。

平面组禁止嵌套、空组及超过8项；单项组仍保留v5。新marker独立提供组合准入，旧两个入口和v1–v4封套继续拒绝组。完整声明仍32KiB，数字预算逐叶32字节；完整源码含BOM/CRLF仍64KiB。旧四个发射器与运行文件逐项保持。

单条件/组分别保存缓冲，all/any共享组列表；初次复制单条件有提示，原组首次切回单条件从无条件开始且明确提示。更改/排序撤销审阅，未知模式拒绝并可显式恢复，能力撤销保留输入。静态图只显示声明，不代表条件求值。
