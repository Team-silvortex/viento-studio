## 本次发现并修复

- 原文替换后，WebKit 保留编辑历史，但 Ctrl+Z／Ctrl+Shift+Z 没有触发撤销／重做。新增独立快捷键接线，调用同一浏览器历史，保留焦点、文档归属、忙碌、弹窗及输入法保护；不维护第二份正文历史。
- 900×800 窗口中，新增工具条和媒体预览将正文区挤得过矮。窄窗口媒体区域占比由 35% 调整到 25%，保留原有正文最低可用高度与媒体适配断言。

失败复现与修复后验收分别保存。另修正两处过时测试假设：默认新项目已是通用空白模板；文档索引标识不等于原文路径。共享样例采用明确增量和身份集合核对，并保留原始素材登记数量要求，没有放宽功能断言。
