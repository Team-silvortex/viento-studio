# 行为参数选入动画片段：工作树验收

日期：2026-10-20（Asia/Shanghai）。源码版本保持 0.1.6，承接未发布命名动画片段工作树。没有升版、提交、推送或更新安装。操作见[片段编号选入](../../SCENE_BEHAVIORS.md#将动画片段编号填入行为参数)。

本轮增加独立的保存态动画目录、来源绑定、可选宿主端口与三语选择子组件。显式填入只更新普通字符串参数；审阅、草稿应用与普通 Save 保持。动画语义继续由现有 Rust/WASM 校验，执行仍使用已有 Godot protocol 6；没有新作者格式、运行协议或 Studio 模块。

## 范围与边界

- 目录与服务验证动画/行为独立 UTF-8 限额、来源品牌、稳定身份、双向登记、一致快照和读取冲突；不读图片或执行完整构建。
- 旧动画和空片段不升级或产生写入；目标实例/图片未修好仍允许读取声明，整体登记损坏由 World 层拒绝。目录不保证构建成功。
- 宿主验证每个 await 的来源身份、独立能力撤销/恢复、旧服务退化；音轨与动画目录互不串用。
- UI 验证暂选、显式填入、普通审阅、焦点/选区、行与绑定变化、迟到回复、关闭及中英日小屏幕。
- HTTP→选择→草稿→普通保存→冻结计划覆盖 documents 和 v2 design-data/data-template 两种正文布局，保留 BOM/CRLF，只有行为正文变化。另用真实 Godot 读取实际保存的 clip_id 并产生 select/play 回执。

计数、当前源码指纹及限制见 [summary.json](summary.json)，历史保留核验见 [preservation.json](preservation.json)，评分理由见 [score-review.json](score-review.json)。各测试分组有重叠，不合并计数；上轮已有 Rust 原生、ZIP 或安装验证不改标为本轮重跑。

## 检查中发现的问题

新增 API 最初只加入处理路由，未加入认证/JSON 类型检查入口；HTTP 回归暴露后已补全，未授权、错误 token 和非 JSON 请求分别拒绝。自定义正文目录的首轮测试漏设 v2 和 data-template，修正临时工程后重跑；不是对产品目录契约的放宽。首次失败日志保留，最终结果以完成的重跑为准。

本轮填入的 UUID 仍是普通字符串：不自动识别变量、不保护片段删除、不自动迁移引用。没有动画状态机、混合、Bevy 视觉动画或新安装/移动设备验收。
