# 新建音轨的定时／行为触发选择验收

2026-10-15，0.1.3 之后的工作树。本轮补齐 **构建与运行 → 场景声音设置 → 播放方式**：逐轨选择默认的定时播放或由行为触发，允许混合或全部行为触发；后者不生成初始播放提示。

## 实现与使用边界

纯创建规划只扩展草稿意图 `startMode`；旧输入省略时生成字节完全一致。行为模式不传开始时间，但界面保留未完成时间和稳定身份，切回后恢复校验。临时提示身份仍通过已有 Rust 规则验证，最终删除行为轨的初始提示并复验；声音 schema 1、Rust ABI、保存命令、三文件事务和运行协议保持。

行为音轨仍完整登记并核对 WAV。选择此方式不会自动创建脚本或绑定，也不会立即播放；随后通过[项目声音接口](../../PROJECT_AUDIO_CONTROLS.md)控制已声明音轨。已有文档的结构修改仍使用普通原文编辑；新建表单与字段编辑相互独立。
