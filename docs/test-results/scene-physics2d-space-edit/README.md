## 操作与边界

默认空间图只查看和选择；开启 **调整碰撞偏移** 后，可拖动选中形状，或使用方向按钮、空间图方向键微调（1 单位，Shift 为 10）。另有缩放、显示全部及聚焦选中。指针过程中只有临时轮廓，松手才更新参数表；抓取点和屏幕逆坐标保持，场景实例位置不变。

纯领域从品牌空间视图提出有界偏移，复用原 Rust 数值规则；渲染器只维护手势和查看状态；控制器复核当前来源、选择和检查结果，仅更新变化的偏移轴并撤销旧审阅。必须重新检查，才可继续调整和应用。普通 Save 仍独占正文持久写入。

取消手势、越界、无效坐标、多指、窗口失焦、捕获丢失、旧视图或关闭重开都不提交；零位移保留原数字拼写和已检查审阅。检查或空间刷新重建视图时重新适配全场景。空间失败不阻断字段编辑；缺失目标不能产生位置提案。未增加尺寸手柄、场景实例移动、自由平移、物理求解或运行协议。
