# 二维作者世界工作平面

本专题记录 **2026-11-11、0.2.9 后续未发布工作树**。本轮按用户明确的方向完善创作范式：最终 Studio 由 ns-nova 原生实现接替，JS／Node／Web／Tauri 是当前实验承载；交接资产是作者语义、稳定身份、命令效果、来源／修订、运行与交付合同及可重放样例。

实际补齐的功能是 **世界工作平面与运行 viewport 分离**。旧画布将绘制与命中硬裁到 viewport，尽管作者位置允许 ±100000；现在视口外实例可以显示、选择和布置。应用仍为0.2.9、Godot执行描述符仍为0.42.0；作者格式、构建／运行协议及安装程序均不因此改变。操作见[工作平面指南](../../PROJECT_BUILD.md#世界工作平面与运行视口)，方向见[架构](../../ARCHITECTURE.md)。

## 实现与边界

- 独立 `scene-workspace-view.mjs` 接收 `{position,size}` 几何，不取得身份、选择状态、DOM、保存权或引擎对象；全部取景包含 viewport 与所有逻辑矩形，选择取景由宿主筛选实例。有限数据、范围和预算严格捕获，返回脱离输入的冻结DTO，Node／浏览器使用同源样例。
- Canvas 只以自身画布边界裁绘，运行 viewport 保留背景与边框作为参考。命中依然按实例中心、尺寸和倒序叠放；两个实例共享 OC 也能分别选择。移动仍复用原有 Rust 位置规则、继承权限和保存历史。
- **适应运行视口**／0／Home 保持原取景；**聚焦全部对象**／**聚焦当前选择** 只改临时视图。显式取景在实际 resize 后重算，普通模型刷新保持当前取景，手动平移／缩放则保持世界中心。取景取消未提交拖动，不提交中间位置、不改变选择或消耗撤销历史，也不撤销已审阅保存。
- 缩放允许1e-6～16，小比例显示小数。网格只绘可见世界，支持负坐标，每轴最多256条；最细32世界单位，远景按二倍间距稀疏，作者32单位吸附不变。动画仍变换独立视觉层，取景依据逻辑位置／尺寸，不拟合旋转或偏移后的视觉范围。

本轮只补作者工作平面，**未接运行相机／角色跟随**；运行 viewport 仍取原声明。Godot 的原生坐标观察不证明窗口里能跟随角色。原生 GUI 将承接同一语义和验收样例，当前未扩展 Rust ABI 或创建新的 JS Provider／通信框架。
