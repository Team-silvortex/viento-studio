# 菜单按钮的成员名称接线

2026-11-13，0.2.10工作树／下一版0.3.0／本机安装0.2.0。操作见[菜单指南](../../PROJECT_MENU.md#按名称连接菜单按钮)，实施边界见[架构](../../ARCHITECTURE.md#菜单按钮目标的作者辅助)。本轮没有升版、发布、提交、推送或安装。

## 本轮实现

- 官方场景菜单的 `items_json` 可按名称选择明确组装中的其他成员，替换已有 `scene`／`retry` 按钮目标，或显式填写标识、文字、命令并追加。
- 新 `retry` 使用 `values:{}`，不猜初始值；既有条目的初值、转义、数字表示及空白原样保留。仍受8项、4096 UTF-16单元和8192 UTF-8字节限制。
- 只修改当前一行输入。读取、选择、取消、同目标不改变参数与审阅；真正改值后继续检查、完整审阅、应用原文草稿和普通保存。
- 插入前重读保存态目录，复验修订、全部目录内容、会话／绑定／行节点、原参数和选择。官方脚本识别使用会话参数接口，最终普通检查另重核全部脚本依赖；目录读取本身不证明重新抓取官方脚本。
- 独立纯JSON编辑与界面所有权分开；宿主接口、作者格式、事务、运行协议与Godot0.49.0保持。Bevy/ns-nova没有新增运行实现。

## 样例与测试范围

浏览器使用现有正式空白模板结构，作者正文、素材和登记起始均为空；作品库创建和系统目录选择并未自动化。全部10份正文通过实际Studio控件创建；不注入预制Scene2D、玩法参数或菜单JSON。辅助运行期间无关sentinel绑定逐字节保持。三张截图验证窄屏可滚动、无横向溢出；不等同实体设备或安装验收。

这是菜单接线的三场景纵切，不是整款参考游戏从空白完成。持续运行、跨启动存档、独立发行、字体闭包及脚本创建后返回原场景仍在路线中。旧专题的通过记录保留原时点，本轮不覆盖或重新标注。

## 独立测试驱动修正

首轮浏览器调试未等待目录复核完成就读取输入，已改为等待实际回填；首次原生观察器假设工程启用动画，最小菜单工程并无该模块，已增加独立只读观察器。两次失败分别保存于[失败记录](failed/README.md)，最终浏览器／原生／离线证据与失败分开。观察器不写共享状态、不调用玩法端口、不推进项目时钟，生成运行脚本和作者原文未修补。驱动命令及最终来源见[清单](checks/author-drivers.json)。

完整应用检查覆盖2,311份捕获来源。原始来源守卫如实记录：期间唯一变化是本轮新加的独立原生smoke驱动，另新增最小只读观察器；产品模块和正式 `*.test.mjs` 均未变化。两份测试驱动已随后由真实Godot原窗口／离线执行并分别核对哈希，见[来源范围](checks/full-application-scope.json)。不把该原始守卫写成“所有文件不变”。
