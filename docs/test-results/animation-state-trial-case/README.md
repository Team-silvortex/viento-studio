## 契约与限制

只有parse/create得到的冻结品牌可序列化／重跑。完整JSON先检查，拒绝重复键、未知字段和版本、非法标量及矛盾无转换期望；初始状态沿作者语法，1–32步／64KiB规范化输入／128KiB UTF8原文。核心测试覆盖精确边界、NUL/Unicode/-0、失效品牌和无WASM解析。预期目标可以已从当前表删除，以普通不符呈现；缺少初始状态独立报错。首个不符后actual/result为空，不评估后续步骤。

预期只比较目标状态与转换有无；同目标不同分支可能都符合，不宣称选中了同一分支。完成步骤依然假设选中片段通知已到达，共享值每步独立。用例尚未登记到工程，无运行断言、脚本副作用或自动保存。未验证安装版、Android设备、Bevy动画或新的原生逐用例跟踪。
