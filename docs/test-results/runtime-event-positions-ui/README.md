# 事件位置只读观察

2026-10-28，0.2.5之后的未发布工作树。项目构建与运行对话框现在可以查看事件发布与逐接收者的业务帧、空闲帧、物理帧以及保留范围。观察区只读取验证后的快照，独立于原事件账本和运行对象视图。中、英、日文案随语言设置切换。

未确认仅表示没有观察到投递回执，回调仍可能已经执行并产生影响。空收件人立即结清；取消或其他不完整运行保留有效记录。宿主校验任务、构建、后端、目标、冻结场景和快照归属；切换任务、失效快照或缺少能力会清空旧内容。旧协议和没有项目事件能力的 Bevy 不显示这个面板；没有更改后端协议、事件预算或项目数据。
