## 修复与失败记录

真实 Godot 发现 `is Object` 会在已释放实例上抛错误。新 starter 的三处守卫改为先检查 `typeof`，再确认实例有效；订阅前已释放、订阅后释放再回调及退出均通过。[修复前复现](native-ports-focused.log)和[修复后探针](native-ports-fixed.log)保留。

首次浏览器脚本误读“已有行为”目录、HTTP 测试误用原始回执字段、原生夹具使用不支持的 null 载荷及旧字段预期，也都保留在 initial／first 日志中。首次通过的 Chrome 仍使用修复前 starter，其目录保留但不作为最终源码验收；最终以 **browser-authoring-1792488428503** 为准。最终源码冻结后分别重新跑作者、Chrome、保存构建、原生与完整应用检查。
