## 本轮修复的边界

1. 非循环播放头在极小差值舍入到末尾时必须进入 finished，不能输出下一次调用不接受的 playing@duration。
2. 后端逐帧累计可能与 Rust 从上一条命令一次推进产生差异。改为以最后命令为固定起点，实际 Godot 的 0.2 秒起步加八次 0.1 秒推进再 play 可一致重播。
3. 关闭音频已经进入离场阶段，reader 此后不再接受动画命令。视觉推进诊断失败后也立即退出执行，不补造成功回执。

## 兼容与范围

含动画项目使用 Godot 0.14.0、project protocol 5、生成清单 6；无动画项目保留 protocol 4／清单 5，旧单场景自动播放与生成文件保留。新增的 `project.animation-control` 是后端能力；Studio 仍为 22 模块／43 项声明能力。执行请求返回 true 仅表示入队，最多 64 待执行／256 次受理，每次新运行重新计数。

未包含逐轨／片段选择、动画混合、骨骼、3D、Bevy 动画或 Android 设备验收。本机已安装 0.1.1 AppImage 保持；历史源码报告和作者示例原样保存。
