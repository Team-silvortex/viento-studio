## 作者与执行边界

新入口只传当前场景身份；组装编辑器重新读取保存态目录，预填单成员与入口。目录中找不到场景、作者会话／来源或场景选择变化、存在未保存正文、任务忙碌时不使用旧选择。预填草稿可以修改成员、启动场景、名称、保存位置和文档类型，关闭时按既有未保存确认处理。

保存只消费用户审阅的完整 JSON，并复用原 world／source 修订保护、冲突处理及结果不明时的只读核对。保存确认后选择返回的项目身份并使旧计划失效；构建和运行仍需分别点击。原 **项目组装** 入口保留手动新建与编辑已有组装。新建默认类型遵循工程的第一分类；本次实测显式选择 fixture 已有的 `assembly` 类型，并核对最终登记，不推测自定义类型的用途。

实测场景预置两个动画实例和三个绑定。A 的两个绑定共发命令1–4，B 发5–6；完成分别关联目标命令4和6，全局截止均为6。新项目的目标回看仅呈现A的四条命令和对应完成。单成员组装是已有语义，此轮新增的是从当前场景进入它的作者操作，并未绕过独立 Scene2D 的逐实例构建拒绝。

应用0.2.0、组装作者schema1、动画schema4／子计划3、项目协议11／Godot适配器0.20.0／清单12及Rust/WASM保持。本轮不包含安装更新、原生图形窗口、Android、Bevy动画、ZIP再交付或独立发行验收。以前的[逐实例运行／ZIP专题](../animation-instance-runtime/README.md)与[目标回看专题](../project-animation-target-review/README.md)保留原字节，不改标为本轮重跑。
