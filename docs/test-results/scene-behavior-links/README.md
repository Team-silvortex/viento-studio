## 本轮闭环

保存新 TXT 脚本 → 构建与运行选择场景 → **管理已有行为** → 审阅新增引用 → 保存引用 → 打开行为原文 → 独立编辑绑定、参数和信号 → 普通保存 → Godot → 工程 ZIP。

目录使用一次保存态 World 快照，明确区分尚无行为、唯一可用行为及缺失／歧义／错误依赖。最多 256 份合格候选，每份 UTF-8 TXT 至多 64 KiB；32 条绑定、8 份实际使用脚本的预算保持。无效未关联路径候选会略过；关联中或使用中的无效来源明确报错。

纯核心验证目录与完整命令回执；独立窗口通过已有 `relation.add` 仅追加行为登记的 `references`。脚本、行为和场景正文保持。行为编辑继续只应用普通草稿，普通保存才写正文，没有新增写入协议或后端能力。

预览、过期目录与选择、并发变更、取消、未知保存结果、提交后刷新失败和退出均有保护。未知结果只经重新读取相同场景／行为身份并确认目标已关联后收敛；导航前重新核对来源，父子窗口与编辑器分别守护异步归属。
