- [服务工作流](host.log)：3 项通过，无跳过。由服务构建并运行受限项目，核对完整 30 步移动、跳跃及观察；非法输入、混用旧回放、窗口运行和多场景均在任务启动前拒绝，作者文件与冻结输出哈希不变；末步取消、观察回调异常和运行中取消均保持未完成状态。
- [输入和观察契约组合](contracts.log)：46 项通过，无跳过。覆盖输入数据形状、末步释放、项目资格、身份与来源核对，以及不完整、错位或非固定步观察的拒绝；其中也包含相关构建界面回归。
- [新增界面专项](ui.log)：7 项通过，无跳过。使用模拟宿主验证输入提交、JSON 错误、草稿与构建身份限制、三语、本地输入保留和绑定任务的只读结果；这不是原生桌面实测。
- [隔离浏览器全链](browser.json)：Chrome 156、真实本地 HTTP 服务和 Godot；界面检查与构建、非法 JSON 原文保留、示例回放及中英日结果通过，30 步观察包含水平移动与跳跃。临时作者文件哈希不变；[运行日志](browser.log)、[状态截图](replay-status-zh.png)。这是源码 Web 环境，并非 Tauri 安装测试。

每次回放使用隔离执行副本，输入作用于内建方向控制角色。宿主检查现有物理观察中每个角色 30 步的身份、顺序和时钟；观察完整不能单独证明预期玩法正确。真实引擎测试检查了受限示例的位移和起跳，未覆盖所有碰撞形状、系统与引擎版本，不承诺跨平台逐字节确定性。本轮没有实测物理键盘或原生桌面交互。

当前范围仅单场景、无作者行为、声音和动画的 Godot 物理工程。适配器指纹变化后，应使用当前适配器重新构建旧冻结产物；测试没有修改作者文件、冻结工程或日常作品。
