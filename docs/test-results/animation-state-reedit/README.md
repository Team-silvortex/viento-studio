## 边界与保留

只有带已知声明且完整源码可精确再生成的TXT才能重开表格；旧无声明源码与手改脚本保留普通编辑，不逆向解析、不自动迁移。统一LF／CRLF及BOM可逆保留。未知版本、混合换行或附加代码明确拒绝表格覆盖。

表格重开读取当前原文草稿；应用只写内存，普通Save才更新原TXT。状态标识变化会改变 `clip_...` 参数，界面列新增与移除项，但不会修改已保存的行为参数；跨文档重构与引用迁移仍是后续工作。每场景共用播放头和已有预算保持。

浏览器起点为已登记、已绑定脚本的临时场景夹具，从重编辑→保存→实际Godot运行使用同一份新源码。HTTP另验证新建源码与绑定，ZIP独立测试迁出工程；不拼成从空工程建成游戏的全GUI结论。实测为Linux HTTP编辑器、Chrome和Godot无头，未更新Tauri安装或验证Android、其他平台、物理画面与Bevy动画。

本轮开始前8464份示例／历史／证据、旧2376个评分及2579个证据对象核对保留。原始发射器仍为v1，旧13个起始脚本保持；第14个状态表starter增加同文件声明。新窗口与新建窗口分开持有端口和DOM标识，仍归既有脚本模块。


## 首轮发现与复验

首轮完整应用 [日志](app-initial.log)有6项旧编辑器测试失败，均因共享VM测试环境未注入新增的独立源码端口。补齐测试装配后，80项相关回归和最终完整应用分别通过。

首轮 [浏览器](browser-authoring-1792499698597/browser.json)漏掉“开始编辑”步骤，等待编辑入口超时；修正操作后最终浏览器通过。其失败截图同时发现单行声明被通用解析当成长标题，最终改为短标题加独立声明行，并补默认／structured／prose解析回归，没有修改通用解析器。codec／Godot在旧单行格式的首轮日志与最终两行格式日志分别保留；最终41项作者／保存、80项集成、11项codec、Godot／ZIP和浏览器均使用最终格式。

代码复核另修复了取消检查同步更换来源后仍可能使用旧快照的边界：先执行调用方guard，再重新捕获来源；四检查点×11字段均验证拒绝且不写草稿。UI与源码封装、来源宿主和运行时装配的独立只读复核未再发现阻断问题。
