## 行为与边界

支持二维视觉偏移、旋转、缩放、不透明度；线性或保持插值，循环或末尾保持。规则与采样位于 Rust，时钟、示意视图、原文宿主和引擎适配分离。Godot 只接管原生成视觉，保留逻辑移动、行为节点、声音与绘制顺序。

界面预览明确标注为采样示意；它不加载真实场景、图片或物理。保存后的构建检查实例目标及登记关系。轨道目标目前填写稳定实例编号，尚无从场景创建动画或目标选择器。序列帧、骨骼、混合、事件、脚本播放控制、3D、Bevy 和动画控制重放尚未实现。

浏览器只修改临时示例的动画正文，保留 BOM／CRLF，其他九份作者文件保持；不读取素材。[保全记录](preservation.json)核对 7831 份旧示例／历史／报告、2172 个既有评分对象和 2295 份既有证据对象。前轮音轨使用位置工作保留。新增动画示例不复制素材。

当前 22 模块／42 声明能力，Godot 适配器 0.12.0；主 Rust ABI、Scene2D 作者版本和项目运行协议保持。未升产品版本、提交推送或更新已安装的 0.1.1 AppImage；无安装、Android 设备、Godot 窗口渲染或独立游戏发行验收。
