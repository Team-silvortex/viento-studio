# 试听进度、暂停与定位验收

2026-10-16，基线 `cc4e5aa3`／0.1.4 后未发布工作树。在 **编辑场景声音** 中读取已绑定素材并开始试听后，显示当前位置与总时长，支持 **暂停试听／继续试听** 和进度条定位。[完整操作](../../SCENE_AUDIO.md#就地试听音轨素材)。

## 行为与分层

暂停保留本次已校验的内存缓冲，继续从保存位置播放；暂停时定位不自动开始。播放时定位替换一次性的 BufferSource，保持当前音量和循环。非循环精确末尾停在暂停状态，继续从头播放；循环末尾对应零点。非循环自然结束仍释放播放器。继续处理中暂不接受暂停／定位，停止始终可用。

进度取自 AudioContext 时钟，界面每 250 毫秒只更新进度，不重建作者表单、审阅或持续播报状态。键盘和指针操作时保留待定位值，确认改变后才定位；切换三语保留播放状态。暂停／继续按钮互换时传递当前焦点，滑块焦点保持。进度步长随时长分段，避免非整百分秒音频的真实结尾不可达。

播放器继续独立于来源宿主、纯字节校验和编辑／保存；node 身份、代次与 owner 共同防止旧 ended 或迟到 resume 干扰新播放。停止、编辑、读目录、检查／应用、取消、隐藏及释放继续撤销暂停中的试听。读取／解码预算沿用此前 32 MiB 文件／128 MiB 预计解码缓冲，继续与定位不重新读取或解码；暂停保留的快照不代表磁盘正在被监测。需要验证磁盘当前内容时，重新显式开始试听。
