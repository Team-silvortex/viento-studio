2026-10-26，**0.2.4之后开发工作树**，Godot执行适配器**0.30.0**。沿现有入口 **编辑二维物理 → 静态矩形 → 平台移动方式 → 水平往返**，设置终点水平偏移与平台速度，检查、审阅、应用原文草稿后普通保存。使用说明见[平台配置](../../SCENE_PHYSICS2D.md#配置水平往返平台)。未升版、提交推送或更新本机0.2.0安装。

## 已完成范围

- 新物理schema 5允许静态矩形保存可选 `platformMotion: {kind: "horizontal", offsetX, speed}`；有限偏移绝对值1–8192，有限速度1–2000，可与 `oneWay` 组合。显式启用才升级，关闭不降级，默认新建流程保持。
- Rust独立 `scenePhysics2D.inspectPlatformMotion` 与WASM标记验证规则；JS保留原文、来源与旧数字拼写，计划从实际字段派生 `physics.platform-motion2d`。不支持的后端明确拒绝；原项目运行、物理观察协议保持。
- 平台按本次访问的保存位置及水平终点恒速往返，使用已有项目物理时钟。重力角色只有上次真实返回向上支撑且本步仍有效时才被携带；位移合入原有请求，调用原有碰撞求解，观察 `requestedMotion` 包含输入／重力和承载总量。
- 实际起跳、下穿请求在下一物理步复核执行时停止承载；多个角色独立，走离后不继承水平惯性。原有碰撞、落地事件继续驱动动画和声音。关闭／退出撤销控制，重入重置轨迹和支撑状态。
- 新生成器只在计划副本投影schema 5为旧格式并去除新字段，交给冻结旧生成器；无运动声明的结果与旧生成层逐字节一致。新参数、helper、清单和旧运行原文接受严格库存核对，再运行完整旧验证链，纳入工程ZIP。
- 中英日表单复用现有审阅与保存流程，390px下可达。空间图只展示保存起点与几何，调整碰撞形状不会改变运动参数。没有新增模板或脚本类别，已有19项脚本目录与起始源码保持。

边界：只做水平轨迹，不含垂直、旋转、多段路径、动态刚体、侧向推挤或挤压伤害。承载对象限 `characterMotion` 重力角色；自由平面角色保留原碰撞。支撑来自原生返回事实，不是持续几何接触全集；同次返回其他普通／未知支撑或多个移动平台时不推断跟随对象。平台自身不自动避障，携带角色仍被原生墙体阻挡。Bevy、Android、桌面安装产物和硬件声音输出未验收。
