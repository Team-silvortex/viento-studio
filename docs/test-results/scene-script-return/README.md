# 首次行为配置与普通脚本的显式往返

2026-11-13，应用0.2.10工作树／下一版0.3.0／已安装0.2.0。操作见[行为指南](../../SCENE_BEHAVIORS.md#创建脚本后返回场景)，接口边界见[架构](../../ARCHITECTURE.md#首次行为创建的脚本往返)。本轮不含提交、推送、升版或安装。

## 本轮实现

首次行为创建可暂存完整表单，进入普通脚本选择／TXT草稿，再通过普通保存登记。保存或取消后由作者明确返回，重新读取目录、核对原场景及实际写入的脚本，恢复原文档／绑定身份和全部选择，再明确选脚本并重新审阅。新脚本不会自动选中、建立绑定或关系。

宿主适配器只观察真实写入回执；保存函数吞错、编辑器已退出创建态或索引重建返回都不是注册成功的证明。返回时以新目录再次核对。挂起期间无World写锁，原关闭表单仍受退出保护；内存暂存不进入作品包或恢复日志。现有行为原文含未保存修改的跨区往返未接入。

## 三条真实作者路径

- **成功**：从零正文／登记创建定义、两实例场景，暂存路径／类型／后端及第二实例选择；普通官方信号TXT保存仅新增正文与登记；返回后原身份不变且脚本仍空，作者明确选脚本、审阅保存行为，再普通保存信号映射。最终4正文／10作者文件；一次真实Godot无头运行由该第二实例及原绑定发出 `context_ready`，参数为 `["dock",0]`。
- **取消**：独立工程验证取消脚本选择、取消普通脚本草稿，再返回恢复原设置；另验证明确放弃暂存。最终2正文／6作者文件，无TXT或行为登记增加。
- **来源变化**：第三份工程通过真实普通接口给场景追加换行，返回前置拒绝，主编辑器路径和正文不被拉走；恢复原字节后再次返回，同一配置与身份恢复。最终3正文／8作者文件，无自动行为写入。

所有正文通过实际Studio控件创建，未注入预制场景／行为／玩法JSON；初始化只创建原正式空白目录／模板结构。作品库创建、系统选择器、已安装Tauri、Android与实体设备未自动化。Godot仅验证成功工程一次无头运行，未用它替代窗口／声音、独立发行或Bevy执行证据。三个工程共24作者文件原字节保存。
