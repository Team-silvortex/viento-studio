# 宿主调度观察与预算窗口

2026-10-26，0.2.5之后开发工作树。新Godot执行适配器及项目生成层 **0.33.0** 将实际引擎帧对、七维预算用量和有界窗口摘要接入独立观察流及会话记录。原作者格式、项目协议4／7／10／11和有限累计额度保持，未更新本机0.2.0安装。

## 已接通的链路

新项目的autoload在生成协调器进入场景树时安装预算观察包装；普通作者的 `_ready`、`_process`、`_physics_process`、信号和deferred仍走原端口及冻结0.32准入对象。一次成功扣费归入调用当时的 `Engine.get_process_frames()`／`Engine.get_physics_frames()` 对；同一窗口合并输出。flush、切场景和deferred本身不推进窗口，也不会补充额度。无预算调用的正常会话保留一个零用量终态窗口。

这是**调度观察窗口，不是完整因果事务**。例如 `_ready` 之后的deferred可能已跨过一个物理步；应按真实计数核对，不能仅按源码回调名称猜测同一窗口。原事件序号、状态revision、媒体命令、队列和完整语义账本仍独立维护。

`VIENTO_EXECUTION_CLOCK:` 协议1单独携带窗口身份、时钟、七维窗口差值和累计值。可移植reader验证连续身份、时钟单调、差值等式和原有限策略；最多解析8192条本前缀记录，每行16KiB，非法帧不覆盖有效状态。宿主保留最近32个窗口并记录累计／保留／移出数量；原项目及物理协议继续交给原reader。

`session.json.executionClock` 和任务接口保存该摘要。成功、失败、取消均保留最后有效观察；不完整过程标记 `incomplete`。强制终止可能早于下一次合并输出，所以该摘要不保证覆盖终止前尚未输出的消耗。新独立辅助文件、autoload配置、原配置副本和sidecar进入严格库存；删除或篡改不能回退为旧工程。旧GDScript及0.32预算生成器保持原字节。

## 初次失败与范围

[主矩阵首轮](initial-native.log)为6通过、1夹具失败：测试错误地要求 `_ready` 与deferred必在同一Engine帧。日志实际显示physics计数推进，生产逻辑正确；将递归统一从deferred开始后，冻结测试源码重跑全部7案通过。初始作者和运行证据保存在 `initial-native-evidence/`。

[首次全量检查](full-check-first.log)发现三个旧测试仍直接调用冻结0.32清单读取器，因而少列两个新增观察脚本；正式适配器已使用0.33完整清单。仅更新测试入口后，三个测试文件定向复验通过。首轮运行期间生命周期测试还加强了错误码断言，源码守卫如实报告该测试文件变化；生产源码未变。首轮退出与前后摘要保留在 `full-check-first-exit.json` 和 `full-check-first-sources.json`。

生命周期首轮失败来自测试误要求保留观察者原始错误消息；宿主已有净化策略返回 `build_failed`。最终断言核对真实抛错次数、失败状态、明确错误码、无异常逃逸及完整落盘，生产代码未改；初始日志与证据另存。

[清单修正后的中间全量](full-check-before-host-fix.log)为7920通过、533跳过，但其运行中恰逢宿主异常修复，源码守卫报告变化，不能作为最终实现验收；最终完整检查已在生产和测试全部冻结后重跑。

独立审查另复现了收尾异常漏洞：[两项首轮](host-finalization-before.log)均因最终观察回调再次抛错而绕过会话保存；[初始化边界](host-initialization-before.log)在reader赋值前抛错，失败会话的观察phase仍为waiting。宿主现在捕获最终finish异常并继续落盘，且独立归一化失败／取消／超时状态。三项回归全部通过；原生九案随后在最终生产源码上重新验证，早期日志与摘要保持原时点。

本轮没有新增编辑器控件、Rust／WASM逻辑或Bevy接入，没有放开累计事件／媒体／访问／输出／时限，也没有裁剪完整动画因果账本。持续运行仍需定义跨窗口的未决调用与因果锚点，再引入明确的实时准入合同。原生headless结果不等于窗口图形、扬声器或安装验收。

复现命令见[验证指南](../../TESTING.md)，职责与格式见[中间层](../../BACKEND_MIDDLEWARE.md#执行调度观察)。`VIENTO_EXECUTION_CLOCK_EVIDENCE` 与 `VIENTO_EXECUTION_CLOCK_LIFECYCLE_EVIDENCE` 可指定两个原生测试的证据输出目录。
