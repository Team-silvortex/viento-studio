## 边界

状态表仅用于本次创建，生成后普通 TXT 成为作者编辑依据；没有任意源码逆向回填、持久状态图、条件或混合。每场景仍共享一根播放头；单个控制器是作者配置约定，并非运行时所有权仲裁。逻辑状态只代表选择／播放请求已受理，实际执行仍看现有命令与完成记录。两条请求不具有回滚事务。

Chrome 运行样例在基线前配置为与表格生成相同的源码，GUI 新保存脚本另验精确字节；新保存来源到运行由独立 HTTP 工作流贯通，不拼成一次从空工程到游戏的全GUI验证。实测为 Linux HTTP 编辑器、Chrome 与 Godot 无头，未更新 Tauri 安装、未新增 Android／其他平台或硬件画面验收。Bevy 动画、每实例播放头、骨骼、3D 动画、独立游戏发行不属于本轮。

Rust／WASM更新仅增加可选状态表能力；既有运行后端、13份旧starter、8399份本轮开始前的示例／历史／证据和已安装程序均核对保留。
