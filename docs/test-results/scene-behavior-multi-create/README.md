## 能力与边界

首次添加场景行为现在使用可增删清单：1–32 条稳定绑定、最多 8 份去重脚本。新增优先未分配实例，允许多个实例复用脚本，也允许同一实例挂多个行为。选择条目不使审阅失效，实际增删或修改重新审阅；至少保留一条，已有身份保持。

新增纯规划器只把明确的实例、脚本和绑定身份生成现有声明，调用既有格式检查。界面负责选择与审阅，原 `behavior.create` 事务负责正文、登记及场景关联；初始参数／信号为空，后续沿独立行为编辑器和普通保存配置。已有行为清单新增脚本依赖仍需显式登记，本轮不开放自动追加、场景迁移、LSP、Bevy 作者 Rust 或新运行协议。
