## 范围

本轮增加独立的保存态动画使用位置目录、来源宿主可选读取和三语只读视图。按完整 UUID 匹配当前场景关联的已保存行为参数；原文定位复用保存快照，不重新读取或进入编辑。所有查询、刷新和关闭操作不写入作者数据，也不取得删除审阅或引用迁移权。

- 核心/服务验证描述符捕获、品牌与匹配对象身份、独立字节预算、双向关系、读取冲突、旧格式、空片段和缺省行为。
- 原文位置覆盖重复编号、BOM、LF/CRLF/CR、Unicode 转义与非精确子串排除。
- 来源宿主检查每次异步边界、可选能力独立撤销/恢复、保存字节摘要、旧服务退化以及普通草稿应用不受影响。
- HTTP 与普通保存链路覆盖默认正文目录和 v2 design-data/data-template。片段改名只修改名称，保持编号和行为匹配；片段移除仍可经原有审阅保存，行为原文不被重写。外部行为变化只在显式刷新后更新查询快照。
- 界面范围和最终执行数字见本轮报告；浏览器不是安装、Android 或新的后端执行验收。

未找到匹配不等于未被使用。脚本源码、其他场景、未保存行为草稿及动态值不在查询范围；当前字段的未保存新增片段也可按编号查找，但不会因此被保存。读取允许目标图片或实例成员待修复，整体登记仍须满足 World 契约。目录可读不证明完整工程可构建。

本轮未修改 Rust/WASM、运行协议或 Godot/Bevy 生成器，未重复声称前轮实际引擎或 ZIP 迁移结果。
