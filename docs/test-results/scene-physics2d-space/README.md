本轮在 0.2.1 后工作树补齐“保存态场景位置 → 已检查碰撞形状 → 图形／键盘选择 → 字段检查与审阅 → 原文草稿 → 普通保存”。当前 **23 模块／45 项声明能力**，源码 0.2.1，安装仍为 0.2.0；本轮未提交、推送或安装。

## 读取与编辑边界

独立空间域严格捕获有界 DTO，绑定物理 source5，按保存态实例根位置加声明偏移生成只读几何。宿主从 World 快照复用 Scene2D v2／v3 投影，不读取素材字节，不借用构建或执行后端；不要求物理／声音／动画／行为已构建成功。渲染器只消费品牌几何并返回已有 body ID。

点击形状或键盘选择不修改值；参数改变后必须检查才显示新形状。刷新空间保持未完成输入、选择和审阅，目标目录仍负责已有应用前身份核对。缺失目标明确列出，不绘制猜测位置。空间失败保留字段编辑；旧响应不能跨文档、能力代际或关闭重开接管会话。普通 Save 独占持久正文写入。

没有新增碰撞求解、拖拽、缩放／平移工具、图片渲染、动态刚体或后端映射；作者格式、Rust/WASM、Godot 适配器和运行协议保持。
