## 环境和边界

浏览器为Linux Chrome156；原生为Godot4.7.2音频清理修订、Xvfb／Mesa软件OpenGL和XTest合成按键。原生观察器只转发一次原物理回调并采样，附加测试GUI只消费指定输入，不发布玩法事件、写共享状态、修改作者／生成脚本或调用玩法端口。受控接口探针与只读窗口观察分开。
