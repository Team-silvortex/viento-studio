# 原地重启：真实浏览器作者工作流

原始结果：[browser.json](browser.json)。本轮使用真实 Chrome 和 Studio HTTP 编辑器：11 张截图、9 组中英日 390px 布局检查、零浏览器异常。26 个生产源文件、驱动脚本及官方示例的 98 个文件在测试前后哈希一致。

一次性作品副本来自官方 `topdown-collect`，不是从空白创建。测试准备只调整已有的三个普通作者文档：输入映射增加 `restart_game`（R／Space）、菜单初始值增加 `progress: checkpoint-7`、收集音轨循环。它们供独立原生重启验证观察进度保留和音轨清理，不属于浏览器创建结果。官方示例自身保持原字节。

通过实际 UI 创建并普通保存原地重启 TXT 与登记；通过“管理已有行为”审阅并保存脚本引用；通过行为编辑器新建独立绑定，显式补齐 `action_name`、`state_values_json` 两个默认参数，填写 `restart_game` 与 `{"score":0,"health":3,"door_open":false}`，检查、应用、普通保存后重新打开。没有 `target_scene_id` 参数。脚本创建取消、引用审阅取消及新增绑定／参数取消均未写入作者文件；应用只更新编辑器草稿，最后的普通保存只修改行为正文，原有 11 条绑定原始字节完整。

[保留的作者作品](author-final/workspace.json)含 34 份登记文档、9 项素材、100 个作者文件，构建快照为合法四场景组装、关卡 12 条绑定。此浏览器报告不宣称已完成原生桌面安装、Android、空白全流程、游戏实跑或独立发行；原生实跑由同主题下的独立记录提供。

已人工查看英文脚本预览、日文默认参数和中文已编辑参数截图。原始输出及保留作品的逐文件清单见 [evidence-inventory.json](evidence-inventory.json)；原始报告中的临时绝对路径保持测试当时记录不重写。


完整可迁移作者数据保存在标准作品包 [author-final.viento.zip](author-final.viento.zip)，导出／标准原生导入回执见 [author-archive.json](author-archive.json)。标准格式包含 99 份作者数据文件及 1 份清单，完整携带 9 项素材与 9 份素材登记；恢复后逐文件哈希一致，四场景构建快照与源作品完全一致。顶层 `README.md` 是格式之外的普通说明旁附，原字节保留并在导入后加回，现场全部 100 个文件再次核对一致。

`author-final/` 是测试现场便览，其中素材和素材登记受现有仓库忽略规则影响，不保证原始目录中的每个文件都会进入 Git；迁移与完整性复核应使用上述标准 ZIP。原浏览器报告和原始证据清单字节保持不变，新增导出／恢复结果单独记录。
