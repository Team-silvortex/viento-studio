# 已有声音时间提示增删验收

2026-10-16，基线 `cc4e5aa3`／0.1.4 后未发布工作树。新增提示的轨道选择、播放／停止及删除复用独立声音编辑器，**检查完整原文 → 应用到原文草稿 → 普通保存**。操作见[场景声音](../../SCENE_AUDIO.md#增删已有声音的时间提示)。

## 实现与边界

新 `createSceneAudioCueProposal` 与旧叶值提案共用来源宿主；旧 API 仍拒绝结构变化。保留项按稳定身份匹配、固定既有轨道和相对顺序，新项只追加；候选交既有 Rust 声音语义验证。无结构变化仍只改叶 token，结构变化只重建 `/cues`，复用未改条目的原文片段。轨道用途、音量和循环可同批修改，资源与元数据不受表单写入。

允许 0–64 条提示；从空添加、删至空、同刻 play／stop 均复用原语义。空时间线不自动绑定行为，也不控制当前运行工程。表单不提供轨道增删、素材替换、既有提示换轨或重排。声音 schema、Rust ABI、模块／能力、Godot 适配器和运行协议保持；不新增 JS 语义替代层或保存事务。

## 使用与交付流程

先删中间提示、向第二轨追加播放／停止，完整审阅后切换三语并取消，作者目录和主编辑草稿均保持。再移除全部提示并普通保存，重开仍有两轨和同一 WAV。随后通过界面添加四条提示，直接断言持久化的轨道顺序；完整审阅、应用草稿时磁盘保持，普通保存只改变声音 JSON。Godot 实际执行音乐播放、0.125 秒音效播放及同在 0.5 秒的两条停止，作者同刻顺序保持。

Chrome 下载 **58,555 字节**工程 ZIP，独立校验 **8 个文件／1 份 WAV**；异地导入与运行得到同样声音事件，SHA-256 `e76af966f66a959f027125797d68ebf7a35581d5d9c9f3a9170412a3b9c726fd`。这仍是需要 Godot 的工程交付，不是独立游戏安装器。

首轮成功记录见[browser-initial.log](browser-initial.log)；审查后仅给验收脚本增加明确的持久化轨道顺序断言，再执行上述最终浏览器流程，产品源码没有因此变化。完整应用启动后的验收脚本补充另经过语法检查。

**7468** 份旧示例／历史／证据及已安装 AppImage 保持；2136 个旧评分对象复核后原样保留。临时工程、浏览器进程与解包目录由验收脚本回收；[清理](cleanup.json)仅移除本轮生成桌面副本，现有移动副本保留。未改版本、提交推送、安装或进行 Android 设备验收。
