## 完成范围

- 引擎中立契约支持布尔、有限数字与 Unicode 字符串；64 键、1024 次有效变更及 UTF-8 容量预算，完整候选校验后才提交。状态来源从冻结行为绑定派生，事件不能提供任意文件路径。
- Godot 0.9.0 提供访问绑定的 `read_state`／`write_state`／`erase_state`。A→B→A 保留状态，旧访问引用失效；新运行、作者离线恢复后再次运行及异地启动均从空状态开始。
- 项目协议 2 校验连续修订及结束修订，纯读取器保持显式协议 1；宿主按冻结构建选择协议，不绕过旧适配器指纹。旧本机构建需重新构建，旧独立 ZIP 保留自己的代码。
- 独立只读界面显示键值、修订与最后来源；支持筛选、中英日、删除回源。内置共享状态起始脚本只生成普通草稿，工程 ZIP 保留同一行为接口。
