# 项目运行时场景切换验收

2026-10-15，源码 0.1.3 之后的未发布工作树。本轮接续[项目组装](../project-assembly/README.md)，把已冻结的成员场景接入运行时切换、按访问隔离的观察、当前实例查询及工程 ZIP 交付。操作见[运行中切换场景](../../PROJECT_ASSEMBLY.md#运行中切换场景)。本轮未升版、提交、推送或更新安装。

## 完成范围

- 纯运行契约不依赖 Node、DOM 或作者解析器。项目协议独立包装原场景协议 1／2／3，每次进入建立新访问；旧访问事件、接口和导航不能影响新访问。
- Godot 适配器 0.8.0 生成协调器与成员包装，行为通过当前访问的 `request_scene` 接口请求成员 UUID。退出先停止处理和声音，再进入目标场景；A→B→A 创建三次独立访问。内置 GDScript 起始内容及中英日说明已接入。
- 构建面板显示冻结成员、当前场景和访问记录。公共 `inspect` 查询按当前实例／对象筛选并保留项目归属；作者离线后恢复冻结工程仍能运行和查询。
- 项目无头测试使用整个会话两步、每步 0.25 秒的预算，切换不重置。适配器提供预期时长，通用读取器拒绝提前结束；普通窗口仍可立即正常关闭。

## 实测发现并修复

1. 浏览器运行查询曾间接导入作者构建解析器及裸 `yaml` 依赖，使编辑器无法装载。冻结计划校验已抽成纯模块；真实递归 ES 模块装载回归防止重新耦合。
2. 作者脚本在就绪时关闭窗口曾使零步测试被记为成功。适配层现为有限项目运行提供完成时长；真实测试确认零秒有限运行失败，而同一工程不限时关闭仍正常。
3. 公共 `inspect` 曾仍使用旧单场景查询器，拒绝项目观察。现按任务目标分流，真实 HTTP 和服务测试覆盖当前实例筛选与访问记录。
4. 来源导航的持续检查曾把自己的读取忙碌状态误作外部干扰。现点击前检查忙碌，读取中持续检查任务、访问、草稿及窗口归属，宿主另守护编辑器读取令牌；重复点击和迟到结果仍被拒绝。

初始浏览器失败、全量失败、模式修复前和导航修复前的检查点全部保留在本目录，不能当作最终结果。旧 `project-assembly` 与 `scene-audio-creation` 报告保持原字节。
