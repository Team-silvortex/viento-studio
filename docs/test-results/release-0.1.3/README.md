本版收录多绑定行为与引用管理、Bevy Rust 就绪／固定步行为、独立场景声音。功能与边界见[发布记录](../../RELEASE_0.1.3.md)；[发布预检](preflight.json)记录本次实际验证。

- 版本与源码归档回归 **8／8**，无跳过；**814** 个应用 JavaScript 加 **2** 个桌面脚本语法及 API 契约通过。产品版本 0.1.3，Android 1001003，macOS 1.1.3。
- [实际临时源码归档](source-archive.json)含 **8383** 文件，逐项回读和摘要验证，覆盖声音示例 **14** 文件及 Bevy 模板 **5** 文件。归档 301,937,942 字节，已删除；它早于最终审计文字与图谱派生刷新，不声称为最终提交归档。
- 修复声音 WAV／资源登记被 Git 忽略及源码包未纳入声音示例的问题；[实际缓存探针](cache-exclusion.json)确认 Bevy 模板 `target` 不进入桌面资源，源码回归另确认归档排除。原探针字节保持，随后清理。
- 桌面与移动[准备副本](prepared.json)完成 **37** 项字节比对、**7** 项实际模块调用；不是安装或设备验收。
- [保留检查](preservation.json)覆盖 **7988** 份既有应用／示例／证据，其中 **7071** 为历史证据和示例；旧安装 AppImage 保持原字节。版本显示与打包回归为明确发布变动，engine README 只改发布导航。
- [清理记录](cleanup.json)记录本轮 **648** 份可重建桌面副本、8,973,744 字节已删除，工具、移动副本、源码 WASM 与作品保留。

升版前最后完整应用为 **0.1.2 工作树**下 **4920 项（4807 通过／113 条件跳过／0 失败）**，见[原日志](../scene-audio/app-check.log)。声音 Rust 334 项、真实 Godot 11 项和真实浏览器 4 组，以及 Bevy 固定步的 Rust／原生／浏览器记录，继续保留各自原版本与范围，不重标为本次重跑。定向检查与这些旧全量不累加。

本次不更新本机 0.1.1 安装，不生成二进制安装器、标签或 GitHub Release。临时源码归档是完整性验证，实际交付为源码提交和推送。
