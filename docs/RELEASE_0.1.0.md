# 0.1.0 版本记录

2026-10-12。把 0.0.10 之后累积的 3D 作者编辑与只读浏览主线纳入源码交付。版本升至 0.1.0，不自动迁移作者工程、元数据或素材，也不表示 3D 已达到完整游戏引擎编辑器阶段；原 `viento-scene3d` schema 1、核心协议和既有 2D 执行契约保持。

## 变更

- **九个独立 3D 作者编辑区**：单对象位置／XYZ 欧拉旋转／尺寸，方块新增／单对象复制／移除，作者背景／相机／方向光，现有名称／颜色，共同位置偏移，明确参照的单轴位置对齐，单轴等距分布，批量复制及批量移除分别维护自己的输入、选择和审阅。每个域只依赖文档模块，可选核心缺失只禁用对应入口。
- **完整审阅后应用草稿，再普通保存**：共享 Rust 核心检查完整来源和最终候选，按稳定 UUID 保真修改值词元或结构区间；可移植私有提案、来源身份、摘要、修订与异步会话归属共同守护应用。未变字段、其他对象及删除区间之外的原字节保持。取消和过期审批不改正文；磁盘基线、外部冲突及持久化仍由编辑器普通保存负责。
- **多对象位置与结构操作**：整体移动保持共同偏移，参照对齐直接取同份原文坐标，分布保留两端并拒绝精度不足的排列；三者只修改目标位置。批量复制按来源顺序追加新 UUID 的保真副本，零偏移也生成独立身份；场景总数最多128，单次成功复制最多64且受剩余容量限制。批量移除一次删除明确选中声明，保留幸存对象的顺序、身份和声明；最多移除127个且至少保留一个，全选不自动截断或保留。任一对象无效或候选超预算时整批拒绝。
- **只读预览导航与选择**：名称／UUID 字面检索保持稳定选择；精确原文定位重新验证完整当前来源并映射 UTF-16／文本框换行。画布单击可见表面同步选择，双击复用临时聚焦；拖动阈值、取消、多指、滚动、尺寸及会话变化均有旧手势守护。选中边缘提示按真实遮挡显示，不透视隐藏对象。
- **单对象与全场景取景**：按真实旋转角点、实际画布比例和当前方向生成临时镜头，远坐标使用浮动原点；搜索不缩小全景范围，选择和作者相机保持。重置或成功刷新恢复作者相机，无效草稿保留最后有效预览与诊断。数学、GPU 适配和三语界面分离，绘图失败沿已有错误接口反馈。
- **模块与交互整理**：当前固定17模块、33项声明能力，九份作者提案互不替代，预览不取得作者／保存／执行权限。中英日表单与窄屏入口补齐；编辑器工具栏随窗口换行，避免新增独立按钮把整个文档横向撑开。功能图谱更新到96功能、239实现、373绑定和1492评分单元，历史证据、来源时点及非交付评分继续保留；本版仅将13项新增3D功能的源码交付状态和57个对应交付评分更新为已交付。

操作方法见[3D 场景编辑与预览](SCENE3D.md)，接口见[可移植引擎](../engine/README.md)与[系统模块](STUDIO_MODULES.md)。现有 2D 配方九域、后端工程管理、Godot CLI 的有限 3D 静态导出／检查及其他编辑迁移能力继承自 0.0.10 或更早版本，不计作本版首次实现。

## 验证与交付范围

[0.1.0 发布预检](test-results/release-0.1.0/preflight.json)使用固定 Node **24.21.0** 完成 **8／8** 项（7 项版本检查＋1 项真实临时源码归档回归），失败／跳过／取消均为零；**647** 个 JavaScript 文件的语法及 API／版本预检全部通过。本轮没有重新运行完整应用、Rust、浏览器或设备检查，不把旧结果改写为0.1.0同字节验收。

最近[批量移除完整验证](test-results/scene3d-removal-authoring/results.json)在升版前的 **0.0.10 工作树**完成：应用 **3811／3811**，失败／跳过／取消／todo为零；**644** 文件语法／API／版本预检、Rust **307** 项及fmt／clippy通过。准备副本 **378** 组与新旧入口 **32** 类浏览器流程分证；最终工具栏另测 **1440／1024／390px × 中英日** 九组布局。初轮跳过、路径修正、修复前截图和最终字节核对各自保留。专项、完整检查和历史轮次存在重叠，不累加为覆盖率。

其后的[全场景取景验证](test-results/scene3d-scene-framing/results.json)仍保留实际 **0.0.10** 版本条件：**256／256** 相关回归、**16** 组资源副本、独立12组几何／界面复核、新 **7** 类及旧 **7** 类浏览器流程通过。最终报告使用 Chrome **154.0.8037.97** 的显式 `--use-gl=angle --use-angle=swiftshader` 软件路径；11份实际HTTP内容与冻结源摘要一致，三语 **390px** 的 **754** 个可见画布点与最终截图全部相符，五张最终截图已目视。此专题没有重跑前段的3811项或307项，也未采集CSP／SVG计数。

默认 headless 自动回退路径曾出现窄屏合成残影，实际readPixels正确而最终截图异常；初次视觉拒绝、各对照和失败记录保持。原CSS恢复后，同一产品在显式软件路径通过，不能依据相同renderer字符串断言底层驱动原因，更不能推断物理GPU、安装版或Android设备没有该问题。初次最终页面导航挂起的部分截图不计为通过流程，测试超时与一次性草稿复位后的完整重测另存。

本次交付源码，不制作新AppImage、deb或APK，不更新既有安装，也不创建GitHub Release或版本标签。最近保留的Linux安装包验收仍为[0.0.4](test-results/release-0.0.4/results.json)；使用0.1.0需从源码启动或自行构建。安装版本映射同步为 Android `versionCode=1001000`、macOS `bundleVersion=1.1.0`。应用标识、用户数据路径、作品原文和素材保持，工具与派生工程继续位于作者工程之外。准备副本和软件WebGL不等于安装、移动宿主、Android设备或硬件GPU验收。

## 当前限制

3D仍只表示1–128个方块、透视相机与方向光，原文前后最多128KiB UTF-8。没有模型／贴图／物理／动画、空间变换层级、OC投影或行为绑定；标准方向与极点手势、多对象旋转／缩放、外形边缘对齐、跨视图统一撤销及多文件原子草稿仍待独立实现。整景范围很大时，远处微小对象可能小于一个像素；几何命中不承诺抗锯齿／深度量化的逐像素一致。

3D没有接入现有2D构建工作台的完整运行、控制或验收协议，也不新增Bevy 3D、作者Rust编译、内嵌引擎视口或GPU计算能力。原Godot CLI导出与有限无头检查沿用首切片契约；生成工程回导、独立游戏发行和ns-nova／yalivia／Nuislang原生接入继续分别推进。
