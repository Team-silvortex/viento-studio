# 0.0.10 版本记录

2026-10-11。把 0.0.9 之后累积的后端工程管理、配方原文创作、系统模块装配和首个独立 3D 切片纳入源码交付。版本按数字补丁从 0.0.9 增至 0.0.10；作者工程、元数据、素材和既有 2D 执行协议不随应用升版自动迁移。

## 变更

- **后端工程可追踪管理**：Godot 原生工程与 Bevy 场景数据包记录冻结来源、工具与适配器身份、生成文件和资源副本库存。工作台提供三语详情，CLI 可只读核对离线输出；后端工程与作者文件分别管理。
- **持久列表与明确运行选择**：成功工程按本机索引跨服务恢复，检查详情不切换运行目标。明确“设为运行工程”后，普通运行、有限控制、用例及验收组统一使用所选冻结工程。作者离线时可继续使用已验证输入，新计划和构建仍需读取作者来源。恢复记录不重新获得自动删除权；源文件改动、新增文件、链接、运行报告和归属异常有明确保留原因。
- **九个配方创作域**：实例属性及恢复继承、单实例位置画布、多实例移动／吸附／六向对齐、共享片段字段及声明恢复、整组放置偏移、共享演员增删、整份放置管理、组织分组、片段定义管理各自独立。新增或复制放置分配稳定身份；演员移除同步清理映射与局部覆盖；组织组只表达关系，不引入空间变换。片段定义支持新增、原文保真复制、移除未引用定义和重命名；重命名原子更新全部放置引用，保持实例／组 UUID 和有效场景。
- **审阅后应用草稿，再普通保存**：共享 Rust 规则、纯提案、候选验收、注入工作流、浏览器连接和原文宿主分层。各编辑区维护自己的输入、选择、审批与局部历史，只取得自己的能力。完整候选与影响清单通过后才应用当前原文草稿；取消、过期、迟到响应和篡改回执不能越过来源守护。磁盘持久化与外部冲突仍由主编辑器普通保存负责。
- **系统模块与模板需求**：工作台以明确端口装配文档、设置、工程、World、导出、素材、2D 构建和可选 3D 模块。工程与模板可声明增量 `studioProfile`，原生实例化和迁移保留它；未知需求给出局部诊断，普通文档仍可编辑。模块装配不授予文件写入或工具执行权限；当前仍是启动装配，正文宿主和部分功能区内部的聚合继续逐步拆分。
- **独立 3D 首切片**：严格 `viento-scene3d` schema 1 描述 1–128 个方块、透视相机、方向光和 XYZ 变换。可选 Rust 能力产生只读模型、独立计划及精确原文范围；WebGL2 预览支持查看对象、旋转观看、重置视角和刷新当前已保存／未保存草稿。保持作者视口比例，错误保留最近有效画面，关闭释放渲染资源。CLI 可导出原文、计划和可检查的 Godot 源工程，并明确调用有限无头检查；这不是现有 2D 后端工作台的 3D 运行模式。
- **回归与交互修复**：补齐旧核心能力缺失时的兼容门禁、静默原始输入导致的审批失效、异步来源／回执归属、目录强制刷新、持久索引锁清理、生成文件保留检查及三语窄屏。3D 相机／灯光预算、极小方向向量归一化和作者视口比例分别验收；图谱与调用工作流同步更新，原始失败与历史报告保留。
- **源码归档完整性**：修复交付白名单漏掉 `examples/scene3d` 的问题，源码归档包含全部五类官方样例和两个独立 Rust crate。新增真实临时归档回归核对清单及原字节，继续排除缓存、生成二进制和私有状态。

操作方法见[后端工程管理](BACKEND_PROJECTS.md)、[配方创作](SCENE_COMPOSITION.md)、[独立创作工作流](SCENE_AUTHORING.md)、[系统模块](STUDIO_MODULES.md)和[3D 初步接入](SCENE3D.md)。当前阶段与后续边界见[状态](STATUS.md)、[架构](ARCHITECTURE.md)和[路线图](ROADMAP.md)。
