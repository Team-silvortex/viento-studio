# 0.3.0 版本记录

2026-11-13。本版收录0.2.10发布后的二维主线与创作工作流增量：复用实例行为配置，补齐原地重启、暂停恢复和运行菜单，减少菜单目标编号的手填，并打通首次行为配置与普通脚本创建之间的显式往返。新增影视起始模板，继续共用文档、对象、素材与迁移基础。

## 主要变化

- **复制行为绑定**：在已有行为编辑器明确选择目标实例，复制当前脚本引用、参数原始输入与信号顺序，只分配新的绑定身份。未完成输入可以保留为草稿；参数里的UUID不推断改写，选择本身不改值，复制后仍需检查、完整审阅、应用草稿并普通保存。旧行与迟到辅助响应不能修改新绑定。[使用指南](SCENE_BEHAVIORS.md#复制当前绑定到场景实例)、[开发验证](test-results/scene-behavior-binding-copy/README.md)
- **独立原地重启**：普通Godot TXT起始脚本通过专用端口重新实例化当前成员，与不同成员导航／重试分别维护。重启原子覆盖明确列出的共享状态，撤销旧访问与节点；未列状态、事件序号和会话累计预算继续，不以重新建场景清空执行额度。[重启指南](SCENE_RESTART.md)、[原生与离线验证](test-results/scene-restart/README.md)
- **暂停、恢复与失焦松键**：显式暂停及窗口失焦可冻结玩法回调、物理、动画、原生音轨和游戏时钟。重新聚焦不会自动恢复；明确恢复后等待注册动作释放，才在同一访问与节点继续。宿主墙钟、输出限制和有限累计预算继续维护，观察面板只读。[暂停指南](PROJECT_PAUSE.md)、[输入与窗口验证](test-results/project-pause/README.md)
- **真实运行菜单**：独立于只读HUD的普通菜单脚本使用标题、按钮JSON与显示模式三项文本参数。场景菜单支持导航、重试、原地重启及结束；暂停菜单仅恢复或结束，暂停中的导航／重开明确拒绝。真实按钮支持键盘焦点与鼠标，选择后等待松键并复核访问；失焦取消待执行选择，旧按钮不能控制下一次访问。[菜单指南](PROJECT_MENU.md)、[实际玩法与交付验证](test-results/project-menu/README.md)
- **按名称连接菜单目标**：明确选择组装与成员场景，可修改已有scene／retry按钮目标，或填写标识、文字和命令后追加。只填入当前`items_json`一行，既有条目的空白、转义与初值保持；新retry默认`values:{}`，不会猜测复位值。写入前重新核对目录与表单归属，最终仍走普通依赖检查、审阅和保存。[名称接线](PROJECT_MENU.md#按名称连接菜单按钮)、[空白三成员纵切](test-results/menu-target-authoring/README.md)
- **创建脚本后返回场景**：首次行为创建窗口可暂存未保存配置，进入普通TXT脚本选择、编辑和保存，再明确返回原场景。恢复时重读目录、核对场景与实际保存版本，保留文档／绑定身份、后端、路径及原选择；新脚本不会自动选中或建立绑定与关系，旧审阅须重做。保存失败、取消、显式放弃和来源变化各有独立处理；暂存只在当前内存中，不作为作品恢复日志。已有行为原文含未保存修改的跨区往返尚未接入。[操作指南](SCENE_BEHAVIORS.md#创建脚本后返回场景)、[完整作者链验证](test-results/scene-script-return/README.md)
- **影视起始模板**：新增`org.viento.oc-film` 1.0.0，提供影视说明、人物、大纲、剧本场次、分镜、拍摄地点、制作计划和道具八类起点。大纲／场次使用prose保留重复对白、冒号和时间提示，其余使用通用structured；人物背景仍属于人物。模板复制进新工程，正文与素材起始为空，既有模板和默认空白选项保持。[影视工作流](FILM_WORKFLOW.md)、[创建、媒体与迁移验证](test-results/film-template/README.md)

## 架构、数据与交付

当前Godot执行描述符为 **0.49.0**。原地重启、暂停和菜单分别由独立生成层组合：项目组装无暂停／菜单需求时仍生成0.47.0，只有暂停需求使用0.48.0，菜单在完整暂停层外叠加0.49.0；单场景生成继续按实际内容选择原有内层。旧生成源码与内部库存分别核对，所需能力在成员、组装、后端和生成输出逐层检查。应用版本、模板包版本与后端生成版本互相独立。

项目业务协议继续按内容选择 **4／7／10／11**；上述增量不升级作者格式或事务日志。暂停状态沿独立只读观察通道回传，不以观察标记取得执行权限。规则、保存与来源核验、界面呈现及Godot执行分别维护，为后续ns-nova原生替换保留语义与验收任务。本版没有新增Bevy对等实现。

影视的`scene`只是剧本文档类型，不因名称获得可运行场景身份；预计时长和所属场次仍是作者文字，不自动建立时间线或对象关系。PNG／WAV／MP4资源沿稳定UUID引用与既有素材接口保存，标准作者ZIP真实异地导入后，模板、正文、登记和资源字节保持。输入样本可解码不等于Studio视频播放、剪辑、渲染或Android媒体验收；镜头时间线、自动摄影机调度和成片输出尚未接入。

`.viento.zip`用于作者工程及素材迁移，`.viento-build.zip`用于交付可审查的生成后端工程；后者仍需要兼容Godot工具。游戏运行专题中的“原生验收”指真实Godot执行，并不表示Studio已由ns-nova重写或本机安装已更新。**本机Linux AppImage仍为0.2.0**；本次提交推送源码，不构建或更新安装程序。

## 验证范围与后续

各专题保留实际Chrome作者操作、取消与重开、三语窄屏、来源守卫以及真实Godot窗口／标准生成ZIP离线运行的独立证据。绑定复制、重启、暂停和菜单从参考工程副本验证；名称接线另从空白结构创建三个成员并实际运行。脚本往返从空白结构验证成功、取消及来源变化，成功工程另做一次Godot无头运行。它们范围不同，不合并声称已从空白完成整款参考游戏，也不把软件图形、合成输入或浏览器桥接算作实体设备验收。

最近一次开发完整检查为 **9,759项：9,059通过、700条件跳过、零失败**，对应0.2.10工作树中的[脚本往返开发记录](test-results/scene-script-return/README.md)。该结果保持原时点，**不是0.3.0升版后的发布测试**；本版实际发布检查、来源摘要与命令另见[0.3.0发布检查](test-results/release-0.3.0/README.md)。条件跳过不算对应工具或设备通过，交叉专题不相加为覆盖率。

0.3.0补齐了部分二维作者和有限运行链路，仍未达到完整从空白制作游戏、跨启动存档、长期持续运行、字体闭包及无引擎工具独立发行的验收门槛。没有新增已安装Tauri、Android实体设备或其他系统的安装验收。后续继续按[路线图](ROADMAP.md)和[0.5.0产品门槛](MILESTONE_0.5.0.md)推进，保留旧开发失败、跳过、来源与历史记录。
