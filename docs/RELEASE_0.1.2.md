# 0.1.2 版本记录

2026-10-13。本版收录 0.1.1 之后的源码编辑辅助、任务问题回源、多演员配方创建与起始排布，并贯通配方到独立二维场景、Godot 运行和生成工程交付。工程格式、作者资料与素材沿用现有保存和迁移规则。

## 变更

- **源码查找与替换**：当前原文支持字面查找、前后导航、替换当前或全部匹配，保留原生撤销与普通保存。辅助输入框与正文素材导入分别处理，过期来源不能覆盖新草稿。
- **当前任务问题列表**：按严重度、原文位置和消息筛选诊断，展开详情后返回对应原文；同任务刷新保留输入，异步结果核对任务与来源归属。修改后仍需明确重新检查。
- **配方创建与多演员清单**：从已有对象或兼容游戏投影创建一份配方，支持 1–64 个演员、同对象多实例及逐项继承。切换演员保留未完成字段，身份在新增时分配；完整 JSON 审阅后进入普通草稿，保存才登记文件。初始结构为一个片段、一次放置，后续复用已有配方编辑器扩展。
- **起始排布**：横排、竖排或网格按演员列表顺序预览全部旧、新坐标，再明确应用；一次撤销可恢复原坐标输入。只修改位置，身份、对象和继承保持；手动修改、增删或过期输入会使旧操作失效，未完成坐标与越界整份拒绝。间距表示中心距离，不保证避免重叠。
- **二维工作流衔接**：已保存配方可在预览中明确生成独立 Scene2D，保留稳定实例、分组与投影继承，再接脚本／行为、问题回源修复、真实 Godot 构建和 `.viento-build.zip` 工程交付。生成场景与原配方分别编辑，互不自动同步。
- **桌面编辑修复**：修复 WebKit 中原文撤销／重做快捷键未触发现有历史的问题；调整小窗口媒体区占比，保留正文编辑空间。补齐“从配方创建场景”窗口的浏览器／桌面退出保护，避免直接关闭时丢失待保存设置或打断创建。
- **功能映射**：补齐普通二维场景、配方、Godot 行为及 Bevy 数据交付分支，新增配方创建与保存工作流入口。图谱区分已有实现、验证证据和规划能力。

当前为 **20 模块、37 项声明能力**；功能图谱为 **115 功能、301 实现、449 绑定、1796 评分单元、79 条工作流**。操作说明见 [场景配方](SCENE_COMPOSITION.md)、[任务问题列表](PROJECT_BUILD.md#当前任务问题列表)、[原文查找替换](SCENE_BEHAVIORS.md#原文查找与替换)及[二维功能映射](FUNCTION_MAPPING_2D.md)。

## 交付边界

本次提交推送 **0.1.2 源码**，不制作安装包、更新本机安装、创建版本标签或 GitHub Release。使用新增功能需从源码启动或自行构建。

最近的 [Linux 实际安装验收](test-results/native-installed-0.1.1/README.md)是此前的 **0.1.1 工作树 AppImage**，包含当时的查找替换、配方生成独立场景及两项桌面修复，但早于新配方创建、多演员和起始排布助手。该报告验证的 5020 个既有数据文件保持不变；它不代表本版新助手的 Tauri 安装验收。

新助手要求宿主提供对象查询；Android 目前只核对准备资源与可移植核心，没有新界面或设备验收。配方需先明确生成独立 Scene2D 才能进入既有构建与交付流程；工程 ZIP 保留后端工具依赖，尚非独立游戏发行程序。Godot 无头验证不代表图形运行或其他设备。Bevy 作者 Rust、持续工程诊断、外部 IDE／LSP、Nuislang／ns-nova 原生执行和嵌入运行视口继续独立推进。
