# 0.2.1 版本记录

2026-10-24。本版把逐实例动画、状态片段配置、目标回看和二维物理纳入同一源码交付。已保存场景可以直接进入项目组装；物理声明可经独立面板编辑、审阅和普通保存，再由 Godot 执行真实碰撞与触发事件。

## 变更

- **按状态配置动画片段**：在当前行为绑定中读取严格生成状态表，按名称选择本场景片段，显式合并参数后继续完整原文审阅与普通保存。选择、重置、取消及参数修改分别管理，完成边使用循环片段时提示作者核对。
- **按实例预览动画**：同一场景里的多个角色独立选择片段、播放、暂停和定位；停止一个实例不影响其他实例，全部停止恢复静态。预览会话只影响当前画面，不隐式改变作者保存的运行范围。
- **逐实例正式动画运行**：在动画字段中显式选择播放范围，检查、审阅并普通保存后，从项目组装构建。每个目标独立控制片段和播放时钟，自然完成、状态进入及命令记录保留目标身份；工程 ZIP 保留这些能力。
- **按动画目标回看**：命令和完成列表可进入独立目标历史，按场景访问与显式目标归组，查看多个行为绑定对同一实例的操作、自然完成锚点和冻结来源。场景重入与不同目标分别显示。
- **从当前场景创建组装**：构建页可将当前保存态二维场景带入独立组装草稿，经 JSON 审阅与显式保存后选中新项目，继续检查、构建和运行。原场景及手动组装入口保持。
- **状态片段绑定预检**：启动工具前检查严格生成控制器的全部状态，集中报告缺失片段、错误参数、无动画与实例轨道缺失。问题可定位原文，普通保存后重新检查；预检不替代运行时动态请求保护。
- **二维物理运行**：独立声明经 Rust 校验，映射为 Godot 静态障碍、受碰撞约束的角色和触发区，支持矩形／圆形、偏移及 16 位层掩码。真实触发区行为可以发布项目事件，连接动画状态转换和自然完成。视觉动画与物理根分离。
- **独立物理编辑面板**：打开已有物理 JSON 后，可增删碰撞体、调整种类和形状参数、查看局部示意，检查并审阅完整原文后应用到普通草稿，再保存。保留未改原文字节，取消与迟到结果不会覆盖原有草稿。实例 UUID 目前手动填写；登记、关联、成员和有效运动属性由构建检查。

以上新增界面提供中、英、日文案，包含窄屏、焦点与取消处理。操作见[场景动画](SCENE_ANIMATION.md)、[从场景组装](PROJECT_ASSEMBLY.md#从当前场景开始)及[二维物理](SCENE_PHYSICS2D.md)。

## 格式、分层与兼容

当前系统为 **23 模块／44 项声明能力**；功能图谱为 **158 功能／472 实现／680 绑定／2720 评分单元／122 工作流**。新增 `org.viento.scene-physics2d` 仅依赖文档模块，提供 `scene.authoring.physics2d`。本次源码归属更新不提高成熟度评分。

逐实例动画使用作者动画 **schema 4**、动画子计划 **3**；只有显式使用 `instance` 范围的项目组装启用 **运行协议 11／清单 12**。旧整场景控制器、普通动画和无动画项目保留原有协议 **10／7／4** 分支，旧格式继续按原形状读取。打开或检查旧动画不会自动升级；范围改变必须经显式审阅、应用和普通保存。预览停止恢复静态，正式运行的停止采样所选范围起点，两者各自定义。

物理作者声明为 `viento-scene-physics2d` **schema 1**，物理子计划为 `viento-physics2d-plan` **v1**；通过场景的 `references`／`physics2d` 关系选入，物理文档须回链场景。声明最多 64 KiB、1–128 个物理体，一个实例最多一个物理体。Rust 可选接口负责声明规则，中立计划负责保存态来源及能力，Godot 适配器负责原生节点和物理时钟；物理编辑面板不新增 HTTP 接口或规则副本。

当前 Godot 执行适配器为 **0.21.0**，含物理的新生成工程使用这一版本；无物理生成工程保留已有回执分支，逐实例动画为 **0.20.0**。物理本身不增加运行线协议，仍按项目的事件／动画内容选择协议。Bevy 数据适配器 **0.3.0**、Rust 适配器与模板 **0.2.0** 保持；不把 Godot 物理能力声明为 Bevy 已支持。

执行适配器变更会改变执行指纹。旧冻结构建可以读取，在新版 Studio 中再次运行或按现行适配器检查交付前需要重新生成；已导出的独立 Godot 工程不依赖 Studio 的执行指纹。应用标识、用户数据路径、作者稳定身份与素材不因本次升版批量迁移。

## 修复与交互保护

- 逐实例协议 11 接入共享状态、事件和声音观察入口，保留各面板及事件回看的独立来源保护。
- 动画目录、绑定参数、来源修订和会话变化撤销旧审阅；迟到读取不能覆盖新选择或已取消的草稿。
- 修复从场景创建组装后的目录同步，保存的新项目可继续选择、检查与执行。
- 物理接入后仍在第一次异步文件检查前验证并分离控制回放输入，保留旧无物理 Godot／Bevy 回放行为。
- 物理面板只在声明检查通过后显示形状；未完成数字保留输入并撤销审阅。中英日窄屏采用单正文滚动，返回、检查、应用和取消保持可见。

## 交付边界

本版为 **0.2.1 源码交付**。此次不制作或安装新程序，不创建版本标签或 GitHub Release；本机已安装程序仍为 **0.2.0**，其[安装验收](test-results/native-installed-0.2.0/README.md)保留原范围。

物理当前限 Godot 二维项目组装；尚无动态刚体、力／冲量、重力、关节、材质、区域间触发、3D 或 Bevy 物理。形状示意不运行求解，场景画布没有碰撞体拖拽；旧直接位置控制回放明确拒绝含物理工程。首次物理文档及双向关系仍通过普通文档和 World 操作建立。

逐实例动画尚不支持单场景直接构建、同目标控制仲裁／混合、骨骼、3D 或 Bevy 动画。运行条件逐项追踪和实际运行断言仍待接入。工程 ZIP 需要对应引擎工具，尚非独立游戏发行程序；源码交付不代表安装版、Android 或其他设备验收。
