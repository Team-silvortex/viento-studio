# 2D 关键帧动画示例

复制整个目录到新的临时作品后打开。示例不包含外部素材。

- 打开 `documents/animations/demo.json` 的原文，进入 **编辑场景动画**，编辑通道和关键帧，播放或拖动时间查看示意预览。
- 检查完整原文后应用草稿，再使用普通保存。
- 对 `documents/scenes/demo.json` 选择 Godot 4 构建并运行，观察视觉偏移、旋转、缩放和阶梯透明度。第一个实例仍可用方向键移动；动画不会改变移动逻辑坐标。
- 每轮 2 秒循环。所有目标使用稳定实例 UUID；编辑器示意图不代替真实场景渲染。

场景以 `animation` 关系明确选择动画文档，文档反向登记 `reference` 关系供迁移和资源包依赖收集。实际格式与边界见 [动画指南](../../docs/SCENE_ANIMATION.md)。
